# tiny-process-library

> 标签: MIT, c++, tiny-process-library, vcpkg

## 简介

A small platform independent library to create and stop new processes in C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/tiny-process-library
