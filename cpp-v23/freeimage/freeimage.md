# freeimage

> 标签: FreeImage, GPL-2.0-only OR GPL-3.0-only OR FreeImage, c++, conan, freeimage, vcpkg

## 简介

Support library for graphics image formats

Conan Center 收录：Open Source library project for developers who would like to support popular graphics image formats

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
