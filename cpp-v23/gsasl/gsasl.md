# gsasl

> 标签: LGPL-2.1-or-later, c++, gsasl, vcpkg

## 简介

Simple Authentication and Security Layer framework and a few common SASL mechanisms

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
