# safeint

> 标签: c++, safeint, vcpkg

## 简介

SafeInt is a class library for C++ that manages integer overflows

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/dcleblanc/SafeInt
- vcpkg 端口：https://vcpkg.io/en/packages/safeint
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/safeint
