# s2n

> 标签: Apache-2.0, c++, s2n, vcpkg

## 简介

C99 implementation of the TLS/SSL protocols.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
