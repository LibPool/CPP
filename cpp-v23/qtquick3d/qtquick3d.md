# qtquick3d

> 标签: c++, qtquick3d, vcpkg

## 简介

Qt Quick 3D provides a high-level API for creating 3D content and 3D user interfaces based on Qt Quick.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
