# curve-flagpp

> 标签: c++, curve-flagpp, vcpkg

## 简介

A C++20 library that provides (opt-in) bit-wise operations for arbitrary `enum class`es

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
