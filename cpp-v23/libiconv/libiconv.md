# libiconv

> 标签: c++, libiconv, vcpkg

## 简介

iconv() text conversion.
This port installs GNU libiconv if the system C runtime doesn't provide a suitable iconv() implementation.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
