# clue

> 标签: c++, clue, vcpkg

## 简介

clue is a C++03 header-only library to log messages with a severity and optional module identifier.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/martinmoene/clue
- vcpkg 端口：https://vcpkg.io/en/packages/clue
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/clue
