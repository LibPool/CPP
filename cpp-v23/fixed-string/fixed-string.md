# fixed-string

> 标签: MIT, c++, fixed-string, vcpkg

## 简介

Header-only C++17 library provides a string class with std::array fixed-size semantic.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
