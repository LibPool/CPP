# freealut

> 标签: LGPL-2.0-only, LGPL-2.0-or-later, c++, conan, freealut, vcpkg

## 简介

FreeALUT is a free implementation of OpenAL's ALUT standard.
ALUT is a set of portable functions which remove the annoying details of getting an audio application started. It is the OpenAL counterpart of what GLUT is for OpenGL.

Conan Center 收录：freealut is a free implementation of OpenAL's ALUT standard.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
