# platformfolders

> 标签: MIT, c++, conan, platformfolders

## 简介

Conan Center 收录：A C++ library to look for special directories like My Documents and APPDATA so that you do not need to write Linux, Windows or Mac OS X specific code

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网（Conan）：https://github.com/sago007/PlatformFolders
- Conan Center：https://conan.io/center/recipes/platformfolders
- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/platformfolders
