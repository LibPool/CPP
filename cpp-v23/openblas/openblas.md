# openblas

> 标签: BSD-3-Clause, c++, conan, openblas, vcpkg

## 简介

OpenBLAS is an optimized BLAS library based on GotoBLAS2 1.13 BSD version.

Conan Center 收录：An optimized BLAS library based on GotoBLAS2 1.13 BSD version

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
