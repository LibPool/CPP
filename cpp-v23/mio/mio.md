# mio

> 标签: MIT, c++, mio, vcpkg

## 简介

Cross-platform header-only C++11 library for memory mapped file IO.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/mandreyel/mio
- vcpkg 端口：https://vcpkg.io/en/packages/mio
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mio
