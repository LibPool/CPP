# libssh

> 标签: LGPL-2.1-only, c++, libssh, vcpkg

## 简介

libssh is a multiplatform C library implementing the SSHv2 protocol on client and server side

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
