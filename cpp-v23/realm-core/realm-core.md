# realm-core

> 标签: c++, realm-core, vcpkg

## 简介

Realm is a mobile database that runs directly inside phones, tablets or wearables.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
