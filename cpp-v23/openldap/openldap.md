# openldap

> 标签: OLDAP-2.8, c++, openldap, vcpkg

## 简介

OpenLDAP Software is an open source implementation of the Lightweight Directory Access Protocol.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
