# ngtcp2

> 标签: MIT, c++, ngtcp2, vcpkg

## 简介

ngtcp2 project is an effort to implement RFC9000 QUIC protocol.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
