# munit

> 标签: c++, munit, vcpkg

## 简介

A small but full-featured unit testing framework for C

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/nemequ/munit
- vcpkg 端口：https://vcpkg.io/en/packages/munit
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/munit
