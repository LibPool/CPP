# tree-gen

> 标签: Apache-2.0, c++, conan, tree-gen

## 简介

Conan Center 收录：C++ and Python code generator for tree-like structures common in parser and compiler codebases.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
