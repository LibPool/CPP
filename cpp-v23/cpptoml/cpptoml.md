# cpptoml

> 标签: MIT, c++, conan, cpptoml, vcpkg

## 简介

A header-only library for parsing TOML configuration files.

Conan Center 收录：cpptoml is a header-only library for parsing TOML

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
