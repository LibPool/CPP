# discord-game-sdk

> 标签: c++, discord-game-sdk, vcpkg

## 简介

The Discord GameSDK is an easy drop-in SDK to help you manage all the hard things that come with making a game.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
