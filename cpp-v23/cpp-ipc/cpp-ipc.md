# cpp-ipc

> 标签: c++, cpp-ipc, vcpkg

## 简介

C++ IPC Library: A high-performance inter-process communication using shared memory on Linux/Windows.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
