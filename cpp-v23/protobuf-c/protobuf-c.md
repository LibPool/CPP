# protobuf-c

> 标签: LicenseRef-LICENSE, c++, conan, protobuf-c, vcpkg

## 简介

This is protobuf-c, a C implementation of the Google Protocol Buffers data serialization format.

Conan Center 收录：Protocol Buffers implementation in C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
