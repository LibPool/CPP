# libinput

> 标签: MIT, c++, conan, libinput

## 简介

Conan Center 收录：libinput is a library that handles input devices for display servers and other applications that need to directly deal with input devices.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
