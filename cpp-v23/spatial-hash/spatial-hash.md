# spatial-hash

> 标签: BSD-3-Clause, c++, spatial-hash, vcpkg

## 简介

A minimal C++ library for spatial data structures based on voxel hashing.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
