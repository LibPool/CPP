# concurrencpp

> 标签: MIT, c++, conan, concurrencpp, vcpkg

## 简介

concurrencpp is a tasking library for C++ allowing developers to write highly concurrent applications easily and safely by using tasks, executors and coroutines.

Conan Center 收录：Modern concurrency for C++. Tasks, executors, timers and C++20 coroutines to rule them all.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
