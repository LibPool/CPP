# fixed-math

> 标签: BSL-1.0, c++, fixed-math, vcpkg

## 简介

A High-Performance C++23, C++17 Library for Fixed-Point 48.16 Arithmetic

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
