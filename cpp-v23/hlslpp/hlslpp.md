# hlslpp

> 标签: MIT, c++, hlslpp, vcpkg

## 简介

Math library using HLSL syntax with multiplatform SIMD support.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/redorav/hlslpp
- vcpkg 端口：https://vcpkg.io/en/packages/hlslpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/hlslpp
