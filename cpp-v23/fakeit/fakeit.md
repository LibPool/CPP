# fakeit

> 标签: MIT, c++, fakeit, vcpkg

## 简介

FakeIt is a simple mocking framework for C++. It supports GCC, Clang and MS Visual C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/eranpeer/FakeIt
- vcpkg 端口：https://vcpkg.io/en/packages/fakeit
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/fakeit
