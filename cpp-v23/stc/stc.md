# stc

> 标签: MIT, c++, stc, vcpkg

## 简介

A modern, user friendly, generic, type-safe and fast C99 container library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/stc
