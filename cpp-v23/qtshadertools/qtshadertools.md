# qtshadertools

> 标签: c++, qtshadertools, vcpkg

## 简介

The Qt Shader Tools module is designed to provide a set of tools and utilities to work with graphics shaders.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
