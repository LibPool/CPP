# ini-cpp

> 标签: BSD-3-Clause, c++, ini-cpp, vcpkg

## 简介

Single-header INI file reader and writer for modern C++ (C++17), with type-aware getters and sensible defaults

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
