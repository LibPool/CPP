# dxut

> 标签: MIT, c++, dxut, vcpkg

## 简介

A "GLUT"-like framework for Direct3D 11.x Win32 desktop applications

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
