# lpeg

> 标签: MIT, c++, lpeg, vcpkg

## 简介

LPeg is a pattern-matching library for Lua, based on Parsing Expression Grammars (PEGs).

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
