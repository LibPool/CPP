# libxcb

> 标签: X11-distribute-modifications-variant, c++, libxcb, vcpkg

## 简介

C interface to the X Window System protocol, which replaces the traditional Xlib interface.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libxcb
