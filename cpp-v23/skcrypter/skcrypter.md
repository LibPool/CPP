# skcrypter

> 标签: c++, skcrypter, vcpkg

## 简介

Compile-time, Usermode + Kernelmode, safe and lightweight string crypter library for C++11

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/skadro-official/skCrypter
- vcpkg 端口：https://vcpkg.io/en/packages/skcrypter
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/skcrypter
