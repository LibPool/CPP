# hidapi

> 标签: BSD-3-Clause-Clear, GPL-3.0-or-later, c++, conan, hidapi, vcpkg

## 简介

A Simple library for communicating with USB and Bluetooth HID devices on Linux, Mac and Windows.

Conan Center 收录：HIDAPI is a multi-platform library which allows an application to interface

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
