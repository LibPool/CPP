# ixwebsocket

> 标签: BSD-3-Clause, c++, conan, ixwebsocket, vcpkg

## 简介

Lightweight WebSocket Client and Server + HTTP Client and Server

Conan Center 收录：IXWebSocket is a C++ library for WebSocket client and server development

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
