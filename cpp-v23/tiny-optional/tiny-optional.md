# tiny-optional

> 标签: BSL-1.0, c++, tiny-optional, vcpkg

## 简介

Drop-in replacement for std::optional that does not waste memory unnecessarily

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
