# utfz

> 标签: c++, utfz, vcpkg

## 简介

A tiny C++ library for parsing and encoding utf-8

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/IMQS/utfz
- vcpkg 端口：https://vcpkg.io/en/packages/utfz
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/utfz
