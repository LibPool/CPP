# argtable3

> 标签: BSD-3-Clause AND TCL, BSD-3-clause, argtable3, c++, conan, vcpkg

## 简介

A single-file, ANSI C, command-line parsing library that parses GNU-style command-line options

Conan Center 收录：A single-file, ANSI C, command-line parsing library that parses GNU-style command-line options.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
