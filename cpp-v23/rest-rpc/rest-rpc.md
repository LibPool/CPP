# rest-rpc

> 标签: c++, rest-rpc, vcpkg

## 简介

c++11, high performance, cross platform, easy to use rpc framework

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/qicosmos/rest_rpc
- vcpkg 端口：https://vcpkg.io/en/packages/rest-rpc
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/rest-rpc
