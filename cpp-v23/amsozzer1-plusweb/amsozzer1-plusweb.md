# amsozzer1-plusweb

> 标签: MIT, amsozzer1-plusweb, c++, vcpkg

## 简介

Express-style HTTP framework for C++17 built on libuv and llhttp, with a segment-trie router and a middleware chain

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
