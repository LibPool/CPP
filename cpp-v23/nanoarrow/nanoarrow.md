# nanoarrow

> 标签: Apache-2.0, c++, nanoarrow, vcpkg

## 简介

Helpers for Arrow C Data & Arrow C Stream interfaces

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
