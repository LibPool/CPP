# easyloggingpp

> 标签: MIT, c++, conan, easyloggingpp, vcpkg

## 简介

Easylogging++ is a single header efficient logging library for C++ applications.

Conan Center 收录：Single-header C++ logging library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
