# libzen

> 标签: ZLIB, Zlib, c++, conan, libzen, vcpkg

## 简介

ZenLib is a C++ utility library for easiest cross-platform development

Conan Center 收录：Small C++ derivate classes to have an easier life

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
