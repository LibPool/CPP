# wildcards

> 标签: BSL-1.0, c++, vcpkg, wildcards

## 简介

A simple C++ header-only template library implementing matching using wildcards

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
