# libpqxx

> 标签: BSD-3-Clause, c++, conan, libpqxx, vcpkg

## 简介

The official* C++ client API for PostgreSQL.
*) NB https://pqxx.org/libpqxx/faq/

Conan Center 收录：The official C++ client API for PostgreSQL

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
