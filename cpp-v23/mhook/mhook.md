# mhook

> 标签: c++, mhook, vcpkg

## 简介

A Windows API hooking library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/mhook
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mhook

## 历史版本号

- 当前版本：2.5.1#3

- 2.5.1#3
