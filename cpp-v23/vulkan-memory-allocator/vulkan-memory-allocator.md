# vulkan-memory-allocator

> 标签: MIT, c++, vcpkg, vulkan-memory-allocator

## 简介

Easy to integrate Vulkan memory allocation library from GPUOpen

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/GPUOpen-LibrariesAndSDKs/VulkanMemoryAllocator

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vulkan-memory-allocator
