# vulkan-memory-allocator

> 标签: MIT, c++, conan, vcpkg, vulkan-memory-allocator

## 简介

Easy to integrate Vulkan memory allocation library from GPUOpen

Conan Center 收录：Easy to integrate Vulkan memory allocation library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
