# libbpf

> 标签: LGPL-2.1-only, LGPL-2.1-only OR BSD-2-Clause, c++, conan, libbpf, vcpkg

## 简介

Supports loading compiled BPF object files into the Linux Kernel

Conan Center 收录：eBPF helper library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
