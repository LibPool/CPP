# cpp-lazy

> 标签: MIT, c++, conan, cpp-lazy, vcpkg

## 简介

C++11 (and onwards) library for lazy evaluation

Conan Center 收录：C++11/14/17/20 library for lazy evaluation

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
