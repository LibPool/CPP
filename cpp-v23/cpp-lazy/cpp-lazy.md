# cpp-lazy

> 标签: MIT, c++, cpp-lazy, vcpkg

## 简介

C++11 (and onwards) library for lazy evaluation

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
