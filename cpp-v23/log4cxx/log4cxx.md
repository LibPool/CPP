# log4cxx

> 标签: Apache-2.0, c++, conan, log4cxx, vcpkg

## 简介

Apache log4cxx is a logging framework for C++ patterned after Apache log4j, which uses Apache Portable Runtime for most platform-specific code and should be usable on any platform supported by APR

Conan Center 收录：Logging framework for C++ patterned after Apache log4j

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
