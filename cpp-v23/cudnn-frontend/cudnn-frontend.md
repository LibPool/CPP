# cudnn-frontend

> 标签: Apache-2.0 AND MIT, c++, cudnn-frontend, vcpkg

## 简介

cudnn_frontend provides a c++ wrapper for the cudnn backend API and samples on how to use it

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/NVIDIA/cudnn-frontend
- vcpkg 端口：https://vcpkg.io/en/packages/cudnn-frontend
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cudnn-frontend
