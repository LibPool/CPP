# vtk-compile-tools

> 标签: c++, vcpkg, vtk-compile-tools

## 简介

Tools needed for crosscompiling VTK

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/Kitware/VTK
- vcpkg 端口：https://vcpkg.io/en/packages/vtk-compile-tools
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vtk-compile-tools
