# ctbignum

> 标签: c++, ctbignum, vcpkg

## 简介

This is a header-only template library for fixed-width "small big-integer" computations, for use during run-time as well as compile-time.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
