# cppfs

> 标签: MIT, c++, cppfs, vcpkg

## 简介

Cross-platform C++ file system library supporting multiple backends

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/cppfs
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cppfs
