# cyclonedds

> 标签: EPL-2.0, EPL-2.0 OR BSD-3-Clause, c++, conan, cyclonedds, vcpkg

## 简介

Eclipse Cyclone DDS is a very performant and robust open-source implementation of the OMG DDS specification

Conan Center 收录：Eclipse Cyclone DDS - An implementation

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
