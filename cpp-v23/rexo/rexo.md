# rexo

> 标签: Unlicense, c++, rexo, vcpkg

## 简介

Rexo is a neat single-file cross-platform unit testing framework for C/C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
