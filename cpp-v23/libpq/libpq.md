# libpq

> 标签: PostgreSQL, c++, libpq, vcpkg

## 简介

The official database access API of postgresql

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
