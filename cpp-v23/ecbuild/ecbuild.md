# ecbuild

> 标签: c++, ecbuild, vcpkg

## 简介

ECMWF CMake build system and CMake macro collection

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/ecmwf/ecbuild
- vcpkg 端口：https://vcpkg.io/en/packages/ecbuild
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/ecbuild
