# oatpp-curl

> 标签: Apache-2.0, c++, oatpp-curl, vcpkg

## 简介

Oat++ Modern web framework curl module to use libcurl as a RequestExecutor on the oatpp's ApiClient.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
