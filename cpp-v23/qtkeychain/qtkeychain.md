# qtkeychain

> 标签: BSD-3-Clause, c++, qtkeychain, vcpkg

## 简介

(Unaffiliated with Qt) Platform-independent Qt5 API for storing passwords securely

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
