# gtkmm

> 标签: LGPL-3.0-or-later, c++, gtkmm, vcpkg

## 简介

gtkmm is the official C++ interface for the popular GUI library GTK+.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
