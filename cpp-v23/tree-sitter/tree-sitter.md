# tree-sitter

> 标签: MIT, c++, conan, tree-sitter, vcpkg

## 简介

An incremental parsing system for programming tools.

Conan Center 收录：Tree-sitter is a parser generator tool and an incremental parsing library. It can build a concrete syntax tree for a source file and efficiently update the syntax tree as the source file is edited.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
