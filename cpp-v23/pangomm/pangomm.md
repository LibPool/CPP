# pangomm

> 标签: LGPL-2.1, LGPL-2.1-or-later, c++, conan, pangomm, vcpkg

## 简介

pangomm is the official C++ interface for the Pango font layout library. See, for instance, the Pango::Layout class.

Conan Center 收录：pangomm is a C++ API for Pango: a library for layout and rendering of text.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
