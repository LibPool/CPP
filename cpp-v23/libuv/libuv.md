# libuv

> 标签: BSD-3-Clause, c++, libuv, vcpkg

## 简介

libuv is a multi-platform support library with a focus on asynchronous I/O.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/libuv/libuv
- vcpkg 端口：https://vcpkg.io/en/packages/libuv
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libuv
