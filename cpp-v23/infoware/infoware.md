# infoware

> 标签: CC0-1.0, c++, infoware, vcpkg

## 简介

C++ Library for pulling system and hardware information, without hitting the command line.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/ThePhD/infoware
- vcpkg 端口：https://vcpkg.io/en/packages/infoware
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/infoware
