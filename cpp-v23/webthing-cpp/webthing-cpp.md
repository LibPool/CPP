# webthing-cpp

> 标签: MIT, c++, vcpkg, webthing-cpp

## 简介

Webthing-CPP is a modern CPP/C++17 implementation of the WebThings API.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
