# vcpkg-tool-mozbuild

> 标签: c++, vcpkg, vcpkg-tool-mozbuild

## 简介

mozbuild is a Python package providing functionality used by Mozilla’s build system

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
