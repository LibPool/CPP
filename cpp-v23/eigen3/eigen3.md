# eigen3

> 标签: MPL-2.0, c++, eigen3, vcpkg

## 简介

C++ template library for linear algebra: matrices, vectors, numerical solvers, and related algorithms.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://eigen.tuxfamily.org
- vcpkg 端口：https://vcpkg.io/en/packages/eigen3
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/eigen3
