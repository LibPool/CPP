# libvhdi

> 标签: LGPL-3.0-or-later, c++, libvhdi, vcpkg

## 简介

Library and tools to access the Virtual Hard Disk (VHD) image format

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
