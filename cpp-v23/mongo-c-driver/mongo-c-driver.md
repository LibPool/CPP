# mongo-c-driver

> 标签: Apache-2.0, c++, mongo-c-driver, vcpkg

## 简介

Client library written in C for MongoDB.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
