# tmxlite

> 标签: Zlib, c++, conan, tmxlite, vcpkg

## 简介

A lightweight C++14 parsing library for tmx map files created with the Tiled map editor.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
