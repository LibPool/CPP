# minio-cpp

> 标签: Apache-2.0, c++, minio-cpp, vcpkg

## 简介

The MinIO C++ Client SDK provides simple APIs to access any Amazon S3 compatible object storage

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
