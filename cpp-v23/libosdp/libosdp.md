# libosdp

> 标签: Apache-2.0, c++, libosdp, vcpkg

## 简介

An cross-platform open source implementation of IEC 60839-11-5 Open Supervised Device Protocol (OSDP)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/osdp-dev/libosdp
- vcpkg 端口：https://vcpkg.io/en/packages/libosdp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libosdp
