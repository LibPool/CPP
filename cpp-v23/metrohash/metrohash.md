# metrohash

> 标签: c++, metrohash, vcpkg

## 简介

MetroHash is a set of state-of-the-art hash functions for non-cryptographic use cases

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
