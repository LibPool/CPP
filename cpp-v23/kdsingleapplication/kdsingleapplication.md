# kdsingleapplication

> 标签: MIT, c++, kdsingleapplication, vcpkg

## 简介

KDSingleApplication is a helper class for single-instance policy applications.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
