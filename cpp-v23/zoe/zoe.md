# zoe

> 标签: GPL-3.0-only, c++, conan, vcpkg, zoe

## 简介

C++ File Download Library.

Conan Center 收录：A multi-protocol, multi-threaded, resumable, cross-platform, open source, C++ file download library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
