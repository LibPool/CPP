# gperftools

> 标签: BSD-3-Clause, c++, gperftools, vcpkg

## 简介

A high-performance multi-threaded malloc() implementation, plus some performance analysis tools.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
