# lv2

> 标签: ISC, c++, lv2, vcpkg

## 简介

LV2 is a plugin standard for audio systems. It defines a minimal yet extensible C API for plugin code and a format for plugin "bundles".

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://lv2plug.in
- vcpkg 端口：https://vcpkg.io/en/packages/lv2
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/lv2
