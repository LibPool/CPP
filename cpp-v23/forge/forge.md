# forge

> 标签: BSD-3-Clause, c++, forge, vcpkg

## 简介

An OpenGL interop library that can be used with ArrayFire or any other application using CUDA or OpenCL compute backend.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/arrayfire/forge
- vcpkg 端口：https://vcpkg.io/en/packages/forge
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/forge
