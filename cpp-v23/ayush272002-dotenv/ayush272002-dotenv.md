# ayush272002-dotenv

> 标签: MIT, ayush272002-dotenv, c++, vcpkg

## 简介

A modern C++23 header-only library for loading and parsing .env files at runtime.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
