# sbp

> 标签: MIT, c++, conan, sbp, vcpkg

## 简介

Swift Navigation Binary Protocol (SBP) is a binary protocol for communicating GNSS data used by Piksi devices.

Conan Center 收录：Swift Binary Protocol client library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
