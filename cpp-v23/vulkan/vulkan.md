# vulkan

> 标签: c++, vcpkg, vulkan

## 简介

A stub package that ensures that Vulkan headers and a loader are available.
On Android, the NDK provides a loader at API level 24 or higher.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
