# suitesparse-btf

> 标签: LGPL-2.1-or-later, c++, suitesparse-btf, vcpkg

## 简介

BTF: Software package for permuting a matrix into block upper triangular form in SuiteSparse

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
