# cpp-peglib

> 标签: MIT, c++, conan, cpp-peglib, vcpkg

## 简介

A single file C++ header-only PEG (Parsing Expression Grammars) library

Conan Center 收录：A single file C++11 header-only PEG (Parsing Expression Grammars) library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
