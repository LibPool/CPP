# matajoh-libnpy

> 标签: MIT, c++, matajoh-libnpy, vcpkg

## 简介

A C++17 library for reading and writing NumPy NPY and NPZ array files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
