# 7zip

> 标签: 7zip, LGPL-2.1-or-later, c++, vcpkg

## 简介

Library for archiving file with a high compression ratio.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
