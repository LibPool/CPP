# discount

> 标签: c++, discount, vcpkg

## 简介

DISCOUNT is a implementation of John Gruber & Aaron Swartz's Markdown markup language.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
