# clipboardxx

> 标签: MIT, c++, clipboardxx, vcpkg

## 简介

Header only, lightweight and cross platform C++ library for copy and paste text from clipboard.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/Arian8j2/ClipboardXX
- vcpkg 端口：https://vcpkg.io/en/packages/clipboardxx
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/clipboardxx
