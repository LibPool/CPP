# stormlib

> 标签: c++, stormlib, vcpkg

## 简介

StormLib is a library for opening and manipulating Blizzard MPQ files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://www.zezula.net/en/mpq/stormlib.html
- vcpkg 端口：https://vcpkg.io/en/packages/stormlib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/stormlib
