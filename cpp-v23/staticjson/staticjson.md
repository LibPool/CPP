# staticjson

> 标签: MIT, c++, staticjson, vcpkg

## 简介

Fast, direct and static typed parsing of JSON with C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/netheril96/StaticJSON
- vcpkg 端口：https://vcpkg.io/en/packages/staticjson
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/staticjson
