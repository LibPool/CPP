# yyjson

> 标签: MIT, c++, vcpkg, yyjson

## 简介

A high performance JSON library written in ANSI C

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
