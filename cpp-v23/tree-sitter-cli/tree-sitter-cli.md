# tree-sitter-cli

> 标签: c++, tree-sitter-cli, vcpkg

## 简介

Tree-sitter is a parser generator tool and an incremental parsing library. This port installs the CLI executable.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
