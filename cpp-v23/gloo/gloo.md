# gloo

> 标签: BSD-3-Clause, c++, gloo, vcpkg

## 简介

Collective communications library with various primitives for multi-machine training.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
