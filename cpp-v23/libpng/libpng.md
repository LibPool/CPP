# libpng

> 标签: c++, conan, libpng, libpng-2.0, vcpkg

## 简介

libpng is a library implementing an interface for reading and writing PNG (Portable Network Graphics) format files

Conan Center 收录：libpng is the official PNG file format reference library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
