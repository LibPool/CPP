# i2c-tools

> 标签: c++, conan, i2c-tools

## 简介

Conan Center 收录：I2C tools for the linux kernel as well as an I2C library.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网（Conan）：https://i2c.wiki.kernel.org/index.php/I2C_Tools
- Conan Center：https://conan.io/center/recipes/i2c-tools
- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/i2c-tools
