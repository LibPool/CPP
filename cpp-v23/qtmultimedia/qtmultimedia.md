# qtmultimedia

> 标签: c++, qtmultimedia, vcpkg

## 简介

Qt Multimedia is an add-on module that provides a rich set of QML types and C++ classes to handle multimedia content.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
