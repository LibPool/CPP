# cpuid

> 标签: BSD-2-Clause, c++, cpuid, vcpkg

## 简介

Provides CPU identification for the x86 (and x86_64)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/anrieff/libcpuid
- vcpkg 端口：https://vcpkg.io/en/packages/cpuid
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cpuid
