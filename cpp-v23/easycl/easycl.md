# easycl

> 标签: c++, easycl, vcpkg

## 简介

OpenCL based lightweight c++ computing library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/architector1324/EasyCL
- vcpkg 端口：https://vcpkg.io/en/packages/easycl
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/easycl
