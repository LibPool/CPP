# mathc

> 标签: c++, mathc, vcpkg

## 简介

Pure C math library for 2D and 3D programming

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://github.com/felselva/mathc

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mathc
