# tsl-hopscotch-map

> 标签: c++, tsl-hopscotch-map, vcpkg

## 简介

C++ implementation of a fast hash map and hash set using hopscotch hashing

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
