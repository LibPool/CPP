# bcg729

> 标签: GPL-3.0-or-later OR LicenseRef-Proprietary, bcg729, c++, vcpkg

## 简介

Bcg729 is an open source implementation of the ITU G.729 Annex A and B codec.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/BelledonneCommunications/bcg729
- vcpkg 端口：https://vcpkg.io/en/packages/bcg729
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/bcg729
