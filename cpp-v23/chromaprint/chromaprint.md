# chromaprint

> 标签: LGPL-2.1-or-later, c++, chromaprint, vcpkg

## 简介

C library for generating audio fingerprints used by AcoustID

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/acoustid/chromaprint
- vcpkg 端口：https://vcpkg.io/en/packages/chromaprint
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/chromaprint
