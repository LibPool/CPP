# libspnav

> 标签: c++, libspnav, vcpkg

## 简介

Library for communicating with spacenavd or 3dxsrv to get input from 6-dof devices.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/FreeSpacenav/libspnav
- vcpkg 端口：https://vcpkg.io/en/packages/libspnav
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libspnav
