# offscale-libetcd-cpp

> 标签: c++, offscale-libetcd-cpp, vcpkg

## 简介

A C++ client library for etcd. etcd is a distributed, reliable key-value store.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
