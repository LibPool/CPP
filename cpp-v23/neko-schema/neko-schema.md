# neko-schema

> 标签: MIT OR Apache-2.0, c++, conan, neko-schema, vcpkg

## 简介

A lightweight C++20 header-only library providing fundamental type definitions and utilities for the Neko ecosystem

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
