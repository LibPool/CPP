# activemq-cpp

> 标签: Apache-2.0, activemq-cpp, c++, conan, vcpkg

## 简介

Apache ActiveMQ is the most popular and powerful open source messaging and Integration Patterns server.

Conan Center 收录：JMS-like API for C++ for interfacing with Message Brokers such as Apache ActiveMQ

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
