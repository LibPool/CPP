# trieste

> 标签: MIT, c++, trieste, vcpkg

## 简介

A header-only C++20 term rewriting system for rapidly prototyping programming languages

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
