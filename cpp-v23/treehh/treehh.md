# treehh

> 标签: GPL-2.0-only OR GPL-3.0-only, c++, treehh, vcpkg

## 简介

An STL-like C++ header-only tree library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
