# libtommath

> 标签: c++, libtommath, vcpkg

## 简介

LibTomMath is a free open source portable number theoretic multiple-precision integer library written entirely in C.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.libtom.net/LibTomMath/
- vcpkg 端口：https://vcpkg.io/en/packages/libtommath
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libtommath
