# cppunit

> 标签: LGPL-2.1-or-later, c++, conan, cppunit, vcpkg

## 简介

Unit testing framework module for the C++ programming language

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
