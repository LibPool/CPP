# argus

> 标签: MIT, argus, c++, vcpkg

## 简介

Argus is a cross-platform modern feature-rich command-line argument parser for C

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
