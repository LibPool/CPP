# qtconnectivity

> 标签: c++, qtconnectivity, vcpkg

## 简介

The Qt Connectivity module provides access to Bluetooth and NFC hardware.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
