# flashlight-cuda

> 标签: MIT, c++, flashlight-cuda, vcpkg

## 简介

A C++ standalone library for machine learning. CUDA backend.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
