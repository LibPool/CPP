# chadwick

> 标签: GPL-2.0-or-later, c++, chadwick, vcpkg

## 简介

Suite of tools and C library for parsing Retrosheet baseball play-by-play and event files

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
