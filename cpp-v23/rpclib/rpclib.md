# rpclib

> 标签: c++, rpclib, vcpkg

## 简介

a RPC library for C++, providing both a client and server implementation. It is built using modern C++14.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/rpclib/rpclib
- vcpkg 端口：https://vcpkg.io/en/packages/rpclib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/rpclib
