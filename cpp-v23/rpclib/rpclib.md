# rpclib

> 标签: MIT, c++, conan, rpclib, vcpkg

## 简介

a RPC library for C++, providing both a client and server implementation. It is built using modern C++14.

Conan Center 收录：A modern C++ msgpack-RPC server and client library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
