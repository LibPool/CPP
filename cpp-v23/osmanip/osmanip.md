# osmanip

> 标签: MIT, c++, conan, osmanip, vcpkg

## 简介

A cross-platform library for output stream manipulation using ANSI escape sequences.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
