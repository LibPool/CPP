# qtquick3dphysics

> 标签: c++, qtquick3dphysics, vcpkg

## 简介

Qt Quick 3D Physics provides a high-level API for physics simulation.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
