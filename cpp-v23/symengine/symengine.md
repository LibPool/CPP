# symengine

> 标签: BSD-3-Clause, c++, symengine, vcpkg

## 简介

SymEngine is a fast symbolic manipulation library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
