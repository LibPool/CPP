# pdal

> 标签: BSD-3-Clause, c++, conan, pdal, vcpkg

## 简介

PDAL - Point Data Abstraction Library is a library for manipulating point cloud data.

Conan Center 收录：PDAL is Point Data Abstraction Library. GDAL for point cloud data.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
