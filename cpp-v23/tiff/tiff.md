# tiff

> 标签: c++, libtiff, tiff, vcpkg

## 简介

A library that supports the manipulation of TIFF image files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
