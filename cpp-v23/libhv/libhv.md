# libhv

> 标签: BSD-3-Clause, c++, libhv, vcpkg

## 简介

Libhv is a C/C++ network library similar to libevent/libuv.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/ithewei/libhv
- vcpkg 端口：https://vcpkg.io/en/packages/libhv
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libhv
