# dacap-clip

> 标签: MIT, c++, conan, dacap-clip, vcpkg

## 简介

Cross-platform C++ library to copy/paste clipboard content.

Conan Center 收录：Cross-platform C++ library to copy/paste clipboard content

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
