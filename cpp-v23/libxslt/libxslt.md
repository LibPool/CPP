# libxslt

> 标签: MIT, c++, conan, libxslt, vcpkg

## 简介

Libxslt is a XSLT library implemented in C for XSLT 1.0 and most of EXSLT

Conan Center 收录：libxslt is a software library implementing XSLT processor, based on libxml2

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
