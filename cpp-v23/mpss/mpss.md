# mpss

> 标签: MIT, c++, mpss, vcpkg

## 简介

A multi-platform C++ library for hardware-backed digital signature key storage and signing.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/microsoft/mpss
- vcpkg 端口：https://vcpkg.io/en/packages/mpss
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mpss
