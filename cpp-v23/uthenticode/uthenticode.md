# uthenticode

> 标签: c++, uthenticode, vcpkg

## 简介

A cross-platform library for verifying Authenticode signatures

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
