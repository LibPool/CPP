# kealib

> 标签: MIT, c++, conan, kealib, vcpkg

## 简介

KEALib provides an implementation of the GDAL data model using HDF5.

Conan Center 收录：C++ library providing complete access to the KEA image format.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
