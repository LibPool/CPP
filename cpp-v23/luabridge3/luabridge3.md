# luabridge3

> 标签: MIT, c++, luabridge3, vcpkg

## 简介

A lightweight, dependency-free, suitable for game development library for binding Lua to C++17

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/kunitoki/LuaBridge3
- vcpkg 端口：https://vcpkg.io/en/packages/luabridge3
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/luabridge3
