# coin-or-cbc

> 标签: EPL-2.0, c++, coin-or-cbc, vcpkg

## 简介

Cbc (Coin-or branch and cut) is an open-source mixed integer linear programming solver written in C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
