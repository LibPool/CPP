# daw-header-libraries

> 标签: BSL-1.0, c++, daw-header-libraries, vcpkg

## 简介

Set of header-only algorithms used in daw-utf8-range and daw-json-link.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
