# libe57format

> 标签: BSL-1.0, c++, conan, libe57format, vcpkg

## 简介

A library to provide read & write support for the E57 file format.

Conan Center 收录：Library for reading & writing the E57 file format

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
