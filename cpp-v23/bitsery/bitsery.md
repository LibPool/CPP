# bitsery

> 标签: bitsery, c++, vcpkg

## 简介

Header only C++ binary serialization library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
