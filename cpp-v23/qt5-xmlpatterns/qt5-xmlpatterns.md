# qt5-xmlpatterns

> 标签: c++, qt5-xmlpatterns, vcpkg

## 简介

The Qt XML Patterns module provides support for XPath, XQuery, XSLT, and XML Schema validation.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
