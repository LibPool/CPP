# rapidcsv

> 标签: BSD-3-Clause, c++, rapidcsv, vcpkg

## 简介

Rapidcsv is a C++ header-only library for CSV parsing.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/d99kris/rapidcsv/
- vcpkg 端口：https://vcpkg.io/en/packages/rapidcsv
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/rapidcsv
