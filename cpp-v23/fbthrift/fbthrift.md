# fbthrift

> 标签: Apache-2.0, c++, fbthrift, vcpkg

## 简介

Facebook's branch of Apache Thrift, including a new C++ server.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/facebook/fbthrift
- vcpkg 端口：https://vcpkg.io/en/packages/fbthrift
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/fbthrift
