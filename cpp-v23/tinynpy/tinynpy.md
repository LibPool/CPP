# tinynpy

> 标签: c++, tinynpy, vcpkg

## 简介

tiny C++ loader/exporter of python numpy array NPY/NPZ files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/tinynpy
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinynpy

## 历史版本号

- 当前版本：1.1

- 1.1
- 1.0.0#6
