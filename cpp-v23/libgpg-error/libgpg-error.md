# libgpg-error

> 标签: LGPL-2.1-or-later, c++, libgpg-error, vcpkg

## 简介

A runtime library for GnuPG and other software which likes to use it.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
