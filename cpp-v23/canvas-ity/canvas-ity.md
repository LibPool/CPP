# canvas-ity

> 标签: ISC, c++, canvas-ity, vcpkg

## 简介

A tiny, single-header <canvas>-like 2D rasterizer for C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
