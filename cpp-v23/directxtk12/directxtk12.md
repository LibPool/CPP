# directxtk12

> 标签: MIT, c++, directxtk12, vcpkg

## 简介

A collection of helper classes for writing DirectX 12 code in C++.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
