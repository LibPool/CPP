# neko-event

> 标签: MIT OR Apache-2.0, c++, conan, neko-event, vcpkg

## 简介

A modern easy to use type-safe and high-performance event handling system for C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
