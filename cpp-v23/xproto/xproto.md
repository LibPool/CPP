# xproto

> 标签: c++, vcpkg, xproto

## 简介

X Window System unified protocol definitions

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.freedesktop.org/xorg/proto/xorgproto
- vcpkg 端口：https://vcpkg.io/en/packages/xproto
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/xproto
