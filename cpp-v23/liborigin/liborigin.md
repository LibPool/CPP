# liborigin

> 标签: GPL-3.0-only, c++, liborigin, vcpkg

## 简介

A library for reading OriginLab OPJ project files.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://sourceforge.net/projects/liborigin/
- vcpkg 端口：https://vcpkg.io/en/packages/liborigin
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/liborigin
