# libplist

> 标签: LGPL-2.1-or-later, c++, libplist, vcpkg

## 简介

A library to handle Apple Property List format in binary or XML

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
