# replxx

> 标签: BSD-3-Clause, c++, conan, replxx, vcpkg

## 简介

A small, portable GNU readline replacement for Linux, Windows and MacOS which is capable of handling UTF-8 characters.

Conan Center 收录：A readline and libedit replacement that supports UTF-8,
    syntax highlighting, hints and Windows and is BSD licensed.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
