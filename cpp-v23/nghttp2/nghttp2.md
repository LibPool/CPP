# nghttp2

> 标签: MIT, c++, nghttp2, vcpkg

## 简介

Implementation of the Hypertext Transfer Protocol version 2 in C

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
