# tevclient

> 标签: c++, tevclient, vcpkg

## 简介

C++ client library for communicating to the tev image viewer

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/westlicht/tevclient
- vcpkg 端口：https://vcpkg.io/en/packages/tevclient
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tevclient
