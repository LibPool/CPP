# gst-rtsp-server

> 标签: LGPL-2.1-or-later, c++, gst-rtsp-server, vcpkg

## 简介

gst-rtsp-server is a library on top of GStreamer for building an RTSP server

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
