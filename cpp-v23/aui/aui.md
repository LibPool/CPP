# aui

> 标签: MPL-2.0, aui, c++, vcpkg

## 简介

Declarative UI toolkit for modern C++20

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/aui
