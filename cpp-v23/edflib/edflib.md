# edflib

> 标签: BSD-3-Clause, c++, edflib, vcpkg

## 简介

A C library to read/write EDF/EDF+/BDF/BDF+ files

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/edflib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/edflib
