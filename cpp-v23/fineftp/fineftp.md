# fineftp

> 标签: MIT, c++, fineftp, vcpkg

## 简介

FineFTP is a minimal FTP server library for Windows and Unix flavors.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/eclipse-ecal/fineftp-server
- vcpkg 端口：https://vcpkg.io/en/packages/fineftp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/fineftp
