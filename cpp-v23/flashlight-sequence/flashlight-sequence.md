# flashlight-sequence

> 标签: MIT, c++, flashlight-sequence, vcpkg

## 简介

Flashlight Sequence is a library containing fast implementations of sequence loss algorithms.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
