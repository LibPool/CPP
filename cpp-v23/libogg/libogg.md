# libogg

> 标签: BSD-3-Clause, c++, libogg, vcpkg

## 简介

Ogg is a multimedia container format, and the native file and stream format for the Xiph.org multimedia codecs.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.xiph.org/ogg
- vcpkg 端口：https://vcpkg.io/en/packages/libogg
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libogg
