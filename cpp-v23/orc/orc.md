# orc

> 标签: Apache-2.0, c++, conan, orc, vcpkg

## 简介

The smallest, fastest columnar storage for Hadoop workloads.

Conan Center 收录：ORC is a self-describing type-aware columnar file format designed for Hadoop workloads

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
