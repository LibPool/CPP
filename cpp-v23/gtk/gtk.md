# gtk

> 标签: LGPL-2.1-or-later AND Apache-2.0, c++, gtk, vcpkg

## 简介

Portable library for creating graphical user interfaces.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.gtk.org/
- vcpkg 端口：https://vcpkg.io/en/packages/gtk
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/gtk
