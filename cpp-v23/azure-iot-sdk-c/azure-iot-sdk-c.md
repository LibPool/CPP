# azure-iot-sdk-c

> 标签: MIT, azure-iot-sdk-c, c++, vcpkg

## 简介

A C99 SDK for connecting devices to Microsoft Azure IoT services

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
