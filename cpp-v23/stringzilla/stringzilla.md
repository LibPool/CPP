# stringzilla

> 标签: Apache-2.0, c++, conan, stringzilla, vcpkg

## 简介

StringZilla is the GodZilla of string libraries, using SIMD and SWAR to accelerate string operations on modern CPUs.

Conan Center 收录：Fastest string sort, search, split, and shuffle for long strings and multi-gigabyte files in Python and C, leveraging SIMD with Arm Neon and x86 AVX2 & AVX-512 intrinsics.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
