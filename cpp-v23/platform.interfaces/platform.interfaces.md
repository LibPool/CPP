# platform.interfaces

> 标签: Unlicense, c++, conan, platform.interfaces

## 简介

Conan Center 收录：platform.interfaces is one of the libraries of the LinksPlatform modular framework, which uses
    innovations from the C++20 standard, for easier use of static polymorphism. It also includes some auxiliary
    structures for more convenient work with containers.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
