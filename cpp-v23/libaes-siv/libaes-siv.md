# libaes-siv

> 标签: Apache-2.0, c++, libaes-siv, vcpkg

## 简介

An RFC5297-compliant C implementation of AES-SIV.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
