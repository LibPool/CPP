# caf

> 标签: BSD-3-Clause, c++, caf, conan, vcpkg

## 简介

an open source implementation of the actor model for C++ featuring lightweight & fast actor implementations, pattern matching for messages, network transparent messaging, and more.

Conan Center 收录：An open source implementation of the Actor Model in C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
