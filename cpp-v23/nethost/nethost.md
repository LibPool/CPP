# nethost

> 标签: MIT, c++, nethost, vcpkg

## 简介

Provides a set of APIs that can be used to host .NET Core (dotnet)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/dotnet/runtime/tree/main/src/native/corehost/nethost
- vcpkg 端口：https://vcpkg.io/en/packages/nethost
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/nethost
