# libpcap

> 标签: BSD-3-Clause, c++, conan, libpcap, vcpkg

## 简介

A portable C/C++ library for network traffic capture

Conan Center 收录：libpcap is an API for capturing network traffic

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
