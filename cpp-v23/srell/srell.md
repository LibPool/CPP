# srell

> 标签: BSD-2-Clause AND Unicode-3.0, c++, srell, vcpkg

## 简介

SRELL (std::regex-like library) is a regular expression template library for C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
