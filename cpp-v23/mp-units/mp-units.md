# mp-units

> 标签: MIT, c++, mp-units, vcpkg

## 简介

The quantities and units library for C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
