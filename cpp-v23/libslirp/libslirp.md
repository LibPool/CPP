# libslirp

> 标签: BSD-3-Clause, c++, libslirp, vcpkg

## 简介

libslirp is a user-mode networking library used by virtual machines, containers or various tools.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
