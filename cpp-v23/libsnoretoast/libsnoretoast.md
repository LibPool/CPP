# libsnoretoast

> 标签: c++, libsnoretoast, vcpkg

## 简介

A tool to create Windows Toast notifications and parse them on Windows 8 or later.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://invent.kde.org/libraries/snoretoast
- vcpkg 端口：https://vcpkg.io/en/packages/libsnoretoast
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libsnoretoast
