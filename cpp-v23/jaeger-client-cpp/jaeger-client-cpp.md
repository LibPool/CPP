# jaeger-client-cpp

> 标签: c++, jaeger-client-cpp, vcpkg

## 简介

C++ OpenTracing binding for Jaeger https://jaegertracing.io/

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
