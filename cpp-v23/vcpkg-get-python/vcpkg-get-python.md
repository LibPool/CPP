# vcpkg-get-python

> 标签: MIT, c++, vcpkg, vcpkg-get-python

## 简介

vcpkg 端口 vcpkg-get-python，由 vcpkg C/C++ 软件包管理器收录。

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/vcpkg-get-python
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vcpkg-get-python
