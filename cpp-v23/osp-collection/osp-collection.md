# osp-collection

> 标签: BSD-3-Clause, c++, osp-collection, vcpkg

## 简介

A C library providing data structures for efficient collection management.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
