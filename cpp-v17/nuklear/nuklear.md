# nuklear

> 标签: Unlicense OR MIT, c++, conan, nuklear, vcpkg

## 简介

This is a minimal state immediate mode graphical user interface toolkit written in ANSI C and licensed under public domain

Conan Center 收录：A single-header ANSI C immediate mode cross-platform GUI library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
