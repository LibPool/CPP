# aws-c-auth

> 标签: Apache-2.0, aws-c-auth, c++, vcpkg

## 简介

C99 library implementation of AWS client-side authentication: standard credentials providers and signing.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
