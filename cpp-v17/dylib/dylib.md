# dylib

> 标签: MIT, c++, dylib, vcpkg

## 简介

C++ cross-platform wrapper around dynamic loading of shared libraries

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/martin-olivier/dylib
- vcpkg 端口：https://vcpkg.io/en/packages/dylib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/dylib
