# libcpplocate

> 标签: MIT, c++, libcpplocate, vcpkg

## 简介

Cross-platform C++ library providing tools for applications to locate themselves, their data assets as well as dependent modules.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://cpplocate.org/

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libcpplocate
