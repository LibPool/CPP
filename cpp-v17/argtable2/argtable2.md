# argtable2

> 标签: LGPL-2.0+, LGPL-2.0-only, argtable2, c++, conan, vcpkg

## 简介

Argtable is an ANSI C library for parsing GNU style command line options with a minimum of fuss.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
