# godot-cpp

> 标签: MIT, c++, conan, godot-cpp, vcpkg

## 简介

C++ bindings for the Godot script API

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/godot-cpp
