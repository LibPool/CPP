# maddy

> 标签: MIT, c++, conan, maddy, vcpkg

## 简介

C++ Markdown to HTML header-only parser library

Conan Center 收录：open-source, maddy is a C++ Markdown to HTML header-only parser library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
