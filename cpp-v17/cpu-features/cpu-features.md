# cpu-features

> 标签: Apache-2.0, c++, cpu-features, vcpkg

## 简介

A cross-platform C library to retrieve CPU features (such as available instructions) at runtime

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/google/cpu_features
- vcpkg 端口：https://vcpkg.io/en/packages/cpu-features
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cpu-features
