# hnswlib

> 标签: Apache-2.0, c++, hnswlib, vcpkg

## 简介

Header-only library for fast approximate nearest neighbors

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/nmslib/hnswlib
