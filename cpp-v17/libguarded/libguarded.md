# libguarded

> 标签: BSD-2-Clause, c++, libguarded, vcpkg

## 简介

Header-only library for multithreaded programming.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
