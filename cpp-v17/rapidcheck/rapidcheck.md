# rapidcheck

> 标签: BSD-2-Clause, c++, conan, rapidcheck, vcpkg

## 简介

A property-based testing library for C++ (a la QuickCheck) with the goal of being simple to use with as little boilerplate as possible.

Conan Center 收录：QuickCheck clone for C++ with the goal of being simple to use with as little boilerplate as possible

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
