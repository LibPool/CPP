# fontconfig

> 标签: MIT, c++, fontconfig, vcpkg

## 简介

Library for configuring and customizing font access.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
