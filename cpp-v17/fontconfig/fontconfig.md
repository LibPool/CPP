# fontconfig

> 标签: MIT, c++, conan, fontconfig, vcpkg

## 简介

Library for configuring and customizing font access.

Conan Center 收录：Fontconfig is a library for configuring and customizing font access

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
