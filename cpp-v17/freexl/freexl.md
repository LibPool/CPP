# freexl

> 标签: MPL-1.1 OR GPL-2.0-or-later OR LGPL-2.1-or-later, c++, conan, freexl, vcpkg

## 简介

FreeXL is an open source library to extract valid data from within an Excel (.xls) spreadsheet

Conan Center 收录：FreeXL is an open source library to extract valid data

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
