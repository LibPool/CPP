# opengl

> 标签: MIT, c++, conan, opengl, vcpkg

## 简介

Open Graphics Library (OpenGL)[3][4][5] is a cross-language, cross-platform application programming interface (API) for rendering 2D and 3D vector graphics.

Conan Center 收录：cross-platform virtual conan package for the OpenGL support

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
