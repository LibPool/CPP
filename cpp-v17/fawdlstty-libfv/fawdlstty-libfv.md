# fawdlstty-libfv

> 标签: MIT, c++, fawdlstty-libfv, vcpkg

## 简介

libfv is C++20 header-only network library, support TCP/SSL/Http/websocket server and client

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
