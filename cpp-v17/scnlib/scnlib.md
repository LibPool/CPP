# scnlib

> 标签: Apache-2.0, c++, scnlib, vcpkg

## 简介

scnlib is a modern C++ library for replacing scanf and std::istream

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://scnlib.dev/
- vcpkg 端口：https://vcpkg.io/en/packages/scnlib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/scnlib
