# dukglue

> 标签: MIT, c++, dukglue, vcpkg

## 简介

A C++ binding/wrapper library for the Duktape JavaScript interpreter.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
