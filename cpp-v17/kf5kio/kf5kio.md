# kf5kio

> 标签: c++, kf5kio, vcpkg

## 简介

Network transparent access to files and data

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://invent.kde.org/frameworks/kio
- vcpkg 端口：https://vcpkg.io/en/packages/kf5kio
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/kf5kio
