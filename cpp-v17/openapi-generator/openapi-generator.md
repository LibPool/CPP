# openapi-generator

> 标签: Apache-2.0, c++, conan, openapi-generator

## 简介

Conan Center 收录：Generation of API client libraries (SDK generation), server stubs, documentation and configuration automatically given an OpenAPI Spec (v2, v3)

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
