# openslide

> 标签: LGPL-2.1, LGPL-2.1-only, c++, conan, openslide, vcpkg

## 简介

OpenSlide is a C library for reading whole slide image files (also known as virtual slides). It provides a consistent and simple API for reading files from multiple vendors.

Conan Center 收录：OpenSlide is a C library for reading whole slide image files (also known as virtual slides)

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
