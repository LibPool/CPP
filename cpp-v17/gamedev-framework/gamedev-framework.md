# gamedev-framework

> 标签: Zlib, c++, gamedev-framework, vcpkg

## 简介

gamedev-framework is a framework to build 2D games in C++17

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gamedevframework.github.io/
- vcpkg 端口：https://vcpkg.io/en/packages/gamedev-framework
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/gamedev-framework
