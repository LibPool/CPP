# minizip

> 标签: Zlib, c++, conan, minizip, vcpkg

## 简介

Minizip zip file manipulation library

Conan Center 收录：An experimental package to read and write files in .zip format, written on top of zlib

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
