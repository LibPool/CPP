# xcb-util

> 标签: c++, vcpkg, xcb-util

## 简介

C interface to the X Window System protocol, which replaces the traditional Xlib interface.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
