# libgeotiff

> 标签: MIT, c++, conan, libgeotiff, vcpkg

## 简介

Libgeotiff is an open source library on top of libtiff for reading and writing GeoTIFF information tags.

Conan Center 收录：Libgeotiff is an open source library normally hosted on top

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
