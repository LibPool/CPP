# bit7z

> 标签: MPL-2.0, bit7z, c++, vcpkg

## 简介

A C++ static library offering a clean and simple interface to the 7-zip shared libraries.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
