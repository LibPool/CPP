# ghc-filesystem

> 标签: MIT, c++, conan, ghc-filesystem, vcpkg

## 简介

An implementation of C++17 std::filesystem for C++11/C++14/C++17/C++20 on Windows, macOS, Linux and FreeBSD

Conan Center 收录：A header-only single-file std::filesystem compatible helper library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
