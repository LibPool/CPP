# rapidfuzz-cpp

> 标签: MIT, c++, rapidfuzz-cpp, vcpkg

## 简介

Rapid fuzzy string matching library for C++ using the Levenshtein Distance.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
