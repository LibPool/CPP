# mach

> 标签: MIT AND BSL-1.0, c++, mach, vcpkg

## 简介

A modern C++20 web framework designed for performance, type safety, and a great developer experience.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://machframework.dev
- vcpkg 端口：https://vcpkg.io/en/packages/mach
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mach

## 历史版本号

- 当前版本：1.0.0

- 1.0.0
