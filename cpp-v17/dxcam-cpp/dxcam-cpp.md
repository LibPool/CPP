# dxcam-cpp

> 标签: MIT, c++, dxcam-cpp, vcpkg

## 简介

A high performance screen capturing library for Windows rewriting DXcam in C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/Fidelxyz/DXCam-CPP
- vcpkg 端口：https://vcpkg.io/en/packages/dxcam-cpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/dxcam-cpp
