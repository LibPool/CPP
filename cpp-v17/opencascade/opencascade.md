# opencascade

> 标签: LGPL-2.1-only, c++, opencascade, vcpkg

## 简介

Open CASCADE Technology (OCCT) is an open-source software development platform for 3D CAD, CAM, CAE.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/Open-Cascade-SAS/OCCT
- vcpkg 端口：https://vcpkg.io/en/packages/opencascade
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/opencascade
