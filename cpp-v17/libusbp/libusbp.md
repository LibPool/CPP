# libusbp

> 标签: MIT, c++, libusbp, vcpkg

## 简介

The Pololu USB Library (also known as libusbp) is a cross-platform C library for accessing USB devices.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/pololu/libusbp
- vcpkg 端口：https://vcpkg.io/en/packages/libusbp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libusbp
