# croncpp

> 标签: MIT, c++, conan, croncpp, vcpkg

## 简介

croncpp is a C++11/14/17 header-only cross-platform library for handling CRON expressions.

Conan Center 收录：A C++11/14/17 header-only cross-platform library for handling CRON expressions

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
