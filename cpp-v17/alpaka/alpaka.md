# alpaka

> 标签: MPL-2.0, alpaka, c++, vcpkg

## 简介

The alpaka library is a header-only abstraction library for accelerator development

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
