# lionkor-commandline

> 标签: MIT, c++, lionkor-commandline, vcpkg

## 简介

A C++ commandline for use in servers and chat software. Provides very simple asynchronous input/output.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
