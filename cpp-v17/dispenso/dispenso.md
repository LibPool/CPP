# dispenso

> 标签: MIT, c++, conan, dispenso, vcpkg

## 简介

A high-performance C++ library for parallel programming with thread pools, parallel for loops, futures, task graphs, and concurrent containers

Conan Center 收录：Dispenso is a library for working with sets of tasks in parallel

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
