# globjects

> 标签: c++, globjects, vcpkg

## 简介

C++ library strictly wrapping OpenGL objects

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/cginternals/globjects
- vcpkg 端口：https://vcpkg.io/en/packages/globjects
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/globjects
