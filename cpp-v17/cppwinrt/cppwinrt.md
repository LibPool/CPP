# cppwinrt

> 标签: MIT, c++, cppwinrt, vcpkg

## 简介

C++/WinRT is a standard C++ language projection for the Windows Runtime.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/microsoft/cppwinrt
- vcpkg 端口：https://vcpkg.io/en/packages/cppwinrt
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cppwinrt
