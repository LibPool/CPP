# kealib

> 标签: MIT, c++, kealib, vcpkg

## 简介

KEALib provides an implementation of the GDAL data model using HDF5.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
