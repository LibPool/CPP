# cmocka

> 标签: Apache-2.0, c++, cmocka, conan, vcpkg

## 简介

An elegant unit testing framework for C with support for mock objects

Conan Center 收录：A unit testing framework for C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
