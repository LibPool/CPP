# yubico-piv-tool

> 标签: BSD-2-Clause, c++, vcpkg, yubico-piv-tool

## 简介

YubiKey PIV library (libykpiv) for interacting with the PIV application on a YubiKey

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
