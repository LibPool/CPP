# fluidlite

> 标签: LGPL-2.1-or-later, c++, fluidlite, vcpkg

## 简介

FluidLite is a very light version of FluidSynth designed to be hardware, platform and external dependency independant.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/divideconcept/FluidLite
- vcpkg 端口：https://vcpkg.io/en/packages/fluidlite
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/fluidlite
