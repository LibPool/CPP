# libusb-win32

> 标签: LGPL-3.0-only, c++, libusb-win32, vcpkg

## 简介

Allows user space applications to access many USB device on Windows.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/mcuee/libusb-win32
- vcpkg 端口：https://vcpkg.io/en/packages/libusb-win32
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libusb-win32
