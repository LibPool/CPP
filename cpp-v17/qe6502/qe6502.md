# qe6502

> 标签: MIT, c++, qe6502, vcpkg

## 简介

Cycle-oriented MOS 6502/65C02 CPU emulation core with C and C++ APIs

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
