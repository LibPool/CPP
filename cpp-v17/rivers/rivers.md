# rivers

> 标签: BSL-1.0, c++, rivers, vcpkg

## 简介

A C++ internal iteration library based loosely on Java Streams

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
