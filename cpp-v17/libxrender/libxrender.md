# libxrender

> 标签: c++, libxrender, vcpkg

## 简介

library for the Render Extension to the X11 protocol

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.freedesktop.org/xorg/lib/libxrender
- vcpkg 端口：https://vcpkg.io/en/packages/libxrender
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libxrender
