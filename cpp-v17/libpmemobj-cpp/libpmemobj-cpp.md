# libpmemobj-cpp

> 标签: c++, libpmemobj-cpp, vcpkg

## 简介

C++ bindings for libpmemobj (https://github.com/pmem/pmdk)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
