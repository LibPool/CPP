# cppadcodegen

> 标签: EPL-1.0 OR GPL-3.0-only, c++, cppadcodegen, vcpkg

## 简介

Source code generation for automatic differentiation using operator overloading (extension of CppAD)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/joaoleal/CppADCodeGen
- vcpkg 端口：https://vcpkg.io/en/packages/cppadcodegen
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cppadcodegen
