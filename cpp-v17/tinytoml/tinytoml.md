# tinytoml

> 标签: c++, tinytoml, vcpkg

## 简介

A header only C++11 library for parsing TOML.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/mayah/tinytoml
- vcpkg 端口：https://vcpkg.io/en/packages/tinytoml
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinytoml
