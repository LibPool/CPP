# ctbench

> 标签: MIT, c++, ctbench, vcpkg

## 简介

Compiler-assisted variable size benchmarking for the study of C++ metaprogram compile times.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/JPenuchot/ctbench
- vcpkg 端口：https://vcpkg.io/en/packages/ctbench
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/ctbench
