# chaiscript

> 标签: c++, chaiscript, vcpkg

## 简介

Embedded Scripting Language Designed for C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://github.com/ChaiScript/ChaiScript
- vcpkg 端口：https://vcpkg.io/en/packages/chaiscript
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/chaiscript
