# cpputest

> 标签: BSD-3-Clause, c++, cpputest, vcpkg

## 简介

CppUTest unit testing and mocking framework for C/C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/cpputest
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cpputest
