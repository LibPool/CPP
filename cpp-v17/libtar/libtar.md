# libtar

> 标签: c++, libtar, vcpkg

## 简介

libtar - C library for manipulating tar files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
