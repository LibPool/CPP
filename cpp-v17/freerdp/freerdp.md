# freerdp

> 标签: Apache-2.0 AND BSD-3-Clause, c++, freerdp, vcpkg

## 简介

A free implementation of the Remote Desktop Protocol (RDP)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/freerdp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/freerdp
