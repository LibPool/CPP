# eve

> 标签: BSL-1.0, c++, conan, eve, vcpkg

## 简介

EVE - the Expressive Vector Engine : C++20 SIMD Programming Library

Conan Center 收录：EVE is a C++20 and onward implementation of a type based wrapper around SIMD extensions sets for most current architectures.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
