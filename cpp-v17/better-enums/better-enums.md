# better-enums

> 标签: BSD-2-Clause, better-enums, c++, vcpkg

## 简介

C++ compile-time enum to string, iteration, in a single header file.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
