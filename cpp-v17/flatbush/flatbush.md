# flatbush

> 标签: MIT, c++, conan, flatbush, vcpkg

## 简介

A C++11 header-only single file port of Flatbush

Conan Center 收录：Flatbush for C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
