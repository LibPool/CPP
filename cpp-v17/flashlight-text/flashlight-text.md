# flashlight-text

> 标签: MIT, c++, flashlight-text, vcpkg

## 简介

Flashlight Text is a library for tokenization, beam search, and text processing.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/flashlight/text
- vcpkg 端口：https://vcpkg.io/en/packages/flashlight-text
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/flashlight-text
