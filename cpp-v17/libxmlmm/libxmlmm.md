# libxmlmm

> 标签: MIT, c++, libxmlmm, vcpkg

## 简介

Libxmlmm is a C++ wrapper for libxml 2.0 that only relies on standard C++ and libxml2.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/rioki/libxmlmm
- vcpkg 端口：https://vcpkg.io/en/packages/libxmlmm
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libxmlmm
