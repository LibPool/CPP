# glui

> 标签: c++, glui, vcpkg

## 简介

GLUI is a GLUT-based C++ user interface library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/libglui/glui
- vcpkg 端口：https://vcpkg.io/en/packages/glui
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/glui
