# nyan-lang

> 标签: LGPL-3.0-or-later, c++, nyan-lang, vcpkg

## 简介

nyan is a data description language, It is a mixture of python, json, patch, wml, yaml and some new ideas.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/SFTtech/nyan
- vcpkg 端口：https://vcpkg.io/en/packages/nyan-lang
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/nyan-lang
