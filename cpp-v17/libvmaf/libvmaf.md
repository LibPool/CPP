# libvmaf

> 标签: BSD-2-Clause-Patent, c++, libvmaf, vcpkg

## 简介

libvmaf is a library developed by Netflix to compute the VMAF (Video Multi-Method Assessment Fusion) metric.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/Netflix/vmaf
- vcpkg 端口：https://vcpkg.io/en/packages/libvmaf
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libvmaf
