# trantor

> 标签: BSD-2-Clause, BSD-3-Clause, c++, conan, trantor, vcpkg

## 简介

A non-blocking I/O cross-platform TCP network library, using C++14

Conan Center 收录：a non-blocking I/O tcp network lib based on c++14/17

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
