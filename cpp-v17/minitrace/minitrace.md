# minitrace

> 标签: MIT, c++, conan, minitrace, vcpkg

## 简介

Simple C/C++ library for producing JSON traces suitable for Chrome's built-in trace viewer.

Conan Center 收录：Simple C/C++ library for producing JSON traces suitable for Chrome's built-in trace viewer (about:tracing).
