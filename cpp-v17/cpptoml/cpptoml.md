# cpptoml

> 标签: MIT, c++, cpptoml, vcpkg

## 简介

A header-only library for parsing TOML configuration files.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/chadaustin/cpptoml
- vcpkg 端口：https://vcpkg.io/en/packages/cpptoml
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cpptoml
