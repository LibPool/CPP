# matchit

> 标签: Apache-2.0, c++, matchit, vcpkg

## 简介

matchit is a pattern matching library for C++17 with macro-free APIs

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
