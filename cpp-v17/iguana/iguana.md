# iguana

> 标签: Apache-2.0, c++, iguana, vcpkg

## 简介

Header-only C++ serialization library used by Cinatra.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/qicosmos/iguana
- vcpkg 端口：https://vcpkg.io/en/packages/iguana
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/iguana
