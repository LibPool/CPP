# mtdev

> 标签: MIT, c++, conan, mtdev

## 简介

Conan Center 收录：The mtdev library transforms all variants of kernel MT events to the slotted type B protocol.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
