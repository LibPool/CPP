# refl-cpp

> 标签: MIT, c++, conan, refl-cpp, vcpkg

## 简介

Static reflection for C++17 (compile-time enumeration, attributes, proxies, overloads, template functions, metaprogramming).

Conan Center 收录：A modern compile-time reflection library for C++ with support for overloads, templates, attributes and proxies

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
