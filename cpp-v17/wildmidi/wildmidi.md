# wildmidi

> 标签: LGPL-3.0-only, c++, conan, vcpkg, wildmidi

## 简介

MIDI software synthesizer library.

Conan Center 收录：WildMIDI is a simple software midi player which has a core softsynth library that can be used in other applications.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
