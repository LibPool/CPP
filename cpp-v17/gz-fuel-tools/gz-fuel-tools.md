# gz-fuel-tools

> 标签: c++, gz-fuel-tools, vcpkg

## 简介

Tools for using fuel API to download robot models

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gazebosim.org/libs/fuel_tools
- vcpkg 端口：https://vcpkg.io/en/packages/gz-fuel-tools
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/gz-fuel-tools
