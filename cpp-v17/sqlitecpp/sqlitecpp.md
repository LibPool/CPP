# sqlitecpp

> 标签: MIT, c++, sqlitecpp, vcpkg

## 简介

SQLiteC++ (SQLiteCpp) is a smart and easy to use C++ SQLite3 wrapper.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/SRombauts/SQLiteCpp
- vcpkg 端口：https://vcpkg.io/en/packages/sqlitecpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/sqlitecpp
