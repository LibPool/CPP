# vcpkg-tool-nodejs

> 标签: c++, vcpkg, vcpkg-tool-nodejs

## 简介

C++ 库 vcpkg-tool-nodejs，由软件包管理器收录。

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/vcpkg-tool-nodejs
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vcpkg-tool-nodejs
