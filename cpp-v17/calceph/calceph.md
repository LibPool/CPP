# calceph

> 标签: CECILL-2.1 OR CECILL-B OR CECILL-C, c++, calceph, conan, vcpkg

## 简介

C library to access the binary planetary ephemeris files.

Conan Center 收录：C Library designed to access the binary planetary ephemeris

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
