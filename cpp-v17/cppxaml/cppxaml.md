# cppxaml

> 标签: MIT, c++, cppxaml, vcpkg

## 简介

CppXaml is a library to facilitate usage of the XAML UI framework in C++ Windows apps.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
