# sfgui

> 标签: Zlib, c++, sfgui, vcpkg

## 简介

Simple and Fast Graphical User Interface Library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/TankOs/SFGUI
- vcpkg 端口：https://vcpkg.io/en/packages/sfgui
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/sfgui
