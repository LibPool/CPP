# nanogui

> 标签: BSD-3-Clause, c++, nanogui, vcpkg

## 简介

NanoGUI is a minimalistic cross-platform widget library for OpenGL 3.x or higher.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
