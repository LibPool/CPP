# spix

> 标签: MIT, c++, conan, spix, vcpkg

## 简介

A minimally invasive UI testing library for Qt/QML applications. Control your application and verify its behavior using a simple C++ API.

Conan Center 收录：UI test automation library for QtQuick/QML Apps

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
