# aws-c-compression

> 标签: Apache-2.0, aws-c-compression, c++, conan, vcpkg

## 简介

C99 implementation of huffman encoding/decoding

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
