# json5-parser

> 标签: c++, json5-parser, vcpkg

## 简介

An enhancement of the JSON Spirit C++ library to understand json5.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
