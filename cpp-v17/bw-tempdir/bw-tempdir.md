# bw-tempdir

> 标签: MIT, bw-tempdir, c++, vcpkg

## 简介

TempDir: Simplified Temporary Directory for C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://github.com/bw-hro/TempDir
- vcpkg 端口：https://vcpkg.io/en/packages/bw-tempdir
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/bw-tempdir
