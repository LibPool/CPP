# cppdap

> 标签: Apache-2.0, c++, conan, cppdap, vcpkg

## 简介

A C++11 library ("SDK") implementation of the Debug Adapter Protocol, providing an API for implementing a DAP client or server.

Conan Center 收录：Debug Adapter Protocol SDK

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
