# simpleini

> 标签: MIT, c++, simpleini, vcpkg

## 简介

Cross-platform C++ library providing a simple API to read and write INI-style configuration files

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/brofield/simpleini
- vcpkg 端口：https://vcpkg.io/en/packages/simpleini
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/simpleini
