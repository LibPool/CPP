# qoixx

> 标签: MIT, c++, conan, qoixx, vcpkg

## 简介

Single Header Quite Fast QOI(Quite OK Image Format) Implementation written in C++20

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
