# fdlibm

> 标签: c++, fdlibm, vcpkg

## 简介

FDLIBM (Freely Distributable LIBM) is a C math library for machines that support IEEE 754 floating-point arithmetic

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/fdlibm
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/fdlibm
