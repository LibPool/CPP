# pipewire

> 标签: MIT, c++, conan, pipewire, vcpkg

## 简介

Low-latency audio/video router and processor. This port only builds the client library, not the server.

Conan Center 收录：PipeWire is a server and user space API to deal with multimedia pipelines.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
