# vlpp

> 标签: c++, vcpkg, vlpp

## 简介

Common C++ construction, including string operation / generic container / linq / General-LR parser generator / multithreading / reflection for C++ / etc

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
