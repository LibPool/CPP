# tinyxml2

> 标签: Zlib, c++, tinyxml2, vcpkg

## 简介

A simple, small, efficient, C++ XML parser

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
