# tinyproto

> 标签: GPL-3.0-or-later, c++, tinyproto, vcpkg

## 简介

Tiny Software Protocol for communication over UART, SPI, etc

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/lexus2k/tinyproto
- vcpkg 端口：https://vcpkg.io/en/packages/tinyproto
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinyproto
