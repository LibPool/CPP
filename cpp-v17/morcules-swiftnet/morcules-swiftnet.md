# morcules-swiftnet

> 标签: Apache-2.0, c++, morcules-swiftnet, vcpkg

## 简介

SwiftNet is a C networking library built using pcap, providing a clean and readable API.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/morcules/SwiftNet
- vcpkg 端口：https://vcpkg.io/en/packages/morcules-swiftnet
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/morcules-swiftnet
