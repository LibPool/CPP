# kfr

> 标签: c++, kfr, vcpkg

## 简介

Fast, modern C++ DSP framework.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.kfr.dev/
- vcpkg 端口：https://vcpkg.io/en/packages/kfr
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/kfr

## 获取地址

vcpkg 安装：`vcpkg install kfr`
