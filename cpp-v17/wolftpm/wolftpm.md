# wolftpm

> 标签: GPL-3.0-or-later, c++, vcpkg, wolftpm

## 简介

TPM library used with wolfSSL library for many platforms

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://wolfssl.com
- vcpkg 端口：https://vcpkg.io/en/packages/wolftpm
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/wolftpm
