# ada-idna

> 标签: Apache-2.0 AND MIT, ada-idna, c++, vcpkg

## 简介

C++ library implementing the to_ascii and to_unicode functions from the Unicode Technical Standard.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
