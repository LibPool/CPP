# libplist

> 标签: LGPL-2.1, LGPL-2.1-or-later, c++, conan, libplist, vcpkg

## 简介

A library to handle Apple Property List format in binary or XML

Conan Center 收录：A small portable C library to handle Apple Property List files in binary, XML, JSON, or OpenStep format.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
