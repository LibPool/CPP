# sheenbidi

> 标签: Apache-2.0, c++, sheenbidi, vcpkg

## 简介

SheenBidi is a lightweight, fast and stable implementation of the Unicode Bidirectional Algorithm.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
