# liberasurecode

> 标签: BSD-2-Clause, c++, liberasurecode, vcpkg

## 简介

Erasure Code API library written in C with pluggable Erasure Code backends. Mirror of code maintained at opendev.org.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/openstack/liberasurecode
- vcpkg 端口：https://vcpkg.io/en/packages/liberasurecode
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/liberasurecode
