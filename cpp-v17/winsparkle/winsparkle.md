# winsparkle

> 标签: MIT, c++, vcpkg, winsparkle

## 简介

WinSparkle is an easy-to-use software update library for Windows developers.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
