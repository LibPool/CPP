# liblsl

> 标签: MIT, c++, liblsl, vcpkg

## 简介

C++ lsl library for multi-modal time-synched data transmission over the local network

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
