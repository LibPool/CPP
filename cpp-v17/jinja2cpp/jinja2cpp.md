# jinja2cpp

> 标签: MIT, c++, conan, jinja2cpp

## 简介

Conan Center 收录：Jinja2 C++ (and for C++) almost full-conformance template engine implementation

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
