# gainput

> 标签: MIT, c++, conan, gainput, vcpkg

## 简介

Gainput is a multiplatform C++ input library, supporting mouse, keyboard and controllers

Conan Center 收录：Cross-platform C++ input library supporting gamepads, keyboard, mouse, touch.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
