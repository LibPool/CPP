# pcre2

> 标签: BSD-3-Clause, c++, conan, pcre2, vcpkg

## 简介

Regular Expression pattern matching using the same syntax and semantics as Perl 5.

Conan Center 收录：Perl Compatible Regular Expressions

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
