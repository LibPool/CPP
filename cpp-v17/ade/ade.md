# ade

> 标签: Apache-2.0, ade, c++, vcpkg

## 简介

ADE Framework is a graph construction, manipulation, and processing framework. ADE Framework is suitable for organizing data flow processing and execution.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/opencv/ade
- vcpkg 端口：https://vcpkg.io/en/packages/ade
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/ade
