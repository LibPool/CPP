# zeroc-ice

> 标签: c++, vcpkg, zeroc-ice

## 简介

Comprehensive RPC framework with support for C++, CSharp, Java, JavaScript, Python and more.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/zeroc-ice
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/zeroc-ice
