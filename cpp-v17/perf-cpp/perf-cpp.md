# perf-cpp

> 标签: Apache-2.0, c++, conan, perf-cpp, vcpkg

## 简介

Lightweight C++17 library for recording and sampling hardware performance counters directly from C++ applications, using the Linux perf subsystem.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
