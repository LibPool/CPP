# zstr

> 标签: MIT, c++, vcpkg, zstr

## 简介

This C++ header-only library enables the use of C++ standard iostreams to access ZLib-compressed streams.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
