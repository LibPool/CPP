# vsg

> 标签: MIT, c++, vcpkg, vsg

## 简介

A modern, cross platform, high performance scene graph library built upon Vulkan.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://www.vulkanscenegraph.org/
- vcpkg 端口：https://vcpkg.io/en/packages/vsg
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vsg
