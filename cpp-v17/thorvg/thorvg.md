# thorvg

> 标签: MIT, c++, conan, thorvg, vcpkg

## 简介

ThorVG is a platform-independent portable library for drawing vector-based scenes and animations

Conan Center 收录：ThorVG is a platform-independent portable library that allows for drawing vector-based scenes and animations.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
