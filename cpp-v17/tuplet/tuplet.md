# tuplet

> 标签: BSL-1.0, c++, conan, tuplet, vcpkg

## 简介

A Lightweight Tuple Library for Modern C++

Conan Center 收录：A fast, simple tuple implementation that implements tuple as an aggregate

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
