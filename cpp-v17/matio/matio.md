# matio

> 标签: BSD-2-Clause, c++, conan, matio, vcpkg

## 简介

MATLAB MAT File I/O Library

Conan Center 收录：Matio is a C library for reading and writing binary MATLAB MAT files.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
