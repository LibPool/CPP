# blingfire

> 标签: MIT, blingfire, c++, vcpkg

## 简介

BlingFire is a lightning fast Finite State machine and REgular expression manipulation library.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/blingfire
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/blingfire
