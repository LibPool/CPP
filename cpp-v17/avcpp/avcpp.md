# avcpp

> 标签: LGPL-2.1-only OR BSD-3-Clause, avcpp, c++, vcpkg

## 简介

Wrapper for the FFmpeg that simplify usage it from C++ projects.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/h4tr3d/avcpp
- vcpkg 端口：https://vcpkg.io/en/packages/avcpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/avcpp
