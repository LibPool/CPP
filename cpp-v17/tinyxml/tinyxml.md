# tinyxml

> 标签: Zlib, c++, conan, tinyxml, vcpkg

## 简介

A simple, small, minimal, C++ XML parser that can be easily integrating into other programs.

Conan Center 收录：TinyXML is a simple, small, C++ XML parser that can be easily integrated into other programs.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
