# tinyxml

> 标签: c++, tinyxml, vcpkg

## 简介

A simple, small, minimal, C++ XML parser that can be easily integrating into other programs.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://sourceforge.net/projects/tinyxml/
- vcpkg 端口：https://vcpkg.io/en/packages/tinyxml
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinyxml
