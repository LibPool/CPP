# ffmpeg-bin2c

> 标签: MIT, c++, ffmpeg-bin2c, vcpkg

## 简介

Host tool bin2c for FFmpeg build

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
