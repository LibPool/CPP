# apr

> 标签: Apache-2.0, apr, c++, conan, vcpkg

## 简介

The Apache Portable Runtime (APR) is a C library that forms a system portability layer that covers many operating systems.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
