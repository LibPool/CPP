# at-spi2-core

> 标签: LGPL-2.1-or-later, at-spi2-core, c++, conan, vcpkg

## 简介

Base DBus XML interfaces for accessibility, the accessibility registry daemon, and atspi library.

Conan Center 收录：It provides a Service Provider Interface for the Assistive Technologies available on the GNOME platform and a library against which applications can be linked

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
