# lightningscanner

> 标签: MIT, c++, lightningscanner, vcpkg

## 简介

A lightning-fast memory signature/pattern scanner, capable of scanning gigabytes of data per second.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
