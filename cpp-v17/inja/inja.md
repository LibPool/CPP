# inja

> 标签: MIT, c++, conan, inja, vcpkg

## 简介

Inja - A Template Engine for Modern C++

Conan Center 收录：Inja is a template engine for modern C++, loosely inspired by jinja for python

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
