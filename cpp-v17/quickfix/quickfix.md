# quickfix

> 标签: c++, quickfix, vcpkg

## 简介

QuickFIX is a free and open source implementation of the FIX protocol.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
