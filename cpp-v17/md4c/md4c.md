# md4c

> 标签: MIT, c++, conan, md4c, vcpkg

## 简介

MD4C is a C library providing a Markdown parser.

Conan Center 收录：C Markdown parser. Fast. SAX-like interface. Compliant to CommonMark specification.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
