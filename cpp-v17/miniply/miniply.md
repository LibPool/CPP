# miniply

> 标签: MIT, c++, miniply, vcpkg

## 简介

A fast and easy-to-use PLY parsing library in a single c++11 header and cpp file

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
