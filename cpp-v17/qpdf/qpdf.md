# qpdf

> 标签: Apache-2.0, Apache-2.0 AND MIT, c++, conan, qpdf, vcpkg

## 简介

A content-preserving PDF document transformer

Conan Center 收录：QPDF is a command-line tool and C++ library that performs content-preserving transformations on PDF files.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
