# quaternions

> 标签: MIT, c++, conan, quaternions, vcpkg

## 简介

A C++11 library to work with quaternions, as a single header file.

Conan Center 收录：A blazingly fast C++ library to work with quaternions.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
