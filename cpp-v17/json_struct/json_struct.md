# json_struct

> 标签: MIT, c++, conan, json_struct

## 简介

Conan Center 收录：json_struct is a single header only C++ library for parsing JSON directly to C++ structs and vice versa

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
