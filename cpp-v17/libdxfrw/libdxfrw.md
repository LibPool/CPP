# libdxfrw

> 标签: GPL-2.0-only, c++, libdxfrw, vcpkg

## 简介

libdxfrw is a free C++ library to read and write DXF files in both formats, ascii and binary form. It also has rudimentary capabilities to read DWG files.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/libdxfrw
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libdxfrw
