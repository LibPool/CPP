# xtensor-io

> 标签: c++, vcpkg, xtensor-io

## 简介

xtensor plugin to read and write images, audio files, numpy (compressed) npz and HDF5

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/xtensor-stack/xtensor-io
- vcpkg 端口：https://vcpkg.io/en/packages/xtensor-io
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/xtensor-io
