# libxmlpp

> 标签: LGPL-2.1, LGPL-2.1-or-later, c++, conan, libxmlpp, vcpkg

## 简介

A C++ wrapper for the libxml XML parser library.

Conan Center 收录：libxml++ (a.k.a. libxmlplusplus) provides a C++ interface to XML files

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
