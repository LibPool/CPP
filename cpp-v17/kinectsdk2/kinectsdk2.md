# kinectsdk2

> 标签: c++, kinectsdk2, vcpkg

## 简介

Kinect for Windows SDK for Kinect v2 sensor.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/kinectsdk2
