# freetype-gl

> 标签: c++, freetype-gl, vcpkg

## 简介

OpenGL text using one vertex buffer, one texture and FreeType

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/rougier/freetype-gl
- vcpkg 端口：https://vcpkg.io/en/packages/freetype-gl
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/freetype-gl
