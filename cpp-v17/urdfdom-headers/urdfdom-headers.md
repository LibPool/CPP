# urdfdom-headers

> 标签: BSD-2-Clause, c++, urdfdom-headers, vcpkg

## 简介

The URDF (U-Robot Description Format) headers provides core data structure headers for URDF.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
