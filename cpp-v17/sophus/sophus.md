# sophus

> 标签: MIT, c++, conan, sophus, vcpkg

## 简介

Lie group library for C++

Conan Center 收录：C++ implementation of Lie Groups using Eigen.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
