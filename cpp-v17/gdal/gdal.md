# gdal

> 标签: MIT, c++, conan, gdal, vcpkg

## 简介

The Geographic Data Abstraction Library for reading and writing geospatial raster and vector data

Conan Center 收录：GDAL is an open source X/MIT licensed translator library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
