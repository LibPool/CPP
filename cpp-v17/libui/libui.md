# libui

> 标签: MIT, c++, conan, libui, vcpkg

## 简介

Simple and portable (but not inflexible) native GUI library in C.

Conan Center 收录：Simple and portable GUI library in C that uses the native GUI technologies of each platform it supports.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
