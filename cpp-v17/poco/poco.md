# poco

> 标签: BSD-3-Clause AND BSL-1.0 AND MIT AND Zlib, BSL-1.0, c++, conan, poco, vcpkg

## 简介

Modern, powerful open source C++ class libraries for building network and internet-based applications that run on desktop, server, mobile and embedded systems.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
