# mujs

> 标签: ISC AND Unicode-3.0, c++, mujs, vcpkg

## 简介

An embeddable Javascript interpreter in C

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://mujs.com/
- vcpkg 端口：https://vcpkg.io/en/packages/mujs
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mujs
