# libdotconf

> 标签: LGPL-2.1-only, c++, libdotconf, vcpkg

## 简介

dot.conf configuration file parser

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
