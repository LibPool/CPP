# tvision

> 标签: MIT, c++, tvision, vcpkg

## 简介

A modern port of Turbo Vision 2.0, the classical framework for text-based user interfaces.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
