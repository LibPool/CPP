# proxy

> 标签: MIT, c++, proxy, vcpkg

## 简介

A single-header C++20 library that facilitates runtime polymorphism.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
