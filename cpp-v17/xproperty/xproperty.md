# xproperty

> 标签: c++, vcpkg, xproperty

## 简介

Traitlets-like C++ properties and implementation of the observer pattern

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
