# lib3mf

> 标签: BSD-2-Clause, c++, lib3mf, vcpkg

## 简介

lib3mf is an implementation of the 3D Manufacturing Format file standard

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
