# plibsys

> 标签: c++, plibsys, vcpkg

## 简介

Highly portable C system library: threads and synchronization, sockets, IPC, data structures and more.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/saprykin/plibsys
- vcpkg 端口：https://vcpkg.io/en/packages/plibsys
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/plibsys
