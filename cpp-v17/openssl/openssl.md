# openssl

> 标签: Apache-2.0, OpenSSL, c++, conan, openssl, vcpkg

## 简介

OpenSSL is an open source project that provides a robust, commercial-grade, and full-featured toolkit for the Transport Layer Security (TLS) and Secure Sockets Layer (SSL) protocols. It is also a general-purpose cryptography library.

Conan Center 收录：A toolkit for the Transport Layer Security (TLS) and Secure Sockets Layer (SSL) protocols

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
