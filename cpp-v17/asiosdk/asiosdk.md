# asiosdk

> 标签: asiosdk, c++, vcpkg

## 简介

ASIO is a low latency audio API from Steinberg.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.steinberg.net/developers/asiosdk-open/
- vcpkg 端口：https://vcpkg.io/en/packages/asiosdk
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/asiosdk
