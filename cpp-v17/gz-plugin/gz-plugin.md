# gz-plugin

> 标签: c++, gz-plugin, vcpkg

## 简介

Library for registering plugin libraries and dynamically loading them at runtime

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://ignitionrobotics.org/libs/plugin
- vcpkg 端口：https://vcpkg.io/en/packages/gz-plugin
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/gz-plugin
