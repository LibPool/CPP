# neko-network

> 标签: MIT OR Apache-2.0, c++, neko-network, vcpkg

## 简介

Neko Network is a modern, easy-to-use, and efficient C++20 network library built on top of libcurl.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
