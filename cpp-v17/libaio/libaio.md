# libaio

> 标签: LGPL-2.1, LGPL-2.1-only, c++, conan, libaio, vcpkg

## 简介

The Linux-native asynchronous I/O facility

Conan Center 收录：libaio provides the Linux-native API for async I/O.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
