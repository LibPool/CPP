# libevhtp

> 标签: c++, libevhtp, vcpkg

## 简介

Libevhtp was created as a replacement API for Libevent's current HTTP API.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
