# stdgpu

> 标签: Apache-2.0, c++, conan, stdgpu, vcpkg

## 简介

Open-source library providing generic GPU data structures for fast and reliable data management

Conan Center 收录：Efficient STL-like Data Structures on the GPU

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
