# libgnutls

> 标签: c++, libgnutls, vcpkg

## 简介

A secure communications library implementing the SSL, TLS and DTLS protocols.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
