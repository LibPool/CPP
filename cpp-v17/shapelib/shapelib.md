# shapelib

> 标签: LGPL-2.0-or-later, MIT OR LGPL-2.0-or-later, c++, conan, shapelib, vcpkg

## 简介

Shapefile C Library is simple C API for reading and writing ESRI Shapefiles

Conan Center 收录：C library for reading and writing ESRI Shapefiles

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
