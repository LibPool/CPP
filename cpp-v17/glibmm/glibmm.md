# glibmm

> 标签: LGPL-2.1, LGPL-2.1-or-later, c++, conan, glibmm, vcpkg

## 简介

This is glibmm, a C++ API for parts of glib that are useful for C++.

Conan Center 收录：glibmm is a C++ API for parts of glib that are useful for C++.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
