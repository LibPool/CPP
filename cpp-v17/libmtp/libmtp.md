# libmtp

> 标签: LGPL-2.1-or-later, c++, libmtp, vcpkg

## 简介

A library to access MTP (Media Transfer Protocol) devices

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://sourceforge.net/projects/libmtp/
- vcpkg 端口：https://vcpkg.io/en/packages/libmtp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libmtp
