# mlpack

> 标签: BSD-3-Clause, c++, conan, mlpack, vcpkg

## 简介

mlpack is an intuitive, fast, and flexible header-only C++ machine learning library with bindings to other languages.

Conan Center 收录：mlpack: a fast, header-only C++ machine learning library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
