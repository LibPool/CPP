# morton-nd

> 标签: c++, morton-nd, vcpkg

## 简介

header-only constexpr library for fast Morton encoding/decoding in N dimensions.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
