# glbinding

> 标签: MIT, c++, conan, glbinding, vcpkg

## 简介

glbinding is an MIT licensed, cross-platform C++ binding for the OpenGL API

Conan Center 收录：A C++ binding for the OpenGL API, generated using the gl.xml specification.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
