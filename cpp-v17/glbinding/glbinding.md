# glbinding

> 标签: MIT, c++, glbinding, vcpkg

## 简介

glbinding is an MIT licensed, cross-platform C++ binding for the OpenGL API

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/cginternals/glbinding
- vcpkg 端口：https://vcpkg.io/en/packages/glbinding
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/glbinding
