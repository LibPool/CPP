# readline-win32

> 标签: GPL-2.0, c++, readline-win32, vcpkg

## 简介

Implementation of readline for Windows Desktop

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
