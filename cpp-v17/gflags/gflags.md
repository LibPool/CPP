# gflags

> 标签: BSD-3-Clause, c++, conan, gflags, vcpkg

## 简介

A C++ library that implements commandline flags processing

Conan Center 收录：The gflags package contains a C++ library that implements commandline flags processing

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
