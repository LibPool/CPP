# tesults-gtest

> 标签: MIT, c++, tesults-gtest, vcpkg

## 简介

Google Test event listener for reporting test results to Tesults

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
