# sdl2-ttf

> 标签: Zlib, c++, sdl2-ttf, vcpkg

## 简介

A library for rendering TrueType fonts with SDL

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.libsdl.org/projects/SDL_ttf/
- vcpkg 端口：https://vcpkg.io/en/packages/sdl2-ttf
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/sdl2-ttf
