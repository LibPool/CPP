# sparsepp

> 标签: c++, sparsepp, vcpkg

## 简介

A fast, memory efficient hash map for C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/sparsepp
