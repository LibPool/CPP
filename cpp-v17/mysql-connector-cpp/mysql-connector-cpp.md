# mysql-connector-cpp

> 标签: c++, mysql-connector-cpp, vcpkg

## 简介

This is a release of MySQL Connector/C++, the C++ interface for communicating with MySQL servers.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
