# d3d12-memory-allocator

> 标签: MIT, c++, conan, d3d12-memory-allocator, vcpkg

## 简介

Easy to integrate D3d12 memory allocation library from GPUOpen

Conan Center 收录：The open source memory allocation library for the D3D12 API

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
