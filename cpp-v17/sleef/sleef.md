# sleef

> 标签: BSL-1.0, c++, conan, sleef, vcpkg

## 简介

SIMD Library for Evaluating Elementary Functions, vectorized libm and DFT

Conan Center 收录：SLEEF is a library that implements vectorized versions of C standard math functions.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
