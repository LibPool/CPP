# veigar

> 标签: GPL-3.0-or-later, c++, vcpkg, veigar

## 简介

Cross platform RPC library using shared memory.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
