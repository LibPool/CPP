# qpoases

> 标签: LGPL-2.1, LGPL-2.1-only, c++, conan, qpoases, vcpkg

## 简介

Open-source C++ implementation of the online active set strategy for quadratic programming

Conan Center 收录：Open-source C++ implementation of the recently proposed online active set strategy.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
