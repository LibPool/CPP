# simdjson

> 标签: (Apache-2.0 OR MIT) AND BSL-1.0 AND BSD-3-Clause, c++, conan, simdjson, vcpkg

## 简介

An extremely fast JSON library that can parse gigabytes of JSON per second

Conan Center 收录：Parsing gigabytes of JSON per second

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
