# liboqs

> 标签: MIT, c++, liboqs, vcpkg

## 简介

open source C library for quantum-safe cryptographic algorithms.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://openquantumsafe.org/
- vcpkg 端口：https://vcpkg.io/en/packages/liboqs
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/liboqs
