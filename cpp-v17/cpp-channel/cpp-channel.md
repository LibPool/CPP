# cpp-channel

> 标签: MIT, c++, cpp-channel, vcpkg

## 简介

C++11 thread-safe container for sharing data between threads (synchronized queue)

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/andreiavrammsd/cpp-channel
- vcpkg 端口：https://vcpkg.io/en/packages/cpp-channel
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cpp-channel
