# openal-soft

> 标签: LGPL-2.0-or-later, c++, conan, openal-soft, vcpkg

## 简介

OpenAL Soft is an LGPL-licensed, cross-platform, software implementation of the OpenAL 3D audio API.

Conan Center 收录：OpenAL Soft is a software implementation of the OpenAL 3D audio API.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
