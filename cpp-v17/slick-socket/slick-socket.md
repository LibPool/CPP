# slick-socket

> 标签: MIT, c++, slick-socket, vcpkg

## 简介

A C++20 networking library providing cross-platform TCP and UDP multicast communication.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
