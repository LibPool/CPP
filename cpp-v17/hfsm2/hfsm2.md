# hfsm2

> 标签: MIT, c++, conan, hfsm2, vcpkg

## 简介

Header-only heriarchical FSM framework in C++11, with fully statically-defined structure (no dynamic allocations), built with variadic templates.

Conan Center 收录：High-Performance Hierarchical Finite State Machine Framework

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
