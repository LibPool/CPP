# libe57format

> 标签: BSL-1.0, c++, libe57format, vcpkg

## 简介

A library to provide read & write support for the E57 file format.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
