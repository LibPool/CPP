# libgta

> 标签: LGPL-2.1-or-later, c++, conan, libgta, vcpkg

## 简介

Libgta is a portable library that implements the Generic Tagged Array (GTA) file format.

Conan Center 收录：Library that reads and writes GTA (Generic Tagged Arrays) files.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
