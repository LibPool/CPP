# enkits

> 标签: Zlib, c++, enkits, vcpkg

## 简介

A permissively licensed C and C++ Task Scheduler for creating parallel programs.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/dougbinks/enkiTS
- vcpkg 端口：https://vcpkg.io/en/packages/enkits
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/enkits
