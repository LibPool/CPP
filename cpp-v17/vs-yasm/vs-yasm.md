# vs-yasm

> 标签: c++, vcpkg, vs-yasm

## 简介

Provides Visual Studio integration for the YASM assembler.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/ShiftMediaProject/VSYASM
- vcpkg 端口：https://vcpkg.io/en/packages/vs-yasm
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vs-yasm
