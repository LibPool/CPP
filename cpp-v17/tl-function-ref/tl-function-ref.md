# tl-function-ref

> 标签: CC0-1.0, c++, conan, tl-function-ref, vcpkg

## 简介

A lightweight, non-owning reference to a callable.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
