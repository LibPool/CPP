# anyrpc

> 标签: anyrpc, c++, vcpkg

## 简介

A multiprotocol remote procedure call system for C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/sgieseking/anyrpc
- vcpkg 端口：https://vcpkg.io/en/packages/anyrpc
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/anyrpc
