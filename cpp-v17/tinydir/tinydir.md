# tinydir

> 标签: BSD-2-Clause, c++, conan, tinydir, vcpkg

## 简介

Lightweight, portable and easy to integrate C directory and file reader

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- Conan Center：https://conan.io/center/recipes/tinydir
- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/tinydir
