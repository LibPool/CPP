# scintilla

> 标签: c++, scintilla, vcpkg

## 简介

A free source code editing component for Win32, GTK+, and OS X

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.scintilla.org/
- vcpkg 端口：https://vcpkg.io/en/packages/scintilla
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/scintilla
