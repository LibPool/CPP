# telnetpp

> 标签: MIT, c++, telnetpp, vcpkg

## 简介

A C++ library for interacting with Telnet streams

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
