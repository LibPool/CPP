# liblo

> 标签: c++, liblo, vcpkg

## 简介

liblo is an implementation of the Open Sound Control protocol for POSIX systems

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
