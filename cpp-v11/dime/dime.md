# dime

> 标签: BSD-3-Clause, c++, conan, dime, vcpkg

## 简介

Reading DXF Drawing files

Conan Center 收录：DXF (Data eXchange Format) file format support library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/coin3d/dime
- vcpkg 端口：https://vcpkg.io/en/packages/dime
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/dime
- Conan Center：https://conan.io/center/recipes/dime
- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/dime
