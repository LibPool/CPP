# krabsetw

> 标签: c++, krabsetw, vcpkg

## 简介

krabsetw is a header-only C++ library that simplifies interacting with ETW.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
