# type-lite

> 标签: c++, type-lite, vcpkg

## 简介

Strong types for C++98, C++11 and later in a single-file header-only library.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/martinmoene/type-lite
- vcpkg 端口：https://vcpkg.io/en/packages/type-lite
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/type-lite
