# clockutils

> 标签: MIT, c++, clockutils, vcpkg

## 简介

A lightweight c++ library for commonly needed tasks. Optimized for simplicity and speed.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
