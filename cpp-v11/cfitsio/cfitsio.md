# cfitsio

> 标签: c++, cfitsio, vcpkg

## 简介

Library of C and Fortran subroutines for reading and writing data files in FITS (Flexible Image Transport System) data format

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://heasarc.gsfc.nasa.gov/fitsio/
- vcpkg 端口：https://vcpkg.io/en/packages/cfitsio
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/cfitsio
