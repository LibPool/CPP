# blitz

> 标签: blitz, c++, vcpkg

## 简介

Blitz++ is a C++ template class library that provides high-performance multidimensional array containers for scientific computing.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
