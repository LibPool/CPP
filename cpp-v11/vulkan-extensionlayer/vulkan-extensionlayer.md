# vulkan-extensionlayer

> 标签: Apache-2.0, c++, vcpkg, vulkan-extensionlayer

## 简介

Layer providing Vulkan features when native support is unavailable

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/KhronosGroup/Vulkan-ExtensionLayer
- vcpkg 端口：https://vcpkg.io/en/packages/vulkan-extensionlayer
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vulkan-extensionlayer
