# plf-stack

> 标签: Zlib, c++, plf-stack, vcpkg

## 简介

A C++ data container replicating std::stack functionality but with better performance

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
