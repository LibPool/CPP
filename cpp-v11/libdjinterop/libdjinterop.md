# libdjinterop

> 标签: LGPL-3.0-or-later, c++, libdjinterop, vcpkg

## 简介

C++ library for access to DJ record libraries. Currently only supports Denon Engine Prime databases

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
