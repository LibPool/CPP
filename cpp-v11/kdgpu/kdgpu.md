# kdgpu

> 标签: MIT, c++, kdgpu, vcpkg

## 简介

KDGPU Library - C++ Vulkan wrapper for GPU programming

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/KDAB/kdgpu
- vcpkg 端口：https://vcpkg.io/en/packages/kdgpu
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/kdgpu
