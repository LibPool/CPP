# earcut-hpp

> 标签: ISC, c++, earcut-hpp, vcpkg

## 简介

earcut.hpp is a C++ port of earcut.js, a fast, header-only polygon triangulation library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
