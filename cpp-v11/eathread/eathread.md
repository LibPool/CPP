# eathread

> 标签: c++, eathread, vcpkg

## 简介

Electronic Arts Thread Library. EAThread implements a unified cross-platform interface for multithreaded programming on various platforms.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
