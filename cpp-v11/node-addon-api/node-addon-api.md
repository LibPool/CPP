# node-addon-api

> 标签: MIT, c++, node-addon-api, vcpkg

## 简介

Module for using Node-API from C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
