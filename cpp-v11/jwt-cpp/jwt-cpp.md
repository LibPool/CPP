# jwt-cpp

> 标签: MIT, c++, jwt-cpp, vcpkg

## 简介

A header only library for creating and validating json web tokens in c++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
