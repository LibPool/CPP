# sqlite-modern-cpp

> 标签: c++, sqlite-modern-cpp, vcpkg

## 简介

The C++14 wrapper around sqlite library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
