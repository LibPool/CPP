# backward-cpp

> 标签: backward-cpp, c++, vcpkg

## 简介

A beautiful stack trace pretty printer for C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/bombela/backward-cpp
- vcpkg 端口：https://vcpkg.io/en/packages/backward-cpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/backward-cpp
