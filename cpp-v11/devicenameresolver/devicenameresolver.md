# devicenameresolver

> 标签: c++, devicenameresolver, vcpkg

## 简介

a little library that resolves a path from a (virtual) device name.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/devicenameresolver
