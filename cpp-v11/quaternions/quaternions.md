# quaternions

> 标签: c++, quaternions, vcpkg

## 简介

A C++11 library to work with quaternions, as a single header file.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/ferd36/quaternions
- vcpkg 端口：https://vcpkg.io/en/packages/quaternions
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/quaternions
