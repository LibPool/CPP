# iniparser

> 标签: MIT, c++, iniparser, vcpkg

## 简介

C library for parsing INI-style files

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
