# compoundfilereader

> 标签: c++, compoundfilereader, vcpkg

## 简介

Simple standalone c++ header file to read compound file (Structured Storage File) content.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/compoundfilereader
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/compoundfilereader
