# tinycthread

> 标签: Zlib, c++, conan, tinycthread, vcpkg

## 简介

Small, portable implementation of the C11 threads API

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
