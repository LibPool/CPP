# libsass

> 标签: c++, libsass, vcpkg

## 简介

LibSass - Sass compiler written in C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/sass/libsass
- vcpkg 端口：https://vcpkg.io/en/packages/libsass
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libsass
