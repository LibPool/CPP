# rocksdb

> 标签: GPL-2.0-only OR Apache-2.0, c++, rocksdb, vcpkg

## 简介

A library that provides an embeddable, persistent key-value store for fast storage

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
