# hexl

> 标签: Apache-2.0, c++, conan, hexl, vcpkg

## 简介

Intel® HEXL is an open-source library which provides efficient implementations of integer arithmetic on Galois fields.

Conan Center 收录：Intel Homomorphic Encryption (HE) Acceleration Library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
