# minizip-ng

> 标签: Zlib, c++, minizip-ng, vcpkg

## 简介

minizip-ng is a zip manipulation library written in C that is supported on Windows, macOS, and Linux.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
