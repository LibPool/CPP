# libssh

> 标签: LGPL-2.1, LGPL-2.1-only, c++, conan, libssh, vcpkg

## 简介

libssh is a multiplatform C library implementing the SSHv2 protocol on client and server side

Conan Center 收录：multiplatform C library implementing the SSHv2 protocol on client and server side

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
