# ada-url

> 标签: MIT OR Apache-2.0, ada-url, c++, vcpkg

## 简介

WHATWG-compliant and fast URL parser written in modern C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
