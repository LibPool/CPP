# icey

> 标签: LGPL-2.1-or-later, c++, icey, vcpkg

## 简介

C++20 media stack and libwebrtc alternative for real-time video, signalling, TURN, and media servers

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
