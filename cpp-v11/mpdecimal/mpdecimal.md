# mpdecimal

> 标签: BSD-2-Clause, c++, conan, mpdecimal, vcpkg

## 简介

Correctly rounded arbitrary precision decimal floating point arithmetic (libmpdec)

Conan Center 收录：mpdecimal is a package for correctly-rounded arbitrary precision decimal floating point arithmetic.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
