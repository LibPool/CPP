# wayland-protocols

> 标签: MIT, c++, conan, vcpkg, wayland-protocols

## 简介

wayland-protocols contains Wayland protocols that add functionality not available in the Wayland core protocol.

Conan Center 收录：Wayland is a project to define a protocol for a compositor to talk to its clients as well as a library implementation of the protocol

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
