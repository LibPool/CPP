# picobench

> 标签: MIT, c++, conan, picobench, vcpkg

## 简介

A micro microbenchmarking library for C++11 in a single header file

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
