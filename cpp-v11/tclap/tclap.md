# tclap

> 标签: MIT, c++, tclap, vcpkg

## 简介

Templatized command-line argument parser for C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://sourceforge.net/projects/tclap/
- vcpkg 端口：https://vcpkg.io/en/packages/tclap
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tclap
