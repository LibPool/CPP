# vxl

> 标签: c++, vcpkg, vxl

## 简介

A multi-platform collection of C++ software libraries for Computer Vision and Image Understanding.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://vxl.github.io/
- vcpkg 端口：https://vcpkg.io/en/packages/vxl
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vxl
