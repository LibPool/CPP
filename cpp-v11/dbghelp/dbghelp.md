# dbghelp

> 标签: c++, dbghelp, vcpkg

## 简介

Windows Debug Help Library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/dbghelp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/dbghelp
