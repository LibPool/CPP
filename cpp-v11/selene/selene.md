# selene

> 标签: c++, selene, vcpkg

## 简介

A C++17 image representation, processing and I/O library.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
