# coin

> 标签: BSD-3-Clause, c++, coin, vcpkg

## 简介

A high-level 3D visualization library with Open Inventor 2.1 API

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
