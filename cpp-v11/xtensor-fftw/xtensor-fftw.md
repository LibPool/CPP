# xtensor-fftw

> 标签: c++, vcpkg, xtensor-fftw

## 简介

FFTW bindings for the xtensor C++14 multi-dimensional array library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/xtensor-stack/xtensor-fftw
- vcpkg 端口：https://vcpkg.io/en/packages/xtensor-fftw
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/xtensor-fftw
