# arcus

> 标签: LGPL-3.0-or-later, arcus, c++, conan, vcpkg

## 简介

This library contains C++ bindings for creating a socket in a thread and using this socket to send and receive messages based on the Protocol Buffers library.

Conan Center 收录：This library contains C++ code and Python3 bindings for

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
