# ois

> 标签: Zlib, c++, conan, ois, vcpkg

## 简介

Cross Platform Object Oriented Input Lib System. Meant to be very robust and compatible with many systems and operating systems.

Conan Center 收录：Object oriented Input System.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 获取地址

vcpkg 安装：`vcpkg install ois`
Conan 安装：`conan install --requires=ois/1.5.1`
vcpkg port 目录：https://github.com/microsoft/vcpkg/tree/master/ports/ois
- vcpkg 许可证：Zlib
- 平台/支持条件：!(arm | arm64 | uwp)
