# ois

> 标签: Zlib, c++, ois, vcpkg

## 简介

Cross Platform Object Oriented Input Lib System. Meant to be very robust and compatible with many systems and operating systems.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://wgois.github.io/OIS/
- vcpkg 端口：https://vcpkg.io/en/packages/ois
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/ois
