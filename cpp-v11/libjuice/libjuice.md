# libjuice

> 标签: MPL-2.0, c++, conan, libjuice, vcpkg

## 简介

The library is a simplified implementation of the Interactive Connectivity Establishment (ICE) protocol in C for POSIX platforms (including Linux and Apple macOS) and Microsoft Windows.

Conan Center 收录：JUICE is a UDP Interactive Connectivity Establishment library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
