# libffi

> 标签: MIT, c++, conan, libffi, vcpkg

## 简介

Portable, high level programming interface to various calling conventions

Conan Center 收录：A portable, high level programming interface to various calling conventions

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
