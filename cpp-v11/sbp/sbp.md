# sbp

> 标签: MIT, c++, sbp, vcpkg

## 简介

Swift Navigation Binary Protocol (SBP) is a binary protocol for communicating GNSS data used by Piksi devices.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/swift-nav/libsbp
- vcpkg 端口：https://vcpkg.io/en/packages/sbp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/sbp
