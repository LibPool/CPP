# gsl-lite

> 标签: MIT, c++, conan, gsl-lite, vcpkg

## 简介

ISO C++ Core Guidelines Library implementation for C++98, C++11 up

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
