# stillwater-universal

> 标签: MIT, c++, stillwater-universal, vcpkg

## 简介

A header-only C++ library for plug-in replacement number systems for native types

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
