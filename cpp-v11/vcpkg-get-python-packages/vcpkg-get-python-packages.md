# vcpkg-get-python-packages

> 标签: MIT, c++, vcpkg, vcpkg-get-python-packages

## 简介

C++ 库 vcpkg-get-python-packages，由软件包管理器收录。

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/vcpkg-get-python-packages
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vcpkg-get-python-packages
