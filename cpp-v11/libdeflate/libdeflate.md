# libdeflate

> 标签: MIT, c++, libdeflate, vcpkg

## 简介

libdeflate is a library for fast, whole-buffer DEFLATE-based compression and decompression.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
