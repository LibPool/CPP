# libdeflate

> 标签: MIT, c++, conan, libdeflate, vcpkg

## 简介

libdeflate is a library for fast, whole-buffer DEFLATE-based compression and decompression.

Conan Center 收录：Heavily optimized library for DEFLATE/zlib/gzip compression and decompression.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
