# ddtdanilo-lmdb-wrapper

> 标签: MIT, c++, ddtdanilo-lmdb-wrapper, vcpkg

## 简介

MISRA C compliant wrapper for LMDB (Lightning Memory-Mapped Database)

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
