# sqlpp11

> 标签: BSD-2-Clause, c++, sqlpp11, vcpkg

## 简介

A type safe embedded domain specific language for SQL queries and results in C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
