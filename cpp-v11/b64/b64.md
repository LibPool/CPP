# b64

> 标签: b64, c++, vcpkg

## 简介

libb64 is a library of ANSI C routines for fast encoding/decoding data into and from a base64-encoded format

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
