# libmicrohttpd

> 标签: LGPL-2.1, LGPL-2.1-or-later, c++, conan, libmicrohttpd, vcpkg

## 简介

GNU libmicrohttpd is a small C library that is supposed to make it easy to run an HTTP server as part of another application

Conan Center 收录：A small C library that is supposed to make it easy to run an HTTP server

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
