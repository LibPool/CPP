# edlib

> 标签: c++, edlib, vcpkg

## 简介

Lightweight, super fast C/C++ (& Python) library for sequence alignment using edit (Levenshtein) distance.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
