# cpp-client-telemetry

> 标签: Apache-2.0, c++, cpp-client-telemetry, vcpkg

## 简介

Microsoft 1DS C/C++ Client Telemetry Library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
