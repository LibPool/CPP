# zix

> 标签: c++, vcpkg, zix

## 简介

Zix is a lightweight C library of portability wrappers and data structures.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
