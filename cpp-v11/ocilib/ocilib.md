# ocilib

> 标签: Apache-2.0, c++, conan, ocilib, vcpkg

## 简介

OCILIB is an open source and cross platform Oracle Driver that delivers efficient access to Oracle databases.

Conan Center 收录：An open source and cross platform Oracle Driver that delivers efficient access to Oracle databases.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
