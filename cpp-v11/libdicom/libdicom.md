# libdicom

> 标签: MIT, c++, libdicom, vcpkg

## 简介

libdicom is a C library and a set of command-line tools for reading DICOM WSI files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
