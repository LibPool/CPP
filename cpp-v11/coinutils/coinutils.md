# coinutils

> 标签: EPL-2.0, c++, coinutils, vcpkg

## 简介

CoinUtils (Coin-or Utilities) is an open-source collection of classes and functions that are generally useful to more than one COIN-OR project

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.coin-or.org/
- vcpkg 端口：https://vcpkg.io/en/packages/coinutils
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/coinutils
