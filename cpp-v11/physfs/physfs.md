# physfs

> 标签: Zlib, c++, conan, physfs, vcpkg

## 简介

a library to provide abstract access to various archives

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/physfs
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/physfs
- 官网（Conan）：https://icculus.org/physfs
- Conan Center：https://conan.io/center/recipes/physfs
- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/physfs

vcpkg 安装：`vcpkg install physfs`
