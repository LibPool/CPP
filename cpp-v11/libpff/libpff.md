# libpff

> 标签: LGPL-3.0-or-later, c++, libpff, vcpkg

## 简介

Library and tools to access the Personal Folder File (PFF) and the Offline Folder File (OFF) format.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/libyal/libpff
- vcpkg 端口：https://vcpkg.io/en/packages/libpff
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libpff
