# opusfile

> 标签: BSD-3-Clause, c++, opusfile, vcpkg

## 简介

Stand-alone decoder library for .opus streams

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
