# sdbus-cpp

> 标签: LGPL-2.1-only, c++, sdbus-cpp, vcpkg

## 简介

High-level C++ D-Bus library for Linux designed to provide easy-to-use yet powerful API in modern C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
