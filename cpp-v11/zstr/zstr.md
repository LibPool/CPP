# zstr

> 标签: MIT, c++, conan, vcpkg, zstr

## 简介

This C++ header-only library enables the use of C++ standard iostreams to access ZLib-compressed streams.

Conan Center 收录：A C++ header-only ZLib wrapper.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
