# libxxf86vm

> 标签: c++, libxxf86vm, vcpkg

## 简介

Xlib-based library for the XFree86-VidMode X extension

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/libxxf86vm
