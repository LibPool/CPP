# nvrhi

> 标签: MIT, c++, nvrhi, vcpkg

## 简介

NVIDIA Rendering Hardware Interface abstraction layer for D3D11, D3D12, and Vulkan

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
