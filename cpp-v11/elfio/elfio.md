# elfio

> 标签: MIT, c++, conan, elfio, vcpkg

## 简介

A header-only C++ library intended for reading and generating files in the ELF binary format.

Conan Center 收录：A header-only C++ library that provides a simple interface for reading and generating files in ELF binary format.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
