# libcorrect

> 标签: BSD-3-Clause, c++, conan, libcorrect, vcpkg

## 简介

libcorrect is a library for Forward Error Correction

Conan Center 收录：C library for Convolutional codes and Reed-Solomon

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
