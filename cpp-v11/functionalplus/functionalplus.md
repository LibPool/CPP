# functionalplus

> 标签: BSL-1.0, c++, conan, functionalplus, vcpkg

## 简介

This port is the new fplus port, the old fplus has been removed. Functional Programming Library for C++. Write concise and readable C++ code

Conan Center 收录：Functional Programming Library for C++.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
