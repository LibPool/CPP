# console-bridge

> 标签: BSD-3-Clause, c++, console-bridge, vcpkg

## 简介

A ROS-independent package for logging that seamlessly pipes into rosconsole/rosout for ROS-dependent packages.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/ros/console_bridge
- vcpkg 端口：https://vcpkg.io/en/packages/console-bridge
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/console-bridge
