# tomlplusplus

> 标签: MIT, c++, conan, tomlplusplus, vcpkg

## 简介

Header-only TOML config file parser and serializer for modern C++.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
