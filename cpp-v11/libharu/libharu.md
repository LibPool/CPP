# libharu

> 标签: Zlib, c++, conan, libharu, vcpkg

## 简介

libharu - free PDF library

Conan Center 收录：Haru is a free, cross platform, open-sourced software library for generating PDF.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
