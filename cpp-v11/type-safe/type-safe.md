# type-safe

> 标签: c++, type-safe, vcpkg

## 简介

Zero overhead abstractions that use the C++ type system to prevent bugs.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
