# vins-z-backtesting-engine

> 标签: MIT, c++, vcpkg, vins-z-backtesting-engine

## 简介

C++20 backtesting engine with CMake package exports and a C API wrapper

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
