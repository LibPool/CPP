# elements

> 标签: MIT, c++, elements, vcpkg

## 简介

Elements is a lightweight, fine-grained, resolution independent, modular GUI library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
