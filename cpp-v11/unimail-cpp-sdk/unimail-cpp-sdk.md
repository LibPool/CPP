# unimail-cpp-sdk

> 标签: BSD-3-Clause, c++, unimail-cpp-sdk, vcpkg

## 简介

This is a cpp SDK for Unimail. Quickly integrate into your project.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/unimails/unimail-cpp-sdk
- vcpkg 端口：https://vcpkg.io/en/packages/unimail-cpp-sdk
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/unimail-cpp-sdk
