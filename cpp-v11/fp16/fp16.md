# fp16

> 标签: c++, fp16, vcpkg

## 简介

Header-only library for conversion to/from half-precision floating point formats

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/Maratyszcza/FP16
- vcpkg 端口：https://vcpkg.io/en/packages/fp16
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/fp16
