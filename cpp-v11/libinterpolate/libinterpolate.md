# libinterpolate

> 标签: MIT, c++, conan, libinterpolate, vcpkg

## 简介

Header-only C++ interpolation library.

Conan Center 收录：A C++ interpolation library with a simple interface that supports multiple interpolation methods.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
