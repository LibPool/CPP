# magnum-integration

> 标签: c++, magnum-integration, vcpkg

## 简介

Integrations for magnum, C++11/C++14 graphics middleware for games and data visualization

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
