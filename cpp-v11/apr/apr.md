# apr

> 标签: Apache-2.0, apr, c++, vcpkg

## 简介

The Apache Portable Runtime (APR) is a C library that forms a system portability layer that covers many operating systems.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://apr.apache.org/
- vcpkg 端口：https://vcpkg.io/en/packages/apr
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/apr
