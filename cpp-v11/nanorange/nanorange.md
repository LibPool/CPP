# nanorange

> 标签: BSL-1.0, c++, conan, nanorange, vcpkg

## 简介

NanoRange is a C++14 implementation of the C++20 Ranges proposals.

Conan Center 收录：NanoRange is a C++17 implementation of the C++20 Ranges proposals (formerly the Ranges TS).

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
