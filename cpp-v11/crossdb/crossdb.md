# crossdb

> 标签: MPL-2.0, c++, crossdb, vcpkg

## 简介

Ultra High-performance Lightweight Embedded and Server OLTP RDBMS

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
