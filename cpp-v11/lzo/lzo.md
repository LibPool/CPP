# lzo

> 标签: GPL-2.0, c++, conan, lzo, vcpkg

## 简介

Lossless data compression library

Conan Center 收录：lzo is a portable lossless data compression library written in ANSI C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
