# libgta

> 标签: c++, libgta, vcpkg

## 简介

Libgta is a portable library that implements the Generic Tagged Array (GTA) file format.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://download.savannah.nongnu.org/releases/gta
- vcpkg 端口：https://vcpkg.io/en/packages/libgta
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libgta
