# valijson

> 标签: BSD-2-Clause, c++, conan, valijson, vcpkg

## 简介

Header-only C++ library for JSON Schema validation

Conan Center 收录：Valijson is a header-only JSON Schema Validation library for C++11.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
