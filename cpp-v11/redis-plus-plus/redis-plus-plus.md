# redis-plus-plus

> 标签: Apache-2.0, c++, conan, redis-plus-plus, vcpkg

## 简介

This is a C++ client for Redis. It's based on hiredis, and written in C++ 11

Conan Center 收录：Redis client written in C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
