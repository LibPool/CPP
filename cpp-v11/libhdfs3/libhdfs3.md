# libhdfs3

> 标签: c++, libhdfs3, vcpkg

## 简介

Native Hadoop RPC protocol and HDFS data transfer protocol implementation

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
