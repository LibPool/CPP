# darknet

> 标签: Apache-2.0 AND BSD-2-Clause, c++, darknet, vcpkg

## 简介

Darknet is an open source neural network framework written in C and CUDA for processing images or video frames in computer vision.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://darknetcv.ai/
- vcpkg 端口：https://vcpkg.io/en/packages/darknet
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/darknet
