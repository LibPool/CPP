# minizip

> 标签: Zlib, c++, minizip, vcpkg

## 简介

Minizip zip file manipulation library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/madler/zlib
- vcpkg 端口：https://vcpkg.io/en/packages/minizip
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/minizip
