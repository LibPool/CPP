# easyloggingpp

> 标签: MIT, c++, easyloggingpp, vcpkg

## 简介

Easylogging++ is a single header efficient logging library for C++ applications.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
