# eljonny-testcpp

> 标签: Unlicense, c++, eljonny-testcpp, vcpkg

## 简介

A simple C++ test framework with no dependencies other than C++11 STL.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
