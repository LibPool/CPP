# popsift

> 标签: MPL-2.0, c++, popsift, vcpkg

## 简介

PopSift is an implementation of the SIFT algorithm in CUDA.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
