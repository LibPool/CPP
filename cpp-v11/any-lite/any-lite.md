# any-lite

> 标签: BSL-1.0, any-lite, c++, conan, vcpkg

## 简介

A C++17-like any, a type-safe container for single values of any type for C++98, C++11 and later in a single-file header-only library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
