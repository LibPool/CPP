# winpcap

> 标签: c++, vcpkg, winpcap

## 简介

WinPcap is the industry-standard tool for link-layer network access in Windows environments.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.winpcap.org
- vcpkg 端口：https://vcpkg.io/en/packages/winpcap
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/winpcap
