# libsoundio

> 标签: c++, libsoundio, vcpkg

## 简介

libsoundio is C library providing cross-platform audio input and output.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://libsound.io/
- vcpkg 端口：https://vcpkg.io/en/packages/libsoundio
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libsoundio
