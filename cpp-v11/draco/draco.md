# draco

> 标签: Apache-2.0, c++, conan, draco, vcpkg

## 简介

A library for compressing and decompressing 3D geometric meshes and point clouds. It is intended to improve the storage and transmission of 3D graphics.

Conan Center 收录：Draco is a library for compressing and decompressing 3D

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
