# rapidxml

> 标签: c++, conan, rapidxml, vcpkg

## 简介

RapidXml is an attempt to create the fastest XML parser possible, while retaining useability, portability and reasonable W3C compatibility.

Conan Center 收录：RapidXml is an attempt to create the fastest XML parser possible.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
