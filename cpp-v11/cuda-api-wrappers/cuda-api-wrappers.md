# cuda-api-wrappers

> 标签: BSD-3-Clause, c++, conan, cuda-api-wrappers, vcpkg

## 简介

Header-only library of integrated wrappers around the core parts of NVIDIA's CUDA execution ecosystem

Conan Center 收录：Thin, unified, C++-flavored wrappers for the CUDA APIs

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
