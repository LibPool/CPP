# mathgl

> 标签: GPL-3.0-only, c++, mathgl, vcpkg

## 简介

MathGL is a free library of fast C++ routines for the plotting of the data varied in one or more dimensions

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
