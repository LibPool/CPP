# libgxps

> 标签: c++, libgxps, vcpkg

## 简介

libgxps is a GObject based library for handling and rendering XPS documents.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
