# utf8proc

> 标签: MIT, c++, utf8proc, vcpkg

## 简介

Clean C library for processing UTF-8 Unicode data.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
