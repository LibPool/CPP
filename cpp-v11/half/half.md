# half

> 标签: MIT, c++, half, vcpkg

## 简介

C++ library for half precision floating point arithmetics.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/half
