# libx11

> 标签: MIT, c++, libx11, vcpkg

## 简介

The X Window System is a network-transparent window system that was designed at MIT.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
