# protobuf-c

> 标签: c++, protobuf-c, vcpkg

## 简介

This is protobuf-c, a C implementation of the Google Protocol Buffers data serialization format.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
