# flatcc

> 标签: Apache-2.0, c++, flatcc, vcpkg

## 简介

FlatBuffers Compiler and Library in C for C

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/flatcc
