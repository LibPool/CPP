# gdcm

> 标签: BSD-3-Clause, c++, conan, gdcm, vcpkg

## 简介

Grassroots DICOM library

Conan Center 收录：C++ library for DICOM medical files

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
