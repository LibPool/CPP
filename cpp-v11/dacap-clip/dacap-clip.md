# dacap-clip

> 标签: MIT, c++, dacap-clip, vcpkg

## 简介

Cross-platform C++ library to copy/paste clipboard content.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
