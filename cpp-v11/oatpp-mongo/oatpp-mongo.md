# oatpp-mongo

> 标签: Apache-2.0, c++, oatpp-mongo, vcpkg

## 简介

Oat++ MongoDB adapter for Oat++ ORM (native client). It contains DTO to BSON mapper plus database driver.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
