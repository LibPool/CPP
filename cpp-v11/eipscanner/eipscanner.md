# eipscanner

> 标签: MIT, c++, eipscanner, vcpkg

## 简介

Free implementation of EtherNet/IP in C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
