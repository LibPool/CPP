# slick-shm

> 标签: MIT, c++, slick-shm, vcpkg

## 简介

A modern C++17 header-only, cross-platform shared memory library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
