# proxy

> 标签: MIT, c++, conan, proxy, vcpkg

## 简介

A single-header C++20 library that facilitates runtime polymorphism.

Conan Center 收录：Proxy: Next Generation Polymorphism in C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
