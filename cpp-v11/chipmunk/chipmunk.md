# chipmunk

> 标签: MIT, c++, chipmunk, vcpkg

## 简介

A fast and lightweight 2D game physics library.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
