# pocketpy

> 标签: MIT, c++, pocketpy, vcpkg

## 简介

pkpy is a lightweight(~15K LOC) Python interpreter for game scripting, built on C++17 with STL.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
