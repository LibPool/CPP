# libxdf

> 标签: BSD-2-Clause AND LGPL-3.0-or-later, c++, libxdf, vcpkg

## 简介

C++ library for loading multimodal, multi-rate signals stored in XDF files.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://xdf-modules.github.io/libxdf/
- vcpkg 端口：https://vcpkg.io/en/packages/libxdf
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libxdf
