# pbc

> 标签: LGPL-3.0, c++, pbc, vcpkg

## 简介

Pairing-Based Crypto library provides low-level routines for pairing-based cryptosystems.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
