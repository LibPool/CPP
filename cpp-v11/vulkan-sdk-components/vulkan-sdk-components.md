# vulkan-sdk-components

> 标签: c++, vcpkg, vulkan-sdk-components

## 简介

Installs packages which are part of the Vulkan SDK.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/vulkan-sdk-components
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vulkan-sdk-components
