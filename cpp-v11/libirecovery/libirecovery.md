# libirecovery

> 标签: LGPL-2.1-or-later, c++, libirecovery, vcpkg

## 简介

Library and utility to talk to iBoot/iBSS via USB on Mac OS X, Windows, and Linux

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
