# gtk

> 标签: LGPL-2.1-or-later, LGPL-2.1-or-later AND Apache-2.0, c++, conan, gtk, vcpkg

## 简介

Portable library for creating graphical user interfaces.

Conan Center 收录：libraries used for creating graphical user interfaces for applications.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
