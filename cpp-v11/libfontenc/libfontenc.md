# libfontenc

> 标签: c++, libfontenc, vcpkg

## 简介

X font encoding library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.freedesktop.org/xorg/lib/libfontenc
- vcpkg 端口：https://vcpkg.io/en/packages/libfontenc
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libfontenc
