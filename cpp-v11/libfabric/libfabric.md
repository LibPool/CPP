# libfabric

> 标签: BSD-2-Clause OR GPL-2.0-only, c++, libfabric, vcpkg

## 简介

Libfabric, aka Open Fabrics Interfaces (OFI), defines a communication API for high-performance parallel and distributed applications.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
