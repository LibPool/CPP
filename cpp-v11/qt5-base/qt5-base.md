# qt5-base

> 标签: c++, qt5-base, vcpkg

## 简介

Qt Base provides the basic non-GUI functionality required by all Qt applications.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
