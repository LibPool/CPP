# openh264

> 标签: BSD-2-Clause, c++, conan, openh264, vcpkg

## 简介

OpenH264 is a codec library which supports H.264 encoding and decoding. It is suitable for use in real time applications such as WebRTC.

Conan Center 收录：Open Source H.264 Codec

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
