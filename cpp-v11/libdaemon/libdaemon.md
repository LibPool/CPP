# libdaemon

> 标签: LGPL-2.1-or-later, c++, libdaemon, vcpkg

## 简介

libdaemon is a lightweight C library that eases the writing of UNIX daemons

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
