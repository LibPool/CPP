# easy-profiler

> 标签: MIT OR Apache-2.0, c++, easy-profiler, vcpkg

## 简介

Lightweight profiler library for c++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/yse/easy_profiler
- vcpkg 端口：https://vcpkg.io/en/packages/easy-profiler
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/easy-profiler

## 历史版本号

- 当前版本：2.1.0
