# fast-obj

> 标签: MIT, c++, fast-obj, vcpkg

## 简介

Fast C OBJ parser - a single-header C/C++ library for loading Wavefront .obj files.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
