# read-excel

> 标签: MIT, c++, conan, read-excel

## 简介

Conan Center 收录：This is very simple implementation of the Excel 97-2003 format (BIFF8) written in C++. Supported reading only.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
