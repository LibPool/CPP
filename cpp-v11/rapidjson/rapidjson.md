# rapidjson

> 标签: MIT, c++, rapidjson, vcpkg

## 简介

A fast JSON parser/generator for C++ with both SAX/DOM style API <http://rapidjson.org/>

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://rapidjson.org/
- vcpkg 端口：https://vcpkg.io/en/packages/rapidjson
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/rapidjson
