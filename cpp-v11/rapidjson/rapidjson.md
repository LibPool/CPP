# rapidjson

> 标签: MIT, c++, conan, rapidjson, vcpkg

## 简介

A fast JSON parser/generator for C++ with both SAX/DOM style API <http://rapidjson.org/>

Conan Center 收录：A fast JSON parser/generator for C++ with both SAX/DOM style API

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
