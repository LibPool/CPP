# rapidcsv

> 标签: BSD-3-Clause, c++, conan, rapidcsv, vcpkg

## 简介

Rapidcsv is a C++ header-only library for CSV parsing.

Conan Center 收录：C++ CSV parser library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
