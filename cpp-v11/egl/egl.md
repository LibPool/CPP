# egl

> 标签: MIT, c++, conan, egl, vcpkg

## 简介

EGL is an interface between Khronos rendering APIs (such as OpenGL, OpenGL ES or OpenVG) and the underlying native platform windowing system.

Conan Center 收录：cross-platform virtual conan package for the EGL support

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
