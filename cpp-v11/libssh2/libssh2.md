# libssh2

> 标签: BSD-3-Clause, c++, conan, libssh2, vcpkg

## 简介

libssh2 is a client-side C library implementing the SSH2 protocol.

Conan Center 收录：libssh2 is a client-side C library implementing the SSH2 protocol

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
