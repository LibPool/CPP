# unicorn

> 标签: GPL-2.0-only, c++, conan, unicorn, vcpkg

## 简介

Unicorn is a lightweight multi-platform, multi-architecture CPU emulator framework

Conan Center 收录：Unicorn is a lightweight multi-platform, multi-architecture CPU emulator framework.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
