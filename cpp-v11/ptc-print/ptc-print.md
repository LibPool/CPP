# ptc-print

> 标签: MIT, c++, ptc-print, vcpkg

## 简介

A single-header library for custom printing to the output stream.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
