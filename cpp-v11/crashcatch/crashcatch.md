# crashcatch

> 标签: MIT, c++, crashcatch, vcpkg

## 简介

A cross-platform, single-header C++ crash-reporting library for modern C++ applications.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
