# dlpack

> 标签: Apache-2.0, c++, conan, dlpack, vcpkg

## 简介

DLPack is an open in-memory tensor structure for sharing tensors among frameworks

Conan Center 收录：RFC for common in-memory tensor structure and operator interface for deep learning system

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
