# status-code

> 标签: Apache-2.0 OR BSL-1.0, c++, status-code, vcpkg

## 简介

Proposed SG14 status_code for the C++ standard (https://wg21.link/P1028).

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
