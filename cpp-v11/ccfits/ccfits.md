# ccfits

> 标签: CFITSIO, NASA-1.3, c++, ccfits, conan, vcpkg

## 简介

CCfits is an object oriented interface to the cfitsio library. It is designed to make the capabilities of cfitsio available to programmers working in C++.

Conan Center 收录：CCfits is an object oriented interface to the cfitsio library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
