# librealsense

> 标签: Apache-2.0, c++, conan, librealsense

## 简介

Conan Center 收录：Intel(R) RealSense(tm) Cross Platform API for accessing Intel RealSense cameras.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
