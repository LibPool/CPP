# atlmfc

> 标签: atlmfc, c++, vcpkg

## 简介

A stub package that ensures Visual Studio has ATL/MFC installed.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/atlmfc
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/atlmfc

## 历史版本号

- 当前版本：0#4

- 0#4

- 0#2

## 获取地址

vcpkg 安装：`vcpkg install atlmfc`
vcpkg port 目录：https://github.com/microsoft/vcpkg/tree/master/ports/atlmfc
- 平台/支持条件：windows & !xbox
