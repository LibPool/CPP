# marl

> 标签: Apache-2.0, c++, marl, vcpkg

## 简介

A hybrid thread/fiber task scheduler written in modern C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
