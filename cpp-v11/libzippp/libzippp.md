# libzippp

> 标签: BSD-3-Clause, c++, conan, libzippp, vcpkg

## 简介

Simple basic C++ wrapper around the libzip library. It is meant to be a portable and easy-to-use library for ZIP handling

Conan Center 收录：A simple basic C++ wrapper around the libzip library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
