# wintoast

> 标签: MIT, c++, conan, vcpkg, wintoast

## 简介

WinToast is a lightly library written in C++ which brings a complete integration of the modern toast notifications of Windows 8 & Windows 10.

Conan Center 收录：Lightweight library which brings a complete integration of the modern toast notifications of Windows

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
