# bitflags

> 标签: MIT, bitflags, c++, conan

## 简介

Conan Center 收录：Single-header header-only C++11 / C++14 / C++17 library for easily managing set of auto-generated type-safe flags

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
