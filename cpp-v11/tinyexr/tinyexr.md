# tinyexr

> 标签: BSD-3-Clause, c++, conan, tinyexr, vcpkg

## 简介

Library to load and save OpenEXR(.exr) images

Conan Center 收录：Tiny OpenEXR image loader/saver library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
