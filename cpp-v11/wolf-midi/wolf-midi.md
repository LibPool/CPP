# wolf-midi

> 标签: Apache-2.0, c++, vcpkg, wolf-midi

## 简介

A lightweight MIDI file read-write library.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/wolfgitpr/wolf-midi
- vcpkg 端口：https://vcpkg.io/en/packages/wolf-midi
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/wolf-midi
