# paho-mqttpp3

> 标签: EPL-1.0, c++, paho-mqttpp3, vcpkg

## 简介

Paho project provides open-source C++ wrapper for Paho C library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/eclipse/paho.mqtt.cpp
