# poppler

> 标签: GPL-2.0-or-later, c++, conan, poppler, vcpkg

## 简介

A PDF rendering library

Conan Center 收录：Poppler is a PDF rendering library based on the xpdf-3.0 code base

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
