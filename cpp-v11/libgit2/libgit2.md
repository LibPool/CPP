# libgit2

> 标签: GPL-2.0-linking-exception, c++, conan, libgit2, vcpkg

## 简介

A C library implementing the Git core methods with a solid API

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
