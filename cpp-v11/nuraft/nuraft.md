# nuraft

> 标签: Apache-2.0, c++, nuraft, vcpkg

## 简介

C++ implementation of Raft core logic as a replication library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://github.com/eBay/NuRaft

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/nuraft
