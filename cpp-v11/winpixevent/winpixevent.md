# winpixevent

> 标签: MIT, c++, vcpkg, winpixevent

## 简介

Allows applications to be instrumented with marker events, for use with Microsoft PIX.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://devblogs.microsoft.com/pix/
- vcpkg 端口：https://vcpkg.io/en/packages/winpixevent
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/winpixevent
