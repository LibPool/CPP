# oboe

> 标签: Apache-2.0, c++, conan, oboe, vcpkg

## 简介

Oboe is a C++ library which makes it easy to build high-performance audio apps on Android

Conan Center 收录：Oboe is a C++ library which makes it easy to build high-performance audio apps on Android.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
