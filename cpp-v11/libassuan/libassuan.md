# libassuan

> 标签: LGPL-2.1-or-later, c++, libassuan, vcpkg

## 简介

A library implementing the so-called Assuan protocol

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
