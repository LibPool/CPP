# spdlog

> 标签: MIT, c++, conan, spdlog, vcpkg

## 简介

Very fast, header-only/compiled, C++ logging library.

Conan Center 收录：Fast C++ logging library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
