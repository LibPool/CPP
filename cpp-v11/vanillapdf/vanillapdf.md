# vanillapdf

> 标签: Apache-2.0, c++, vanillapdf, vcpkg

## 简介

Vanilla.PDF is a cross-platform SDK for creating and modifying PDF documents.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/vanillapdf/vanillapdf
- vcpkg 端口：https://vcpkg.io/en/packages/vanillapdf
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/vanillapdf
