# happly

> 标签: c++, happly, vcpkg

## 简介

A header-only C++ reader/writer for the PLY file format.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
