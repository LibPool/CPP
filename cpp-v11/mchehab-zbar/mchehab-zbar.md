# mchehab-zbar

> 标签: LGPL-2.1-or-later, c++, mchehab-zbar, vcpkg

## 简介

ZBar is an open source software suite for reading bar codes from various sources, including webcams. This fork is actively maintained.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
