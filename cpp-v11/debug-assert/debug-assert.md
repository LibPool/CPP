# debug-assert

> 标签: c++, debug-assert, vcpkg

## 简介

Provides flexible DEBUG_ASSERT() macro.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
