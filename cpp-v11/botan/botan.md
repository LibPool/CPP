# botan

> 标签: BSD-2-Clause, botan, c++, conan, vcpkg

## 简介

A cryptography library written in C++11

Conan Center 收录：Botan is a cryptography library written in modern C++.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
