# foonathan-memory

> 标签: Zlib, c++, conan, foonathan-memory, vcpkg

## 简介

STL compatible C++ memory allocator library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
