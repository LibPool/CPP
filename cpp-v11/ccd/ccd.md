# ccd

> 标签: BSD-3-Clause, c++, ccd, vcpkg

## 简介

Library for collision detection between two convex shapes

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
