# dcmtk

> 标签: BSD-3-Clause, c++, conan, dcmtk, vcpkg

## 简介

This DICOM ToolKit (DCMTK) package consists of source code, documentation and installation instructions for a set of software libraries and applications implementing part of the DICOM/MEDICOM Standard.

Conan Center 收录：DCMTK is a collection of libraries and applications implementing large parts the DICOM standard

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
