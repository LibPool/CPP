# whereami

> 标签: MIT OR WTFPL, c++, vcpkg, whereami

## 简介

A drop-in two files library to locate the current executable and the current module on the file system.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
