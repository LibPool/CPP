# toml11

> 标签: MIT, c++, toml11, vcpkg

## 简介

A C++11 header-only toml parser/encoder depending only on C++ standard library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
