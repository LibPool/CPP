# sigslot

> 标签: MIT, c++, conan, sigslot, vcpkg

## 简介

Portable C++ type-safe, thread-safe signal/slot library for ISO C++, Unix/BSD/Linux and Win32. Sigslot allows C++ code to use the signal/slot paradigm made popular by, for example, Qt.

Conan Center 收录：Sigslot is a header-only, thread safe implementation of signal-slots for C++.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
