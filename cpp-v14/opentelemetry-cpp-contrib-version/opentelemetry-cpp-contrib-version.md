# opentelemetry-cpp-contrib-version

> 标签: Apache-2.0, c++, opentelemetry-cpp-contrib-version, vcpkg

## 简介

This port manages the opentelemetry-cpp-version that will be used for opentelemetry-cpp

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
