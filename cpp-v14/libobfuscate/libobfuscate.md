# libobfuscate

> 标签: Unlicense, c++, libobfuscate, vcpkg

## 简介

Guaranteed compile-time string literal obfuscation header-only library for C++14.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
