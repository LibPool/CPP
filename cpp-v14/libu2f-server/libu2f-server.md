# libu2f-server

> 标签: c++, libu2f-server, vcpkg

## 简介

Yubico Universal 2nd Factor (U2F) Server C Library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
