# libqtrest

> 标签: MIT, c++, libqtrest, vcpkg

## 简介

Small and simple REST API (Json/Xml) client for any Qt/QML C++ application

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/qtrest/qtrest
- vcpkg 端口：https://vcpkg.io/en/packages/libqtrest
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libqtrest
