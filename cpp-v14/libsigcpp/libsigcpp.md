# libsigcpp

> 标签: LGPL-3.0-or-later, c++, libsigcpp, vcpkg

## 简介

Typesafe callback framework for C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://libsigcplusplus.github.io/libsigcplusplus/
- vcpkg 端口：https://vcpkg.io/en/packages/libsigcpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libsigcpp
