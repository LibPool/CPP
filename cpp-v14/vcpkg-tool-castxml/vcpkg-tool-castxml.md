# vcpkg-tool-castxml

> 标签: Apache-2.0, c++, vcpkg, vcpkg-tool-castxml

## 简介

CastXML is a C-family abstract syntax tree XML output tool.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
