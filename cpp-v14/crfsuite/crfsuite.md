# crfsuite

> 标签: c++, crfsuite, vcpkg

## 简介

CRFSuite is an implementation of Conditional Random Fields (CRFs) for labeling sequential data.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
