# celero

> 标签: Apache-2.0, c++, celero, conan, vcpkg

## 简介

Celero is a modern cross-platform (Windows, Linux, MacOS) Microbenchmarking library for C++ 11 and later.

Conan Center 收录：C++ Benchmarking Library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
