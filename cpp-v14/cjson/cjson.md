# cjson

> 标签: MIT, c++, cjson, vcpkg

## 简介

Ultralightweight JSON parser in ANSI C

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
