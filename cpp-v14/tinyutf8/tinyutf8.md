# tinyutf8

> 标签: BSD-3-Clause, c++, tinyutf8, vcpkg

## 简介

TINYUTF8 is a library for extremely easy integration of Unicode into an arbitrary C++11 project.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/DuffsDevice/tiny-utf8/
- vcpkg 端口：https://vcpkg.io/en/packages/tinyutf8
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinyutf8
