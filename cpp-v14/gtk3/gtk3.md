# gtk3

> 标签: c++, gtk3, vcpkg

## 简介

Portable library for creating graphical user interfaces.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
