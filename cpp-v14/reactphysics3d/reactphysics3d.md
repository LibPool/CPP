# reactphysics3d

> 标签: Zlib, c++, reactphysics3d, vcpkg

## 简介

Open source C++ physics engine library in 3D

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.reactphysics3d.com
- vcpkg 端口：https://vcpkg.io/en/packages/reactphysics3d
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/reactphysics3d
