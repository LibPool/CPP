# tesults-cpp

> 标签: MIT, c++, tesults-cpp, vcpkg

## 简介

C++ library for uploading test results to Tesults

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://github.com/tesults/cpp
- vcpkg 端口：https://vcpkg.io/en/packages/tesults-cpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tesults-cpp
