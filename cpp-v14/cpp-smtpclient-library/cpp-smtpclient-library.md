# cpp-smtpclient-library

> 标签: MIT, MIT AND Zlib, c++, conan, cpp-smtpclient-library, vcpkg

## 简介

An SMTP client library built in C++ that support authentication and secure connections

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
