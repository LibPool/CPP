# libbpf

> 标签: LGPL-2.1-only OR BSD-2-Clause, c++, libbpf, vcpkg

## 简介

Supports loading compiled BPF object files into the Linux Kernel

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/libbpf
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libbpf

## 历史版本号

- 当前版本：1.7.0

- 1.7.0
