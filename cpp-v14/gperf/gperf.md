# gperf

> 标签: GPL-3.0-or-later, c++, gperf, vcpkg

## 简介

GNU perfect hash function generator

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
