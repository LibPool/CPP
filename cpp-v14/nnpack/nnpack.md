# nnpack

> 标签: BSD-2-Clause, c++, conan, nnpack, vcpkg

## 简介

Acceleration package for neural networks on multi-core CPUs

Conan Center 收录：NNPACK is an acceleration package for neural network computations

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
