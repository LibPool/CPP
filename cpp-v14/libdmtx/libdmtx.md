# libdmtx

> 标签: BSD-2-Clause, c++, conan, libdmtx, vcpkg

## 简介

Software library that enables programs to read and write Data Matrix barcodes of the modern ECC200 variety

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
