# qtdeviceutilities

> 标签: c++, qtdeviceutilities, vcpkg

## 简介

Qt Device Utilities provides functionality that is useful for controlling settings in embedded applications.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
