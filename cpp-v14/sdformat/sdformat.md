# sdformat

> 标签: Apache-2.0, c++, sdformat, vcpkg

## 简介

Simulation Description Format (SDF) parser and description files.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://sdformat.org/
- vcpkg 端口：https://vcpkg.io/en/packages/sdformat
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/sdformat
