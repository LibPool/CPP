# mpark-variant

> 标签: c++, mpark-variant, vcpkg

## 简介

an implementation of C++17 std::variant for C++11/14/17.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/mpark-variant
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mpark-variant
