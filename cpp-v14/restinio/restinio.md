# restinio

> 标签: BSD-3-Clause, c++, conan, restinio, vcpkg

## 简介

A header-only C++14 library that gives you an embedded HTTP/Websocket server targeted primarily for asynchronous processing of HTTP-requests.

Conan Center 收录：RESTinio is a header-only C++14 library that gives you an embedded HTTP/Websocket server.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
