# json-schema-validator

> 标签: MIT, c++, conan, json-schema-validator, vcpkg

## 简介

C++ library for validating JSON documents based on a JSON Schema. This validator is based on the nlohmann-json library.

Conan Center 收录：JSON schema validator for JSON for Modern C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
