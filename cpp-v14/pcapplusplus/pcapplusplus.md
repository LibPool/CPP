# pcapplusplus

> 标签: c++, pcapplusplus, vcpkg

## 简介

PcapPlusPlus is a multi-platform C++ library for capturing, parsing and crafting of network packets

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
