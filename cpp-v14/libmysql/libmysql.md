# libmysql

> 标签: GPL-2.0-or-later, c++, libmysql, vcpkg

## 简介

A MySQL client library for C development

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
