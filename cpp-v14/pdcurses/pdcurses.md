# pdcurses

> 标签: c++, pdcurses, vcpkg

## 简介

Public Domain Curses - a curses library for environments that don't fit the termcap/terminfo model.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://pdcurses.org/
- vcpkg 端口：https://vcpkg.io/en/packages/pdcurses
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/pdcurses
