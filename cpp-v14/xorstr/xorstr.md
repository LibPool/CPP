# xorstr

> 标签: Apache-2.0, c++, vcpkg, xorstr

## 简介

Heavily vectorized c++17 compile time string encryption

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
