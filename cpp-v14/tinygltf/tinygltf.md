# tinygltf

> 标签: MIT AND BSL-1.0 AND Zlib, c++, tinygltf, vcpkg

## 简介

A header-only glTF 2.0 library with a C++11 v2 API and a C++17 v3 API.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/syoyo/tinygltf
