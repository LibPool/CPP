# gpgme

> 标签: c++, gpgme, vcpkg

## 简介

A library designed to make access to GnuPG easier for applications

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gnupg.org/software/gpgme/
- vcpkg 端口：https://vcpkg.io/en/packages/gpgme
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/gpgme
