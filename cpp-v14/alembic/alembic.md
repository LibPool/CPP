# alembic

> 标签: BSD-3-Clause, alembic, c++, conan, vcpkg

## 简介

Alembic is an open framework for storing and sharing scene data that includes a C++ library, a file format, and client plugins and applications.

Conan Center 收录：Open framework for storing and sharing scene data.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
