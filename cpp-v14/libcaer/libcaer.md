# libcaer

> 标签: BSD-2-Clause AND Apache-2.0, c++, libcaer, vcpkg

## 简介

Minimal C library to access, configure and get data from neuromorphic sensors and processors.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.com/inivation/dv/libcaer
- vcpkg 端口：https://vcpkg.io/en/packages/libcaer
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libcaer
