# openxlsx

> 标签: BSD-3-Clause, c++, conan, openxlsx, vcpkg

## 简介

OpenXLSX is a C++ library for reading, writing, creating and modifying Microsoft Excel® files, with the .xlsx format.

Conan Center 收录：reading, writing, creating and modifying Microsoft Excel® (.xlsx) files.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
