# lerc

> 标签: Apache-2.0, c++, conan, lerc, vcpkg

## 简介

An open-source image or raster format which supports rapid encoding and decoding for any pixel type

Conan Center 收录：C++ library for limited Error Raster Compression.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
