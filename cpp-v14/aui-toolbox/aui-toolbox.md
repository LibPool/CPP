# aui-toolbox

> 标签: MPL-2.0, aui-toolbox, c++, vcpkg

## 简介

Host-side asset and shader compiler (aui.toolbox) for the AUI declarative UI toolkit

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/aui-framework/aui
- vcpkg 端口：https://vcpkg.io/en/packages/aui-toolbox
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/aui-toolbox
