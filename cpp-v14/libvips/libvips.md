# libvips

> 标签: LGPL-2.1-or-later, c++, libvips, vcpkg

## 简介

libvips is a demand-driven, horizontally threaded image processing library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/libvips/libvips
- vcpkg 端口：https://vcpkg.io/en/packages/libvips
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libvips
