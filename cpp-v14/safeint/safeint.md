# safeint

> 标签: MIT, c++, conan, safeint, vcpkg

## 简介

SafeInt is a class library for C++ that manages integer overflows

Conan Center 收录：SafeInt is a class library for C++ that manages integer overflows.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
