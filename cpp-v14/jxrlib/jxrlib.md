# jxrlib

> 标签: BSD-2-Clause, c++, conan, jxrlib, vcpkg

## 简介

Open source implementation of the jpegxr image format standard.

Conan Center 收录：jxrlib is JPEG XR Image Codec reference implementation library released by Microsoft under BSD-2-Clause License.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
