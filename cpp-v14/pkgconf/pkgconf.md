# pkgconf

> 标签: ISC, c++, conan, pkgconf, vcpkg

## 简介

pkgconf is a program which helps to configure compiler and linker flags for development libraries. It is similar to pkg-config from freedesktop.org.

Conan Center 收录：package compiler and linker metadata toolkit

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
