# osg

> 标签: c++, osg, vcpkg

## 简介

The OpenSceneGraph is an open source high performance 3D graphics toolkit.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
