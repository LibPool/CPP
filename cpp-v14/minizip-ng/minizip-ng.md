# minizip-ng

> 标签: Zlib, c++, conan, minizip-ng, vcpkg

## 简介

minizip-ng is a zip manipulation library written in C that is supported on Windows, macOS, and Linux.

Conan Center 收录：Fork of the popular zip manipulation library found in the zlib distribution.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
