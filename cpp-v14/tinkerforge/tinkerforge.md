# tinkerforge

> 标签: c++, tinkerforge, vcpkg

## 简介

Tinkerforge C API bindings for bricks and bricklets

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/tinkerforge
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinkerforge

## 历史版本号

- 当前版本：2.1.25#3

- 2.1.25#3
- 2.1.25#2

vcpkg 安装：`vcpkg install tinkerforge`
