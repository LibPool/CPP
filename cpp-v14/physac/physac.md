# physac

> 标签: MIT, c++, physac, vcpkg

## 简介

2D physics header-only library for videogames developed in C using raylib library.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/victorfisac/Physac
- vcpkg 端口：https://vcpkg.io/en/packages/physac
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/physac
