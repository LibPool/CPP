# oboe

> 标签: Apache-2.0, c++, oboe, vcpkg

## 简介

Oboe is a C++ library which makes it easy to build high-performance audio apps on Android

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://developer.android.com/games/sdk/oboe
- vcpkg 端口：https://vcpkg.io/en/packages/oboe
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/oboe
