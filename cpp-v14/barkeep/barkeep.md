# barkeep

> 标签: Apache-2.0, barkeep, c++, vcpkg

## 简介

Small C++ header to display async animations, counters, progress bars, and status messages

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
