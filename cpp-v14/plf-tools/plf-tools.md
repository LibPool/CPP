# plf-tools

> 标签: Zlib, c++, plf-tools, vcpkg

## 简介

Toolsets shared across plf:: libraries

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
