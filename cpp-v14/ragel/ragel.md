# ragel

> 标签: GPL-2.0-or-later, c++, conan, ragel, vcpkg

## 简介

Ragel State Machine Compiler

Conan Center 收录：Ragel compiles executable finite state machines from regular languages

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
