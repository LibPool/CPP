# picosha2

> 标签: MIT, c++, picosha2, vcpkg

## 简介

PicoSHA2 - a header-file-only C++ SHA256 hash generator

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/okdshin/PicoSHA2
- vcpkg 端口：https://vcpkg.io/en/packages/picosha2
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/picosha2
