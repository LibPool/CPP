# meekrosoft-fff

> 标签: MIT, c++, meekrosoft-fff, vcpkg

## 简介

A testing micro framework for creating function test doubles

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
