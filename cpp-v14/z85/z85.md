# z85

> 标签: c++, vcpkg, z85

## 简介

Z85 is a binary-to-text encoding library. It implements ZeroMQ Base-85 Encoding Algorithm and provides custom padding.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/z85
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/z85
