# libgpiod

> 标签: LGPL-2.1-or-later, c++, libgpiod, vcpkg

## 简介

C library and tools for interacting with the linux GPIO character device

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
