# libxkbcommon

> 标签: c++, libxkbcommon, vcpkg

## 简介

keymap handling library for toolkits and window systems

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
