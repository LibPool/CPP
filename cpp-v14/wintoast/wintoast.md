# wintoast

> 标签: c++, vcpkg, wintoast

## 简介

WinToast is a lightly library written in C++ which brings a complete integration of the modern toast notifications of Windows 8 & Windows 10.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/wintoast
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/wintoast
