# gstreamer

> 标签: LGPL-2.0-or-later, LGPL-2.1-or-later, c++, conan, gstreamer, vcpkg

## 简介

GStreamer open-source multimedia framework core library

Conan Center 收录：GStreamer is a development framework for creating applications like media players, video editors, streaming media broadcasters and so on

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
