# sqlcipher

> 标签: BSD-3-Clause, c++, conan, sqlcipher, vcpkg

## 简介

SQLCipher extends the SQLite database library to add security enhancements that make it more suitable for encrypted local data storage.

Conan Center 收录：SQLite extension that provides 256 bit AES encryption of database files.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
