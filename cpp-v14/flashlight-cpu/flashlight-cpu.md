# flashlight-cpu

> 标签: MIT, c++, flashlight-cpu, vcpkg

## 简介

A C++ standalone library for machine learning. CPU backend.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
