# dbus-cxx

> 标签: LGPL-3.0-or-later AND BSD-3-Clause, c++, dbus-cxx, vcpkg

## 简介

DBus-cxx provides an object-oriented interface to DBus.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
