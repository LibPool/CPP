# dbus-cxx

> 标签: LGPL-3.0-only, LGPL-3.0-or-later AND BSD-3-Clause, c++, conan, dbus-cxx, vcpkg

## 简介

DBus-cxx provides an object-oriented interface to DBus.

Conan Center 收录：DBus-cxx provides an object-oriented interface to DBus

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
