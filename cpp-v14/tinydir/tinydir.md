# tinydir

> 标签: BSD-2-Clause, c++, tinydir, vcpkg

## 简介

Lightweight, portable and easy to integrate C directory and file reader

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/cxong/tinydir
- vcpkg 端口：https://vcpkg.io/en/packages/tinydir
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinydir
