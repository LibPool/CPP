# dxsdk-d3dx

> 标签: c++, dxsdk-d3dx, vcpkg

## 简介

Redistributable package for the legacy DirectX SDK's D3DX9, D3DX10, and/or D3DX11 utility libraries.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://walbourn.github.io/legacy-d3dx-on-nuget/
- vcpkg 端口：https://vcpkg.io/en/packages/dxsdk-d3dx
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/dxsdk-d3dx
