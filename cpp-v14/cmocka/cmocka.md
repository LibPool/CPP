# cmocka

> 标签: Apache-2.0, c++, cmocka, vcpkg

## 简介

An elegant unit testing framework for C with support for mock objects

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
