# libodb-mysql

> 标签: c++, libodb-mysql, vcpkg

## 简介

MySQL support for the ODB ORM library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
