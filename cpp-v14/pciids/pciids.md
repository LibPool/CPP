# pciids

> 标签: GPL-2.0-or-later OR BSD-3-Clause, c++, pciids, vcpkg

## 简介

Maintainer function to acquire a PCI ID Repository database snapshot

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://pci-ids.ucw.cz/
- vcpkg 端口：https://vcpkg.io/en/packages/pciids
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/pciids
