# syscalls-cpp

> 标签: MIT, c++, conan, syscalls-cpp, vcpkg

## 简介

A modern C++20 header-only library for advanced direct system call invocation.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
