# json-dto

> 标签: BSD-3-Clause, c++, json-dto, vcpkg

## 简介

A small header-only library for converting data between json representation and c++ structs.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/Stiffstream/json_dto
- vcpkg 端口：https://vcpkg.io/en/packages/json-dto
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/json-dto
