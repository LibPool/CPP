# icu

> 标签: ICU, c++, conan, icu, vcpkg

## 简介

Mature and widely used Unicode and localization library.

Conan Center 收录：ICU is a mature, widely used set of C/C++ and Java libraries

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
