# libgcrypt

> 标签: LGPL-2.1-or-later, c++, conan, libgcrypt, vcpkg

## 简介

A general purpose cryptographic library

Conan Center 收录：Libgcrypt is a general purpose cryptographic library originally based on code from GnuPG

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
