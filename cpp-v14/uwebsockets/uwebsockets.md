# uwebsockets

> 标签: Apache-2.0, Apache-2.0 AND MIT, c++, conan, uwebsockets, vcpkg

## 简介

Simple, secure & standards compliant web I/O for the most demanding of applications

Conan Center 收录：Simple, secure & standards compliant web server for the most demanding of applications

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
