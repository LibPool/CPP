# node-api-headers

> 标签: MIT, c++, node-api-headers, vcpkg

## 简介

NodeJS API for writing modules in C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/node-api-headers
