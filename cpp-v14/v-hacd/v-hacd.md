# v-hacd

> 标签: c++, v-hacd, vcpkg

## 简介

The V-HACD library decomposes a 3D surface into a set of "near" convex parts.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
