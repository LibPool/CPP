# luajit

> 标签: MIT, c++, luajit, vcpkg

## 简介

LuaJIT is a Just-In-Time (JIT) compiler for the Lua programming language.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/LuaJIT/LuaJIT
- vcpkg 端口：https://vcpkg.io/en/packages/luajit
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/luajit
