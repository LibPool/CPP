# libdwarf

> 标签: c++, conan, libdwarf, vcpkg

## 简介

A library for reading DWARF2 and later DWARF.

Conan Center 收录：A library and a set of command-line tools for reading and writing DWARF2

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
