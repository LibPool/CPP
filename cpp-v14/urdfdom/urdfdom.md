# urdfdom

> 标签: BSD-3-Clause, c++, conan, urdfdom, vcpkg

## 简介

Provides core data structures and a simple XML parsers for populating the class data structures from an URDF file.

Conan Center 收录：Data structures and parsers to access URDF files using the DOM model

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
