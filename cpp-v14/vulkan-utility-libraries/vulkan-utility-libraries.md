# vulkan-utility-libraries

> 标签: Apache-2.0, c++, conan, vcpkg, vulkan-utility-libraries

## 简介

Utility libraries for Vulkan developers

Conan Center 收录：The Vulkan-ValidationLayers contained many libraries and utilities that were useful for other Vulkan repositories.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
