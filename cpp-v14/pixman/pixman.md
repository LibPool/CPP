# pixman

> 标签: MIT AND BSD-2-Clause, c++, conan, pixman, vcpkg

## 简介

Pixman is a low-level software library for pixel manipulation, providing features such as image compositing and trapezoid rasterization.

Conan Center 收录：Pixman is a low-level software library for pixel manipulation

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
