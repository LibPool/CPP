# termcolor

> 标签: BSD-3-Clause, c++, conan, termcolor, vcpkg

## 简介

Termcolor is a header-only C++ library for printing colored messages to the terminal.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
