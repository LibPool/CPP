# libmodbus

> 标签: LGPL-2.1, LGPL-2.1-or-later, c++, conan, libmodbus, vcpkg

## 简介

libmodbus is a free software library to send/receive data with a device which respects the Modbus protocol

Conan Center 收录：libmodbus is a free software library to send/receive data according to the Modbus protocol

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
