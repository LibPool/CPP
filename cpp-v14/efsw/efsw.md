# efsw

> 标签: MIT, MIT AND Zlib, c++, conan, efsw, vcpkg

## 简介

efsw is a C++ cross-platform file system watcher and notifier.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/efsw
- Conan Center：https://conan.io/center/recipes/efsw
- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/efsw
