# appstream-glib

> 标签: LGPL-2.1-or-later, appstream-glib, c++, vcpkg

## 简介

Provides GObjects and helper methods to make it easy to read and write AppStream metadata.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
