# sqlite-orm

> 标签: AGPL-3.0-or-later OR MIT, c++, sqlite-orm, vcpkg

## 简介

SQLite ORM light header only library for modern C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
