# evpp

> 标签: c++, evpp, vcpkg

## 简介

A modern C++ network library based on libevent for developing high performance network services in TCP/UDP/HTTP protocols.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
