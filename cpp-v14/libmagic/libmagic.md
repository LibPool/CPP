# libmagic

> 标签: BSD-2-Clause, DocumentRef-COPYING:LicenseRef-BSD-2-Clause-File, c++, conan, libmagic, vcpkg

## 简介

This library can be used to classify files according to magic number tests.

Conan Center 收录：Magic number recognition library - detect files with data in particular fixed formats.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
