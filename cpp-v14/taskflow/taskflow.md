# taskflow

> 标签: MIT, c++, conan, taskflow, vcpkg

## 简介

A General-purpose Task-parallel Programming System using Modern C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
