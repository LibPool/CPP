# etl

> 标签: MIT, c++, etl, vcpkg

## 简介

A C++ template library for embedded applications

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
