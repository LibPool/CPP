# libxfont

> 标签: c++, libxfont, vcpkg

## 简介

X font handling library for server & utilities

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.freedesktop.org/xorg/lib/libxfont
- vcpkg 端口：https://vcpkg.io/en/packages/libxfont
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libxfont
