# libsass

> 标签: MIT, c++, conan, libsass, vcpkg

## 简介

LibSass - Sass compiler written in C++

Conan Center 收录：A C/C++ implementation of a Sass compiler

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
