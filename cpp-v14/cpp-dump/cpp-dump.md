# cpp-dump

> 标签: MIT, c++, conan, cpp-dump

## 简介

Conan Center 收录：An all-round dump function library for C++ that can print any type, even user-defined types.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
