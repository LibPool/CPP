# libmultisense

> 标签: c++, libmultisense, vcpkg

## 简介

A C++ library for interfacing with the MultiSense S family of sensors from Carnegie Robotics.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/carnegierobotics/LibMultiSense
- vcpkg 端口：https://vcpkg.io/en/packages/libmultisense
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libmultisense
