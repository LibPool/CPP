# rttr

> 标签: MIT, c++, conan, rttr, vcpkg

## 简介

an easy and intuitive way to use reflection in C++

Conan Center 收录：Run Time Type Reflection library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
