# msgpack-c

> 标签: BSL-1.0, c++, conan, msgpack-c, vcpkg

## 简介

MessagePack is an efficient binary serialization format, which lets you exchange data among multiple languages like JSON, except that it's faster and smaller.

Conan Center 收录：MessagePack implementation for C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
