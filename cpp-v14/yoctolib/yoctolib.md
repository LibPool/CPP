# yoctolib

> 标签: c++, vcpkg, yoctolib

## 简介

Official Yoctopuce Library for C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/yoctopuce/yoctolib_cpp
- vcpkg 端口：https://vcpkg.io/en/packages/yoctolib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/yoctolib
