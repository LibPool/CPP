# tinycthread

> 标签: c++, tinycthread, vcpkg

## 简介

Small, portable implementation of the C11 threads API

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
