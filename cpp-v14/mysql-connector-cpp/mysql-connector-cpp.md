# mysql-connector-cpp

> 标签: GPL-2.0-only WITH Universal-FOSS-exception-1.0, c++, conan, mysql-connector-cpp, vcpkg

## 简介

This is a release of MySQL Connector/C++, the C++ interface for communicating with MySQL servers.

Conan Center 收录：MySQL database connector for C++ applications

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
