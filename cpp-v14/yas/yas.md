# yas

> 标签: c++, vcpkg, yas

## 简介

Yet Another Serialization is a header only serialization library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
