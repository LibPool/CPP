# reaction

> 标签: MIT, c++, reaction, vcpkg

## 简介

A lightweight, header-only, high-performance reactive programming framework for C++20

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
