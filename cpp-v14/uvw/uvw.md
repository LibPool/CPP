# uvw

> 标签: MIT, c++, uvw, vcpkg

## 简介

A compilable static library, event based, tiny and easy to use libuv wrapper in modern C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
