# xmlsec

> 标签: X11 AND MPL-1.1, c++, conan, vcpkg, xmlsec

## 简介

XML Security Library is a C library based on LibXML2. The library supports major XML security standards.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
