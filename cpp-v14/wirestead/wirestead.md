# wirestead

> 标签: Apache-2.0, c++, vcpkg, wirestead

## 简介

Unified, cross-platform async C++ library for Serial, TCP, UDP, and UDS

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
