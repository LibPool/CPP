# wolfmqtt

> 标签: GPL-3.0-or-later, c++, vcpkg, wolfmqtt

## 简介

MQTT library used with wolfSSL library for many platforms

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
