# wtl

> 标签: MS-PL, c++, conan, vcpkg, wtl

## 简介

Windows Template Library (WTL) is a C++ library for developing Windows applications and UI components.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
