# wtl

> 标签: MS-PL, c++, vcpkg, wtl

## 简介

Windows Template Library (WTL) is a C++ library for developing Windows applications and UI components.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://sourceforge.net/projects/wtl/
- vcpkg 端口：https://vcpkg.io/en/packages/wtl
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/wtl
