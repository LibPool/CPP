# libphonenumber

> 标签: Apache-2.0, c++, conan, libphonenumber, vcpkg

## 简介

Google's common Java, C++ and JavaScript library for parsing, formatting, and validating international phone numbers.

Conan Center 收录：Google's common C++ library for parsing, formatting, and validating international phone numbers

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
