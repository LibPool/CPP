# nativefiledialog

> 标签: Zlib, c++, conan, nativefiledialog

## 简介

Conan Center 收录：A tiny, neat C library that portably invokes native file open and save dialogs.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
