# nt-wrapper

> 标签: c++, nt-wrapper, vcpkg

## 简介

A header only wrapper library around native windows system APIs

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
