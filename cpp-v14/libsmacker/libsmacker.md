# libsmacker

> 标签: LGPL-2.1-or-later, c++, conan, libsmacker, vcpkg

## 简介

libsmacker is a cross-platform C library which can be used for decoding Smacker Video files produced by RAD Game Tools

Conan Center 收录：A C library for decoding .smk Smacker Video files

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
