# libsmacker

> 标签: LGPL-2.1-or-later, c++, libsmacker, vcpkg

## 简介

libsmacker is a cross-platform C library which can be used for decoding Smacker Video files produced by RAD Game Tools

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://libsmacker.sourceforge.net
- vcpkg 端口：https://vcpkg.io/en/packages/libsmacker
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libsmacker
