# darknet

> 标签: Apache-2.0 AND BSD-2-Clause, YOLO, c++, conan, darknet, vcpkg

## 简介

Darknet is an open source neural network framework written in C and CUDA for processing images or video frames in computer vision.

Conan Center 收录：Darknet is a neural network frameworks written in C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
