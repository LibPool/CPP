# libxcvt

> 标签: c++, libxcvt, vcpkg

## 简介

A library providing a standalone version of the X server implementation of the VESA CVT standard timing modelines generator.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.freedesktop.org/xorg/lib/libxcvt
- vcpkg 端口：https://vcpkg.io/en/packages/libxcvt
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libxcvt
