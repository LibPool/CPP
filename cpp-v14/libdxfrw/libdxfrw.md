# libdxfrw

> 标签: GPL-2.0-only, GPL-2.0-or-later, c++, conan, libdxfrw, vcpkg

## 简介

libdxfrw is a free C++ library to read and write DXF files in both formats, ascii and binary form. It also has rudimentary capabilities to read DWG files.

Conan Center 收录：C++ library to read/write DXF and read DWG files

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
