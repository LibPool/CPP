# dpetkov-semver

> 标签: BSD-2-Clause, c++, dpetkov-semver, vcpkg

## 简介

C++20 Semantic Versioning Library — a faithful translation of python-semanticversion, with deprecated features removed.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
