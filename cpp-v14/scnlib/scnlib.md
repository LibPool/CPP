# scnlib

> 标签: Apache-2.0, c++, conan, scnlib, vcpkg

## 简介

scnlib is a modern C++ library for replacing scanf and std::istream

Conan Center 收录：scanf for modern C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
