# libffi

> 标签: MIT, c++, libffi, vcpkg

## 简介

Portable, high level programming interface to various calling conventions

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
