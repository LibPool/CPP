# libconfuse

> 标签: ISC, c++, conan, libconfuse, vcpkg

## 简介

Small configuration file parser library for C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
