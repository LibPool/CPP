# libxscrnsaver

> 标签: c++, libxscrnsaver, vcpkg

## 简介

Xlib-based X11 Screen Saver extension client library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.freedesktop.org/xorg/lib/libxscrnsaver
- vcpkg 端口：https://vcpkg.io/en/packages/libxscrnsaver
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libxscrnsaver
