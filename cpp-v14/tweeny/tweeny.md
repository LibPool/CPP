# tweeny

> 标签: MIT, c++, conan, tweeny, vcpkg

## 简介

A modern C++ tweening library

Conan Center 收录：Tweeny is an inbetweening library designed for the creation of complex animations for games and other beautiful interactive software

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
