# libsbml

> 标签: c++, libsbml, vcpkg

## 简介

A library for reading / writing SBML files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/sbmlteam/libsbml
- vcpkg 端口：https://vcpkg.io/en/packages/libsbml
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libsbml
