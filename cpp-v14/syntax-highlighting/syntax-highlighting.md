# syntax-highlighting

> 标签: c++, syntax-highlighting, vcpkg

## 简介

Syntax highlighting engine for Kate syntax definitions

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
