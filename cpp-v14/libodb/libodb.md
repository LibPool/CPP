# libodb

> 标签: c++, libodb, vcpkg

## 简介

ODB library, base runtime for the ODB ORM solution

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
