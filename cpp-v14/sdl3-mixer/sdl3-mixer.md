# sdl3-mixer

> 标签: Zlib, c++, sdl3-mixer, vcpkg

## 简介

An audio mixer that supports various file formats for Simple Directmedia Layer.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/libsdl-org/SDL_mixer
- vcpkg 端口：https://vcpkg.io/en/packages/sdl3-mixer
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/sdl3-mixer
