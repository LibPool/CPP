# chartdir

> 标签: c++, chartdir, vcpkg

## 简介

ChartDirector is a powerful chart component for creating professional looking charts for web and windows applications.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
