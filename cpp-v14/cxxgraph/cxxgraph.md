# cxxgraph

> 标签: MPL-2.0, c++, conan, cxxgraph, vcpkg

## 简介

CXXGraph is a header only comprehensive C++ graph library.

Conan Center 收录：Header-Only C++ Library for Graph Representation and Algorithms

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
