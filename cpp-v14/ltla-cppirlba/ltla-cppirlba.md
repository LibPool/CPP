# ltla-cppirlba

> 标签: MIT, c++, ltla-cppirlba, vcpkg

## 简介

A C++ port of the IRLBA algorithm, based on the C code in the R package.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/LTLA/CppIrlba
