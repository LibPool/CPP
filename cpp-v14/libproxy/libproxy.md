# libproxy

> 标签: LGPL-2.1-only, c++, libproxy, vcpkg

## 简介

libproxy is a library that provides automatic proxy configuration management.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
