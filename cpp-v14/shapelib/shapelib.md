# shapelib

> 标签: MIT OR LGPL-2.0-or-later, c++, shapelib, vcpkg

## 简介

Shapefile C Library is simple C API for reading and writing ESRI Shapefiles

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://download.osgeo.org/shapelib
- vcpkg 端口：https://vcpkg.io/en/packages/shapelib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/shapelib
