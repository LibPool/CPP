# tomlplusplus

> 标签: MIT, c++, tomlplusplus, vcpkg

## 简介

Header-only TOML config file parser and serializer for modern C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://marzer.github.io/tomlplusplus/
- vcpkg 端口：https://vcpkg.io/en/packages/tomlplusplus
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tomlplusplus
