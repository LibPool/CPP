# glibmm

> 标签: LGPL-2.1-or-later, c++, glibmm, vcpkg

## 简介

This is glibmm, a C++ API for parts of glib that are useful for C++.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.gtkmm.org.
- vcpkg 端口：https://vcpkg.io/en/packages/glibmm
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/glibmm
