# argtable3

> 标签: BSD-3-Clause AND TCL, argtable3, c++, vcpkg

## 简介

A single-file, ANSI C, command-line parsing library that parses GNU-style command-line options

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
