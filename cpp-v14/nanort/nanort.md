# nanort

> 标签: c++, nanort, vcpkg

## 简介

Single header only modern ray tracing kernel

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/lighttransport/nanort
- vcpkg 端口：https://vcpkg.io/en/packages/nanort
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/nanort
