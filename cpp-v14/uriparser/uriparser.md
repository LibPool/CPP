# uriparser

> 标签: BSD-3-Clause, c++, uriparser, vcpkg

## 简介

Strictly RFC 3986 compliant URI parsing and handling library written in C89.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
