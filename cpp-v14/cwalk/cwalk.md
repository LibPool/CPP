# cwalk

> 标签: MIT, c++, conan, cwalk, vcpkg

## 简介

Path library for C/C++. Cross-Platform for Windows, MacOS and Linux. Supports UNIX and Windows path styles on those platforms.

Conan Center 收录：Path library for C/C++. Cross-Platform for Windows,

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
