# fast-cpp-csv-parser

> 标签: BSD-3-Clause, c++, conan, fast-cpp-csv-parser, vcpkg

## 简介

A small, easy-to-use and fast header-only library for reading comma separated value (CSV) files

Conan Center 收录：C++11 header-only library for reading comma separated value (CSV) files.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
