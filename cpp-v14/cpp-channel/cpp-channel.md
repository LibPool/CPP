# cpp-channel

> 标签: MIT, c++, conan, cpp-channel, vcpkg

## 简介

C++11 thread-safe container for sharing data between threads (synchronized queue)

Conan Center 收录：Thread-safe container for sharing data between threads

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
