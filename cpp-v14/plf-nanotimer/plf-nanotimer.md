# plf-nanotimer

> 标签: Zlib, c++, plf-nanotimer, vcpkg

## 简介

A simple C++ 03/11/etc timer class for ~microsecond-precision cross-platform benchmarking

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
