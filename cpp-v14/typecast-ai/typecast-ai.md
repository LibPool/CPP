# typecast-ai

> 标签: MIT, c++, typecast-ai, vcpkg

## 简介

Text-to-Speech API client library for Typecast AI. Pure C with optional C++ wrapper.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
