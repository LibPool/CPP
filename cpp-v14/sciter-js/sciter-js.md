# sciter-js

> 标签: c++, sciter-js, vcpkg

## 简介

Sciter.JS - Sciter but with QuickJS on board instead of TIScript. Sciter is an embeddable HTML/CSS/scripting engine.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://gitlab.com/sciter-engine/sciter-js-sdk
- vcpkg 端口：https://vcpkg.io/en/packages/sciter-js
