# qhttpengine

> 标签: c++, qhttpengine, vcpkg

## 简介

HTTP server for Qt applications

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/qhttpengine
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/qhttpengine
