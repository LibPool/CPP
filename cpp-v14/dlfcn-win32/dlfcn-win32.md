# dlfcn-win32

> 标签: MIT, c++, dlfcn-win32, vcpkg

## 简介

dlfcn-win32 is an implementation of dlfcn for Windows.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/dlfcn-win32/dlfcn-win32
- vcpkg 端口：https://vcpkg.io/en/packages/dlfcn-win32
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/dlfcn-win32
