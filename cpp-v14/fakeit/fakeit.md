# fakeit

> 标签: MIT, c++, conan, fakeit, vcpkg

## 简介

FakeIt is a simple mocking framework for C++. It supports GCC, Clang and MS Visual C++.

Conan Center 收录：C++ mocking made easy. A simple yet very expressive, headers only library for c++ mocking.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
