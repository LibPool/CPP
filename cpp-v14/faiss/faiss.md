# faiss

> 标签: MIT, c++, faiss, vcpkg

## 简介

Faiss is a library for efficient similarity search and clustering of dense vectors.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
