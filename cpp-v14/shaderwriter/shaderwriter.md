# shaderwriter

> 标签: MIT, c++, shaderwriter, vcpkg

## 简介

Library to write shaders directly from C++ code, supports GLSL, HLSL and SPIRV outputs.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/DragonJoker/ShaderWriter
- vcpkg 端口：https://vcpkg.io/en/packages/shaderwriter
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/shaderwriter
