# elfio

> 标签: MIT, c++, elfio, vcpkg

## 简介

A header-only C++ library intended for reading and generating files in the ELF binary format.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
