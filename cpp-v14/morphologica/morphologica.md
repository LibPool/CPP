# morphologica

> 标签: Apache-2.0, c++, morphologica, vcpkg

## 简介

C++ header-only graphing and data visualization with Modern OpenGL

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
