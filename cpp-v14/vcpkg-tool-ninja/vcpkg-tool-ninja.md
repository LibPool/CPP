# vcpkg-tool-ninja

> 标签: Apache-2.0, c++, vcpkg, vcpkg-tool-ninja

## 简介

Ninja is a small build system with a focus on speed.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
