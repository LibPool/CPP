# pravila00-enum-string

> 标签: Unlicense, c++, pravila00-enum-string, vcpkg

## 简介

A utility to provide stringizing support for C++ enums.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
