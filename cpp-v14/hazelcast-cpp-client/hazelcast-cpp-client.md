# hazelcast-cpp-client

> 标签: Apache-2.0, c++, hazelcast-cpp-client, vcpkg

## 简介

C++ client library for Hazelcast in-memory database.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/hazelcast/hazelcast-cpp-client
- vcpkg 端口：https://vcpkg.io/en/packages/hazelcast-cpp-client
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/hazelcast-cpp-client
