# box2d

> 标签: Zlib, box2d, c++, conan, vcpkg

## 简介

An open source C++ engine for simulating rigid bodies in 2D

Conan Center 收录：Box2D is a 2D physics engine for games

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
