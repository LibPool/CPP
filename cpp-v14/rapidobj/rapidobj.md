# rapidobj

> 标签: MIT, c++, rapidobj, vcpkg

## 简介

A fast, header-only, C++17 library for parsing Wavefront .obj files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/rapidobj
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/rapidobj
