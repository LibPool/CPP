# kcrash

> 标签: c++, kcrash, vcpkg

## 简介

KCrash provides support for intercepting and handling application crashes.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://invent.kde.org/frameworks/kcrash
- vcpkg 端口：https://vcpkg.io/en/packages/kcrash
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/kcrash
