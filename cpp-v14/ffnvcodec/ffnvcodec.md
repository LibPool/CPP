# ffnvcodec

> 标签: c++, ffnvcodec, vcpkg

## 简介

FFmpeg version of Nvidia Codec SDK headers.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/FFmpeg/nv-codec-headers
- vcpkg 端口：https://vcpkg.io/en/packages/ffnvcodec
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/ffnvcodec
