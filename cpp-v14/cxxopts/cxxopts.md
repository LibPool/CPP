# cxxopts

> 标签: MIT, c++, cxxopts, vcpkg

## 简介

A lightweight C++ option parser library, supporting the standard GNU style syntax for options

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
