# calceph

> 标签: CECILL-2.1 OR CECILL-B OR CECILL-C, c++, calceph, vcpkg

## 简介

C library to access the binary planetary ephemeris files.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
