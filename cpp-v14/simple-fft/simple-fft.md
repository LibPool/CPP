# simple-fft

> 标签: c++, simple-fft, vcpkg

## 简介

Header-only C++ library implementing fast Fourier transform of 1D, 2D and 3D data

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/d1vanov/Simple-FFT

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/simple-fft
