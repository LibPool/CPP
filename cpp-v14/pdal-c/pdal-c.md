# pdal-c

> 标签: c++, pdal-c, vcpkg

## 简介

C API for the Point Data Abstraction Library (PDAL)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
