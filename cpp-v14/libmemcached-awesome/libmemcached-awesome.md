# libmemcached-awesome

> 标签: BSD-3-Clause, c++, libmemcached-awesome, vcpkg

## 简介

Open source C/C++ client library and tools for the memcached server

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
