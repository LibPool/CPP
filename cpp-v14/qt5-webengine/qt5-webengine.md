# qt5-webengine

> 标签: c++, qt5-webengine, vcpkg

## 简介

Qt WebEngine provides functionality for rendering regions of dynamic web content.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
