# mongo-c-driver

> 标签: Apache-2.0, c++, conan, mongo-c-driver, vcpkg

## 简介

Client library written in C for MongoDB.

Conan Center 收录：A Cross Platform MongoDB Client Library for C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
