# symengine

> 标签: BSD-3-Clause, MIT, c++, conan, symengine, vcpkg

## 简介

SymEngine is a fast symbolic manipulation library

Conan Center 收录：A fast symbolic manipulation library, written in C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
