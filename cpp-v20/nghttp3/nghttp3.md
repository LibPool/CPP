# nghttp3

> 标签: MIT, c++, conan, nghttp3, vcpkg

## 简介

Implementation of RFC 9114 HTTP/3 mapping over QUIC and RFC 9204 QPACK in C

Conan Center 收录：HTTP/3 library written in C

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
