# nghttp3

> 标签: MIT, c++, nghttp3, vcpkg

## 简介

Implementation of RFC 9114 HTTP/3 mapping over QUIC and RFC 9204 QPACK in C

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/ngtcp2/nghttp3
- vcpkg 端口：https://vcpkg.io/en/packages/nghttp3
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/nghttp3
