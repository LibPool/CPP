# libb2

> 标签: c++, libb2, vcpkg

## 简介

C library providing BLAKE2b, BLAKE2s, BLAKE2bp, BLAKE2sp

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://github.com/BLAKE2/libb2
- vcpkg 端口：https://vcpkg.io/en/packages/libb2
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libb2
