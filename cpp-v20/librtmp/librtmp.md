# librtmp

> 标签: c++, librtmp, vcpkg

## 简介

RTMPDump Real-Time Messaging Protocol API

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
