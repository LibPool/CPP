# tdscpp

> 标签: LGPL-3.0, c++, tdscpp, vcpkg

## 简介

C++ library to communicate with Microsoft SQL Server

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/maharmstone/tdscpp
- vcpkg 端口：https://vcpkg.io/en/packages/tdscpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tdscpp
