# cairomm

> 标签: LGPL-2.0-only, c++, cairomm, vcpkg

## 简介

A C++ wrapper for the cairo graphics library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
