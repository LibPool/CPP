# cairomm

> 标签: LGPL-2.0, LGPL-2.0-only, c++, cairomm, conan, vcpkg

## 简介

A C++ wrapper for the cairo graphics library

Conan Center 收录：cairomm is a C++ wrapper for the cairo graphics library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
