# libxcomposite

> 标签: c++, libxcomposite, vcpkg

## 简介

Xlib-based client library for the Composite extension to the X11 protocol

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
