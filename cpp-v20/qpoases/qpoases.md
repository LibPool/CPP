# qpoases

> 标签: LGPL-2.1-only, c++, qpoases, vcpkg

## 简介

Open-source C++ implementation of the online active set strategy for quadratic programming

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/coin-or/qpOASES
- vcpkg 端口：https://vcpkg.io/en/packages/qpoases
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/qpoases
