# elfutils

> 标签: c++, conan, elfutils, vcpkg

## 简介

elfutils is a collection of utilities and libraries to read, create and modify ELF binary files, find and handle DWARF debug data, symbols, thread state and stacktraces for processes and core files on GNU/Linux.

Conan Center 收录：A dwarf, dwfl and dwelf functions to read DWARF, find separate debuginfo, symbols and inspect process state.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
