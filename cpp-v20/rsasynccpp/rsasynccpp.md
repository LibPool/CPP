# rsasynccpp

> 标签: c++, rsasynccpp, vcpkg

## 简介

Task Parallel Library (TPL)/dataflow/actors/async primitives for C++ based on C++ 20 coroutines.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/renestein/Rstein.AsyncCpp
- vcpkg 端口：https://vcpkg.io/en/packages/rsasynccpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/rsasynccpp
