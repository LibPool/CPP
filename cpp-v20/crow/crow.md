# crow

> 标签: BSD-3-Clause, BSD-3-Clause AND MIT AND ISC, c++, conan, crow, vcpkg

## 简介

Very fast and easy to use C++ micro web framework

Conan Center 收录：Crow is C++ microframework for web. (inspired by Python Flask)

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
