# libdmx

> 标签: MIT, c++, libdmx, vcpkg

## 简介

X Window System DMX (Distributed Multihead X) extension library

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/libdmx
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libdmx
