# glpk

> 标签: GPL-3.0-or-later, c++, conan, glpk, vcpkg

## 简介

The GNU Linear Programming Kit (GLPK) solves large-scale linear programming (LP), mixed integer programming (MIP), and related problems.
GLPK includes the following main components:
Primal and dual simplex methods
Primal-dual interior-point method
Branch-and-cut method
Translator for GNU MathProg
Application program interface (API)
Stand-alone LP/MIP solver

Conan Center 收录：GNU Linear Programming Kit

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
