# mmloader

> 标签: MIT, c++, mmloader, vcpkg

## 简介

A library for loading dll module bypassing windows PE loader from memory (x86/x64)

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://tishion.github.io/mmLoader/
- vcpkg 端口：https://vcpkg.io/en/packages/mmloader
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mmloader
