# libgpg-error

> 标签: GPL-2.0-or-later, LGPL-2.1-or-later, c++, conan, libgpg-error, vcpkg

## 简介

A runtime library for GnuPG and other software which likes to use it.

Conan Center 收录：Libgpg-error is a small library that originally defined common error values for all GnuPG

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
