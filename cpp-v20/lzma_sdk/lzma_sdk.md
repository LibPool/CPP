# lzma_sdk

> 标签: c++, conan, lzma_sdk

## 简介

Conan Center 收录：LZMA provides a high compression ratio and fast decompression, so it is very suitable for embedded applications.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
