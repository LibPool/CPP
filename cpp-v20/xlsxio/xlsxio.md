# xlsxio

> 标签: MIT, c++, conan, vcpkg, xlsxio

## 简介

Cross-platform C library for reading values from and writing values to .xlsx files

Conan Center 收录：Cross-platform C library for reading values from and writing values to .xlsx files.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
