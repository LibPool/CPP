# tinygltf

> 标签: MIT, MIT AND BSL-1.0 AND Zlib, c++, conan, tinygltf, vcpkg

## 简介

A header-only glTF 2.0 library with a C++11 v2 API and a C++17 v3 API.

Conan Center 收录：Header only C++11 tiny glTF 2.0 library.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
