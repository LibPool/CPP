# libnice

> 标签: LGPL-2.1-only AND MPL-1.1, c++, conan, libnice, vcpkg

## 简介

Libnice is an implementation of the IETF's Interactive Connectivity Establishment (ICE) standard (RFC 5245) and the Session Traversal Utilities for NAT (STUN) standard (RFC 5389).

Conan Center 收录：a GLib ICE implementation

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
