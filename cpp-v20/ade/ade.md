# ade

> 标签: Apache-2.0, ade, c++, conan, vcpkg

## 简介

ADE Framework is a graph construction, manipulation, and processing framework. ADE Framework is suitable for organizing data flow processing and execution.

Conan Center 收录：Graph construction, manipulation, and processing framework

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
