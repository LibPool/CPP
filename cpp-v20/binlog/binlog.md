# binlog

> 标签: Apache-2.0, binlog, c++, vcpkg

## 简介

Binlog is a high performance C++ log library to produce structured binary logs.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://opensource.morganstanley.com/binlog/
- vcpkg 端口：https://vcpkg.io/en/packages/binlog
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/binlog
