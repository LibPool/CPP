# grppi

> 标签: Apache-2.0, c++, grppi, vcpkg

## 简介

GrPPI is an open source generic and reusable parallel pattern programming interface developed at University Carlos III of Madrid.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/arcosuc3m/grppi
- vcpkg 端口：https://vcpkg.io/en/packages/grppi
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/grppi
