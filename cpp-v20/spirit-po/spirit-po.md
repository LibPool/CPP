# spirit-po

> 标签: c++, spirit-po, vcpkg

## 简介

A header-only C++ library for localization using GNU gettext po files, based on Boost.Spirit.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
