# detours

> 标签: MIT, c++, detours, vcpkg

## 简介

Detours is a software package for monitoring and instrumenting API calls on Windows.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
