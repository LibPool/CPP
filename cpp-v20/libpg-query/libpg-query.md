# libpg-query

> 标签: BSD-3-Clause, c++, libpg-query, vcpkg

## 简介

C library for accessing the PostgreSQL parser outside of the server

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
