# ruckig

> 标签: MIT, c++, ruckig, vcpkg

## 简介

Ruckig generates trajectories on-the-fly, allowing robots and machines to react instantaneously to sensor input.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
