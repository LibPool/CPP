# gperf

> 标签: GPL-3.0-or-later, c++, conan, gperf, vcpkg

## 简介

GNU perfect hash function generator

Conan Center 收录：GNU gperf is a perfect hash function generator

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
