# plf-hive

> 标签: Zlib, c++, plf-hive, vcpkg

## 简介

plf::hive is a fork of plf::colony to match the current C++ standards proposal.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://plflib.org/colony.htm
- vcpkg 端口：https://vcpkg.io/en/packages/plf-hive
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/plf-hive
