# ms-gdkx

> 标签: c++, ms-gdkx, vcpkg

## 简介

Stub port that ensures the Microsoft GDK with Xbox Extensions is installed.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
