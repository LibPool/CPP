# libgig

> 标签: GPL-2.0-or-later, c++, libgig, vcpkg

## 简介

C++ library for loading Gigasampler files and DLS Level 1/2 files

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.linuxsampler.org/libgig/
- vcpkg 端口：https://vcpkg.io/en/packages/libgig
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libgig
