# cfitsio

> 标签: c++, cfitsio, conan, vcpkg

## 简介

Library of C and Fortran subroutines for reading and writing data files in FITS (Flexible Image Transport System) data format

Conan Center 收录：C library for reading and writing data files in FITS

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
