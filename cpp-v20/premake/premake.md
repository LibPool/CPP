# premake

> 标签: BSD-3-Clause, c++, conan, premake

## 简介

C++ 库 premake，由软件包管理器收录。

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网（Conan）：https://premake.github.io
- Conan Center：https://conan.io/center/recipes/premake
- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/premake

## 历史版本号

- 当前版本：5.0.0-beta7

- Conan 5.0.0-beta7

## 获取地址

Conan 安装：`conan install --requires=premake/5.0.0-beta7`
