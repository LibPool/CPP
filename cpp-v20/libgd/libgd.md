# libgd

> 标签: BSD-like, GD, c++, conan, libgd, vcpkg

## 简介

Open source code library for the dynamic creation of images by programmers.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/libgd
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libgd
