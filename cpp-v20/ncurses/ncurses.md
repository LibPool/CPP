# ncurses

> 标签: MIT, X11, c++, conan, ncurses, vcpkg

## 简介

Free software emulation of curses in System V Release 4.0, and more.
This port installs a wide character configuration (ncursesw).

Conan Center 收录：The ncurses (new curses) library is a free software emulation of curses in System V Release 4.0 (SVr4), and more

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
