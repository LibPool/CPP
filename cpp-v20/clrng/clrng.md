# clrng

> 标签: c++, clrng, vcpkg

## 简介

clRNG is a library for uniform random number generation in OpenCL.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/clMathLibraries/clRNG
- vcpkg 端口：https://vcpkg.io/en/packages/clrng
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/clrng
