# mapnik

> 标签: LGPL-2.1-only, c++, mapnik, vcpkg

## 简介

Mapnik is an open source toolkit for developing mapping applications.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/mapnik/mapnik
- vcpkg 端口：https://vcpkg.io/en/packages/mapnik
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/mapnik
