# kaitai-struct-cpp-stl-runtime

> 标签: MIT, c++, kaitai-struct-cpp-stl-runtime, vcpkg

## 简介

Kaitai Struct is a declarative language used for describe various binary data structures, laid out in files or in memory. This library implements Kaitai Struct API for C++ using STL

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
