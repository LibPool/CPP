# libgossip

> 标签: MIT, c++, libgossip, vcpkg

## 简介

A C++17 implementation of the Gossip protocol, designed for decentralized distributed systems.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
