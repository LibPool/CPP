# any-lite

> 标签: any-lite, c++, vcpkg

## 简介

A C++17-like any, a type-safe container for single values of any type for C++98, C++11 and later in a single-file header-only library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
