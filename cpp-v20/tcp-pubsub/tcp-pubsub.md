# tcp-pubsub

> 标签: MIT, c++, tcp-pubsub, vcpkg

## 简介

TCP based publish-subscribe library for C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
