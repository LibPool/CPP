# robin-map

> 标签: MIT, c++, robin-map, vcpkg

## 简介

A C++ implementation of a fast hash map and hash set using robin hood hashing

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
