# poppler-data

> 标签: BSD-3-Clause, c++, conan, poppler-data, vcpkg

## 简介

This package consists of encoding files for use with poppler.

Conan Center 收录：encoding files for use with poppler, enable CJK and Cyrrilic

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
