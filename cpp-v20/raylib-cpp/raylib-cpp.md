# raylib-cpp

> 标签: Zlib, c++, raylib-cpp, vcpkg

## 简介

C++ Object Oriented Wrapper for raylib

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
