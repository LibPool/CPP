# whereami

> 标签: MIT OR WTFPL, c++, conan, vcpkg, whereami

## 简介

A drop-in two files library to locate the current executable and the current module on the file system.

Conan Center 收录：Locate the current executable and the current module/library on the file system

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
