# crc32c

> 标签: BSD-3-Clause, c++, crc32c, vcpkg

## 简介

CRC32C implementation with support for CPU-specific acceleration instructions.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
