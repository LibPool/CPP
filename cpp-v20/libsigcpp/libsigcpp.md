# libsigcpp

> 标签: LGPL-3.0-only, LGPL-3.0-or-later, c++, conan, libsigcpp, vcpkg

## 简介

Typesafe callback framework for C++

Conan Center 收录：libsigc++ implements a typesafe callback system for standard C++.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
