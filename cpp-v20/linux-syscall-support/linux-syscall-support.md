# linux-syscall-support

> 标签: BSD-3-Clause, c++, conan, linux-syscall-support

## 简介

Conan Center 收录：Linux Syscall Support provides a header file that can be included into your application whenever you need to make direct system calls.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
