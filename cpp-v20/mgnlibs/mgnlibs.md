# mgnlibs

> 标签: MIT, c++, mgnlibs, vcpkg

## 简介

Single-file public domain libraries for C/C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
