# retropak

> 标签: CC0-1.0, c++, retropak, vcpkg

## 简介

A modern container format for retro software preservation. Provides JSON schema and metadata specification for Retropak software containers.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://retropak.org
- vcpkg 端口：https://vcpkg.io/en/packages/retropak
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/retropak
