# iceberg-cpp

> 标签: Apache-2.0, c++, iceberg-cpp, vcpkg

## 简介

C++ implementation of Apache Iceberg

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/apache/iceberg-cpp
- vcpkg 端口：https://vcpkg.io/en/packages/iceberg-cpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/iceberg-cpp
