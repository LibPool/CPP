# autodiff

> 标签: MIT, autodiff, c++, vcpkg

## 简介

A modern, fast and expressive C++ library for automatic differentiation.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- vcpkg 端口：https://vcpkg.io/en/packages/autodiff
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/autodiff
