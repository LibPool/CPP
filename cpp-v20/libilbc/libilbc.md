# libilbc

> 标签: BSD-3-Clause, c++, libilbc, vcpkg

## 简介

Open source implementation of the Internet Low Bit Rate Codec (iLBC) / RFC 3951 codec from the WebRTC project.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/TimothyGu/libilbc
- vcpkg 端口：https://vcpkg.io/en/packages/libilbc
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libilbc
