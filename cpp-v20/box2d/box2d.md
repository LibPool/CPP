# box2d

> 标签: box2d, c++, vcpkg

## 简介

An open source C++ engine for simulating rigid bodies in 2D

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://box2d.org
- vcpkg 端口：https://vcpkg.io/en/packages/box2d
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/box2d
