# serd

> 标签: ISC, c++, conan, serd, vcpkg

## 简介

Serd is a lightweight C library for RDF syntax which supports reading and writing Turtle, TRiG, NTriples, and NQuads.

Conan Center 收录：A lightweight C library for RDF syntax

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
