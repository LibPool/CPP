# wukong-easy-sdk

> 标签: MIT, c++, vcpkg, wukong-easy-sdk

## 简介

C++17 WebSocket JSON-RPC client for WuKongIM

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
