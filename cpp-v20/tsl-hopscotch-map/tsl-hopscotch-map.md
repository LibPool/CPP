# tsl-hopscotch-map

> 标签: MIT, c++, conan, tsl-hopscotch-map, vcpkg

## 简介

C++ implementation of a fast hash map and hash set using hopscotch hashing

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
