# libnatpmp

> 标签: BSD-3-Clause, c++, libnatpmp, vcpkg

## 简介

A client-side NAT traversal library implementing the NAT-PMP protocol

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
