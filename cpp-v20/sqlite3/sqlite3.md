# sqlite3

> 标签: Unlicense, blessing, c++, conan, sqlite3, vcpkg

## 简介

SQLite is a software library that implements a self-contained, serverless, zero-configuration, transactional SQL database engine.

Conan Center 收录：Self-contained, serverless, in-process SQL database engine.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
