# sintra

> 标签: BSD-2-Clause, c++, sintra, vcpkg

## 简介

Header-only C++20 IPC library using shared-memory ring buffers.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
