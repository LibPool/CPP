# openigtlink

> 标签: c++, openigtlink, vcpkg

## 简介

OpenIGTLink is an open-source network communication interface specifically designed for image-guided interventions.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/openigtlink/OpenIGTLink
- vcpkg 端口：https://vcpkg.io/en/packages/openigtlink
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/openigtlink
