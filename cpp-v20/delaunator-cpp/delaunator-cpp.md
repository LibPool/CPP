# delaunator-cpp

> 标签: MIT, c++, delaunator-cpp, vcpkg

## 简介

A really fast C++ library for Delaunay triangulation of 2D points

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
