# rtmidi

> 标签: MIT, MIT+send-patches-upstream, c++, conan, rtmidi, vcpkg

## 简介

A set of C++ classes that provide a common API for realtime MIDI input/output across Linux (ALSA & JACK), Macintosh OS X (CoreMidi & JACK) and Windows (Multimedia)

Conan Center 收录：Realtime MIDI input/output

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
