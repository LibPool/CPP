# fast-cpp-csv-parser

> 标签: BSD-3-Clause, c++, fast-cpp-csv-parser, vcpkg

## 简介

A small, easy-to-use and fast header-only library for reading comma separated value (CSV) files

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
