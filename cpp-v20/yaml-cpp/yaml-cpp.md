# yaml-cpp

> 标签: MIT, c++, vcpkg, yaml-cpp

## 简介

yaml-cpp is a YAML parser and emitter in C++ matching the YAML 1.2 spec.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
