# efsw

> 标签: MIT AND Zlib, c++, efsw, vcpkg

## 简介

efsw is a C++ cross-platform file system watcher and notifier.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/SpartanJ/efsw
- vcpkg 端口：https://vcpkg.io/en/packages/efsw
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/efsw
