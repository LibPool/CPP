# mdnsresponder

> 标签: Apache-2.0, c++, conan, mdnsresponder, vcpkg

## 简介

The mDNSResponder project is a component of Bonjour, Apple's ease-of-use IP networking initiative.

Conan Center 收录：Apple Open Source DNS Service Discovery Collection

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
