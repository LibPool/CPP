# jbigkit

> 标签: c++, jbigkit, vcpkg

## 简介

A software implementation of the JBIG1 data compression standard (ITU-T T.82)

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.cl.cam.ac.uk/~mgk25/jbigkit
- vcpkg 端口：https://vcpkg.io/en/packages/jbigkit
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/jbigkit
