# cpu_features

> 标签: Apache-2.0, c++, conan, cpu_features

## 简介

Conan Center 收录：A cross platform C99 library to get cpu features at runtime.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网（Conan）：https://github.com/google/cpu_features

- Conan recipe 源码：https://github.com/conan-io/conan-center-index/tree/master/recipes/cpu_features
