# mfl

> 标签: MIT, c++, mfl, vcpkg

## 简介

Computes the layout information for mathematical formulas provided in TeX-like syntax.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
