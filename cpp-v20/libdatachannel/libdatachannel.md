# libdatachannel

> 标签: MPL-2.0, c++, conan, libdatachannel, vcpkg

## 简介

libdatachannel is a standalone implementation of WebRTC Data Channels, WebRTC Media Transport, and WebSockets in C++17 with C bindings for POSIX platforms (including GNU/Linux, Android, and Apple macOS) and Microsoft Windows.

Conan Center 收录：C/C++ WebRTC network library featuring Data Channels, Media Transport, and WebSockets.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
