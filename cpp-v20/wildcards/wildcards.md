# wildcards

> 标签: BSL-1.0, c++, conan, vcpkg, wildcards

## 简介

A simple C++ header-only template library implementing matching using wildcards

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
