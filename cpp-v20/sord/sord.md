# sord

> 标签: ISC, c++, sord, vcpkg

## 简介

Sord is a lightweight C library for storing RDF statements in memory.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
