# modern-cpp-kafka

> 标签: Apache-2.0, c++, conan, modern-cpp-kafka, vcpkg

## 简介

A C++ API for Kafka clients (i.e. KafkaProducer, KafkaConsumer, AdminClient)

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
