# odbccpp

> 标签: Apache-2.0, c++, odbccpp, vcpkg

## 简介

An object-oriented C++ wrapper of the ODBC API from SAP

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/SAP/odbc-cpp-wrapper
- vcpkg 端口：https://vcpkg.io/en/packages/odbccpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/odbccpp
