# fftwpp

> 标签: c++, fftwpp, vcpkg

## 简介

FFTW++ is a C++ header/MPI transpose for Version 3 of the highly optimized FFTW (https://www.fftw.org) Fourier Transform library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.fftw.org/
- vcpkg 端口：https://vcpkg.io/en/packages/fftwpp
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/fftwpp
