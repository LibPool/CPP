# astr

> 标签: MPL-2.0, astr, c++, vcpkg

## 简介

Compile-time array string header-only library.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
