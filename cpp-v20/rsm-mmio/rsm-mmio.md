# rsm-mmio

> 标签: MIT, c++, rsm-mmio, vcpkg

## 简介

A cross-platform memory-mapped io library for C++

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- vcpkg 端口：https://vcpkg.io/en/packages/rsm-mmio
