# ensmallen

> 标签: BSD-3-Clause, c++, conan, ensmallen, vcpkg

## 简介

A header-only C++ library for mathematical optimization

Conan Center 收录：ensmallen is a high quality C++ library for non-linear numerical optimization.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
