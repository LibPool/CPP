# spix

> 标签: MIT, c++, spix, vcpkg

## 简介

A minimally invasive UI testing library for Qt/QML applications. Control your application and verify its behavior using a simple C++ API.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
