# libdvdcss

> 标签: GPL-2.0-or-later, c++, libdvdcss, vcpkg

## 简介

Accessing DVDs like a block device library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.videolan.org/developers/libdvdcss.html
- vcpkg 端口：https://vcpkg.io/en/packages/libdvdcss
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libdvdcss
