# 7zip

> 标签: 7zip, LGPL-2.1-or-later, c++, conan, vcpkg

## 简介

Library for archiving file with a high compression ratio.

Conan Center 收录：7-Zip is a file archiver with a high compression ratio

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
