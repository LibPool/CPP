# libmspack

> 标签: c++, libmspack, vcpkg

## 简介

libmspack is a portable library for some loosely related Microsoft compression formats.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
