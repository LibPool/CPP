# libodb-sqlite

> 标签: c++, libodb-sqlite, vcpkg

## 简介

Sqlite support for the ODB ORM library

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
