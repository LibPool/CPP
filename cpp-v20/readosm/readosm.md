# readosm

> 标签: MPL-1.1, c++, conan, readosm, vcpkg

## 简介

ReadOSM is an open source library to extract valid data from within an Open Street Map input file (.osm or .osm.pbf)

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
