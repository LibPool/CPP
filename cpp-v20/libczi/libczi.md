# libczi

> 标签: c++, libczi, vcpkg

## 简介

library to read and write CZI files.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

- 官网：https://github.com/ZEISS/libczi

- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libczi
