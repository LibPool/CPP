# winlamb

> 标签: MIT, c++, vcpkg, winlamb

## 简介

A lightweight modern C++11 library for Win32 API, using lambdas to handle Windows messages.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
