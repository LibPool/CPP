# pkgconf

> 标签: c++, pkgconf, vcpkg

## 简介

pkgconf is a program which helps to configure compiler and linker flags for development libraries. It is similar to pkg-config from freedesktop.org.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/pkgconf/pkgconf
- vcpkg 端口：https://vcpkg.io/en/packages/pkgconf
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/pkgconf
