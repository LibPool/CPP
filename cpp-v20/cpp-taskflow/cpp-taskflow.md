# cpp-taskflow

> 标签: MIT, c++, conan, cpp-taskflow

## 简介

Conan Center 收录：A fast C++ header-only library to help you quickly write parallel programs with complex task dependencies.

本库来自 Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
