# bde

> 标签: Apache-2.0, bde, c++, vcpkg

## 简介

Basic Development Environment - a set of foundational C++ libraries used at Bloomberg.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
