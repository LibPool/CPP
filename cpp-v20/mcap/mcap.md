# mcap

> 标签: MIT, c++, mcap, vcpkg

## 简介

MCAP is a modular, performant, and serialization-agnostic container file format, useful for pub/sub and robotics applications.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
