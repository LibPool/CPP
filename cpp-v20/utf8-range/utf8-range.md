# utf8-range

> 标签: MIT, c++, utf8-range, vcpkg

## 简介

Fast UTF-8 validation with Range algorithm (NEON+SSE4+AVX2)

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
