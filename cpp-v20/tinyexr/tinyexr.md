# tinyexr

> 标签: BSD-3-Clause, c++, tinyexr, vcpkg

## 简介

Library to load and save OpenEXR(.exr) images

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/syoyo/tinyexr
- vcpkg 端口：https://vcpkg.io/en/packages/tinyexr
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tinyexr
