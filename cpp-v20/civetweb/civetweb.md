# civetweb

> 标签: c++, civetweb, vcpkg

## 简介

Easy to use, powerful, C/C++ embeddable web server.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/civetweb/civetweb
- vcpkg 端口：https://vcpkg.io/en/packages/civetweb
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/civetweb
