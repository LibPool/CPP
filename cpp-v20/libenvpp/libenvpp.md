# libenvpp

> 标签: Apache-2.0, c++, libenvpp, vcpkg

## 简介

A modern C++ library for type-safe environment variable parsing

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
