# async-mqtt

> 标签: BSL-1.0, async-mqtt, c++, vcpkg

## 简介

Header-only Asynchronous MQTT communication library for C++17 based on Boost.Asio.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
