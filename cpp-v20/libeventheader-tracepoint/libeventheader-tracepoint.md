# libeventheader-tracepoint

> 标签: MIT, c++, libeventheader-tracepoint, vcpkg

## 简介

C/C++ interface for generating EventHeader-encoded Linux Tracepoints

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
