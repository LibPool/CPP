# opengl-registry

> 标签: c++, opengl-registry, vcpkg

## 简介

OpenGL, OpenGL ES, and OpenGL ES-SC API and Extension Registry

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
