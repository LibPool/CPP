# glaze

> 标签: MIT, c++, conan, glaze, vcpkg

## 简介

One of the fastest JSON libraries in the world. Glaze reads and writes from C++ memory, simplifying interfaces and offering incredible performance.

Conan Center 收录：Extremely fast, in memory, JSON and interface library for modern C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
