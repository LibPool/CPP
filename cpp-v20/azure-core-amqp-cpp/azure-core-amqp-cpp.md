# azure-core-amqp-cpp

> 标签: MIT, azure-core-amqp-cpp, c++, vcpkg

## 简介

Microsoft Azure AMQP SDK for C++
This library provides AMQP functionality to Azure SDK services.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
