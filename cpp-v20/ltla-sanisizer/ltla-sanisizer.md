# ltla-sanisizer

> 标签: MIT, c++, ltla-sanisizer, vcpkg

## 简介

Library that provides a few methods for sanitizing size values so that any overflow results in an error

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
