# libvpx

> 标签: BSD-3-Clause, BSD-3-Clause AND ISC, c++, conan, libvpx, vcpkg

## 简介

The reference software implementation for the video coding formats VP8 and VP9.

Conan Center 收录：WebM VP8/VP9 Codec SDK

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
