# libvpx

> 标签: BSD-3-Clause AND ISC, c++, libvpx, vcpkg

## 简介

The reference software implementation for the video coding formats VP8 and VP9.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
