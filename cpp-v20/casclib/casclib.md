# casclib

> 标签: c++, casclib, vcpkg

## 简介

An open-source implementation of library for reading CASC storage from Blizzard games since 2014

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：http://www.zezula.net/en/casc/casclib.html
- vcpkg 端口：https://vcpkg.io/en/packages/casclib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/casclib
