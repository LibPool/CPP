# bgfx

> 标签: BSD-2-Clause AND CC0-1.0, bgfx, c++, vcpkg

## 简介

Cross-platform, graphics API agnostic, Bring Your Own Engine/Framework style rendering library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
