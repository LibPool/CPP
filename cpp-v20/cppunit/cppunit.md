# cppunit

> 标签: c++, cppunit, vcpkg

## 简介

Unit testing framework module for the C++ programming language

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
