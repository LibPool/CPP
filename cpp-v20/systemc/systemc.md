# systemc

> 标签: Apache-2.0, c++, conan, systemc, vcpkg

## 简介

A set of C++ classes and macros which provide an event-driven simulation kernel in C++

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
