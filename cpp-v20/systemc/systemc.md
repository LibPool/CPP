# systemc

> 标签: c++, systemc, vcpkg

## 简介

A set of C++ classes and macros which provide an event-driven simulation kernel in C++

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
