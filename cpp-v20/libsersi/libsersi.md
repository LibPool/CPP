# libsersi

> 标签: BSD-2-Clause, c++, conan, libsersi, vcpkg

## 简介

C++ implementation of the IEEE 1278.1a-1998 Distributed Interactive Simulation (DIS) application protocol.

Conan Center 收录：Modern C++ implementation of IEEE 1278.1a-1998

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
