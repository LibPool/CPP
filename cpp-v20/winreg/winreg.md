# winreg

> 标签: MIT, c++, vcpkg, winreg

## 简介

High-level C++ wrapper around the Windows Registry C API.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
