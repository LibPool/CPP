# winreg

> 标签: MIT, c++, conan, vcpkg, winreg

## 简介

High-level C++ wrapper around the Windows Registry C API.

Conan Center 收录：Convenient high-level C++ wrapper around the Windows Registry API.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
