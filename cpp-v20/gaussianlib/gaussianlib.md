# gaussianlib

> 标签: c++, gaussianlib, vcpkg

## 简介

Basic linear algebra C++ library for 2D and 3D applications

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
