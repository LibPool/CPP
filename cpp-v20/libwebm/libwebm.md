# libwebm

> 标签: BSD-3-Clause, c++, conan, libwebm, vcpkg

## 简介

WebM File Parser

Conan Center 收录：Library for muxing and demuxing WebM media container files

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
