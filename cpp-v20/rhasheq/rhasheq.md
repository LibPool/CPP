# rhasheq

> 标签: 0BSD, c++, rhasheq, vcpkg

## 简介

Simple header-only librhash wrapper for verifying hashes from a file to a given `const char *`.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
