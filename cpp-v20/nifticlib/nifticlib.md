# nifticlib

> 标签: c++, nifticlib, vcpkg

## 简介

Nifticlib is a C I/O library for reading and writing files in the nifti-1 data format.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/NIFTI-Imaging/nifti_clib
- vcpkg 端口：https://vcpkg.io/en/packages/nifticlib
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/nifticlib
