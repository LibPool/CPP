# bitmagic

> 标签: Apache-2.0, bitmagic, c++, conan, vcpkg

## 简介

Algorithms and tools for Algebra of Sets for information retrieval, indexing of databases, scientific algorithms, ranking, clustering, unsupervised machine learning and signal processing.

Conan Center 收录：BitMagic Library helps to develop high-throughput intelligent search systems,

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
