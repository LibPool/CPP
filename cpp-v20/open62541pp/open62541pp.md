# open62541pp

> 标签: MPL-2.0, c++, conan, open62541pp, vcpkg

## 简介

C++ wrapper of the open62541 OPC UA library

Conan Center 收录：open62541++ is a C++ wrapper built on top of the amazing open62541 OPC UA (OPC Unified Architecture) library

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
