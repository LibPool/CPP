# lilv

> 标签: ISC, c++, lilv, vcpkg

## 简介

Lilv is a C library for simple use of LV2 plugins in applications.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
