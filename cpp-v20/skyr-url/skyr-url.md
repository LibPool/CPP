# skyr-url

> 标签: BSL-1.0, c++, conan, skyr-url, vcpkg

## 简介

A C++ library that implements the WhatWG URL specification

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
