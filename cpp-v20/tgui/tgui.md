# tgui

> 标签: Zlib, c++, tgui, vcpkg

## 简介

TGUI is an easy to use, cross-platform, C++ GUI for SFML.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://tgui.eu
- vcpkg 端口：https://vcpkg.io/en/packages/tgui
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/tgui
