# spectra

> 标签: MPL-2.0, c++, spectra, vcpkg

## 简介

A header-only C++ library for large scale eigenvalue problems

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
