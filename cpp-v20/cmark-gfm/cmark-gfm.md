# cmark-gfm

> 标签: BSD-2-Clause, c++, cmark-gfm, vcpkg

## 简介

GitHub Flavored Markdown parser based on cmark.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
