# libnsgif

> 标签: MIT, c++, libnsgif, vcpkg

## 简介

GIF image decompression library written in C

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://www.netsurf-browser.org/projects/libnsgif/
- vcpkg 端口：https://vcpkg.io/en/packages/libnsgif
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libnsgif
