# at-spi2-core

> 标签: at-spi2-core, c++, vcpkg

## 简介

Base DBus XML interfaces for accessibility, the accessibility registry daemon, and atspi library.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
