# speex

> 标签: BSD-3-Clause, c++, speex, vcpkg

## 简介

Speex is an Open Source/Free Software patent-free audio compression format designed for speech.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
