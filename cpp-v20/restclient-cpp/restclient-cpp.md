# restclient-cpp

> 标签: MIT, c++, restclient-cpp, vcpkg

## 简介

Simple REST client for C++. It wraps libcurl for HTTP requests.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
