# libiconv

> 标签: LGPL-2.1-or-later, c++, conan, libiconv, vcpkg

## 简介

iconv() text conversion.
This port installs GNU libiconv if the system C runtime doesn't provide a suitable iconv() implementation.

Conan Center 收录：Convert text to and from Unicode

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
