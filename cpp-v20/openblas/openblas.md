# openblas

> 标签: BSD-3-Clause, c++, openblas, vcpkg

## 简介

OpenBLAS is an optimized BLAS library based on GotoBLAS2 1.13 BSD version.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/OpenMathLib/OpenBLAS
- vcpkg 端口：https://vcpkg.io/en/packages/openblas
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/openblas
