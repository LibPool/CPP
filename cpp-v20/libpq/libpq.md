# libpq

> 标签: PostgreSQL, c++, conan, libpq, vcpkg

## 简介

The official database access API of postgresql

Conan Center 收录：The library used by all the standard PostgreSQL tools.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

Conan 安装：`conan install --requires=libpq/17.11`

- vcpkg 许可证：PostgreSQL
