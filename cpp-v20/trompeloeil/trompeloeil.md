# trompeloeil

> 标签: BSL-1.0, c++, conan, trompeloeil, vcpkg

## 简介

A thread-safe header-only mocking framework for C++11/14 using the Boost Software License 1.0

Conan Center 收录：Header only C++14 mocking framework

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
