# enkits

> 标签: Zlib, c++, conan, enkits, vcpkg

## 简介

A permissively licensed C and C++ Task Scheduler for creating parallel programs.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
