# picobench

> 标签: MIT, c++, picobench, vcpkg

## 简介

A micro microbenchmarking library for C++11 in a single header file

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/iboB/picobench
- vcpkg 端口：https://vcpkg.io/en/packages/picobench
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/picobench
