# tiny-dnn

> 标签: BSD-3-Clause, c++, conan, tiny-dnn, vcpkg

## 简介

A C++14 implementation of deep learning. It is suitable for deep learning on limited computational resource.

Conan Center 收录：tiny-dnn is a C++14 implementation of deep learning.

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
