# tiny-dnn

> 标签: c++, tiny-dnn, vcpkg

## 简介

A C++14 implementation of deep learning. It is suitable for deep learning on limited computational resource.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
