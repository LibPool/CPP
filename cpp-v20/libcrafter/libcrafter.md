# libcrafter

> 标签: c++, libcrafter, vcpkg

## 简介

Libcrafter is a high level library for C++ designed to create and decode network packets.

本库来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网

- 官网：https://github.com/pellegre/libcrafter
- vcpkg 端口：https://vcpkg.io/en/packages/libcrafter
- vcpkg 源码：https://github.com/microsoft/vcpkg/tree/master/ports/libcrafter
