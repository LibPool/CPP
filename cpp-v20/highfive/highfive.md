# highfive

> 标签: BSL-1.0, c++, highfive, vcpkg

## 简介

HighFive is a modern, user-friendly, header-only, C++14 interface for libhdf5.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
