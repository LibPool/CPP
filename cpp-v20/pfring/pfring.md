# pfring

> 标签: c++, pfring, vcpkg

## 简介

Library to interface with the PF_RING™ kernel module for processing packets at high-rates while providing a consistent API.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
