# cpp-jwt

> 标签: MIT, c++, conan, cpp-jwt, vcpkg

## 简介

JSON Web Token library for C++

Conan Center 收录：A C++ library for handling JWT tokens

本库来自 vcpkg 官方端口集、Conan Center 官方 recipe 集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
