# libpcap

> 标签: BSD-3-Clause, c++, libpcap, vcpkg

## 简介

A portable C/C++ library for network traffic capture

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
