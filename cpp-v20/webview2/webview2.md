# webview2

> 标签: BSD-3-Clause, c++, vcpkg, webview2

## 简介

The WebView2 control allows you to embed web technologies (HTML, CSS, and JavaScript) using Microsoft Edge

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
