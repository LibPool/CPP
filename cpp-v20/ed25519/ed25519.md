# ed25519

> 标签: Zlib, c++, ed25519, vcpkg

## 简介

Portable C implementation of Ed25519, a high-speed high-security public-key signature system.

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。

## 官网
