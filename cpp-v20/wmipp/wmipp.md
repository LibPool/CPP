# wmipp

> 标签: MIT, c++, vcpkg, wmipp

## 简介

Streamlined Windows Management Instrumentation (WMI) integration for seamless C++ development

本端口来自 vcpkg 官方端口集，已收录于 cpp-v11、cpp-v14、cpp-v17、cpp-v20、cpp-v23。
